(b) 可采纳启发组合（2 分）

答案

勾选 4 项：$\frac{f}{3}+\frac{g}{3}+\frac{h}{3}$ ✓、$\frac{f}{6}+\frac{g}{3}+\frac{h}{2}$ ✓、$\min(f,g,h)$ ✓、$\max(f,g,h)$ ✓

推理（设三者都 admissible：各 $\le h^*$ 且 $\ge 0$）：

  • 和 $f+g+h$：$\le 3h^*$，可超 $h^*$（反例 $f=g=h=h^*=2$ → 和 = 6 > 2）✗
  • $\frac{f+g+h}{3}$：权重和为 1 的凸组合 ⟹ $\le \frac{h^*+h^*+h^*}{3}=h^*$ ✓
  • $\frac{f}{6}+\frac{g}{3}+\frac{h}{2}$：$\frac16+\frac13+\frac12=1$，同为凸组合 ✓
  • 乘积 $f\cdot g\cdot h$：$2\cdot2\cdot2=8>2$ ✗（每个都 $\le h^*$ 也救不了乘法）
  • $\min$：不超过任何一个 ⟹ $\le h^*$ ✓（但可能太弱）
  • $\max$：被三个 $h^*$ 封顶 ⟹ $\le h^*$ ✓（三者中最强且仍 admissible）

口诀：凸组合、min、max 保 admissible；求和、乘积不保。

(c) Forward Checking（各 1 分）

答案

约束图（已核实）：A—D、A—B、B—C、B—E、C—F

MAXb(△): [叶20, MINb(▽)]     MINb(▽): [叶50, 叶2]

(a) Minimax 值（2 分）

答案
节点计算值

(b) α-β 剪枝（5 分）

答案：原顺序有两处剪枝 
root MAX(-∞,+∞)
├─叶10 → α=10
├─MIN₁(α=10,β=+∞)
│   ├─叶15 → β=15
│   └─MAXa(α=10,β=15)
│       ├─叶1  → v=1, α 仍 10
│       └─MINa(α=10,β=15)
│           ├─叶5 → v=5 ≤ α=10 ✂ 剪！返回 5（界，非真值 2）
│           └─叶2  ← 未探索
│       → MAXa 返回 max(1,5)=5
│   → MIN₁ 返回 min(15,5)=5，root α 仍 10
├─MIN₂(α=10,β=+∞)
│   ├─叶15 → β=15
│   └─MAXb(α=10,β=15)
│       ├─叶20 → v=20 ≥ β=15 ✂ 剪！返回 20
│       └─MINb(50,2) ← 整个子树未探索
│   → MIN₂ 返回 min(15,20)=15，root α=15
└─叶20 → v=20 → root = 20 ✓（与 (a) 一致）

被剪内容：① MINa 的第二个孩子（叶 2，左下）；② MAXb 的第二个孩子 MINb 及其两个叶（50、2，右下）。共 3 个叶子未探索。在图上给这两条枝画斜线、给叶 2 / MINb / 50 / 2 涂阴影。

注意卷面约定 α ≥ β 含等号即可剪——本题两处剪枝都是严格不等（5<10、20>15），用哪种教材约定结果相同。

(c) 更优顺序（2 分）

答案

有。把根的孩子按 minimax 值降序：[叶20, MIN₂, MIN₁, 叶10]（或 [20, MIN₁, MIN₂, 10]，前两个换序效果相同）。

叶20 → α=20
MIN₂(α=20): 叶15 → v=15 ≤ 20 ✂ 剪掉 MAXb 子树（20,50,2 未探索）
MIN₁(α=20): 叶15 → v=15 ≤ 20 ✂ 剪掉 MAXa 子树（1,5,2 未探索）
叶10 → 10 < 20，无剪枝
root = 20 不变；未探索叶子 6 个（对比原顺序 3 个）

原理：MAX 先看大孩子尽早抬 α；之后每个 MIN 第一个孩子就触发 $v \le \alpha$ 剪枝。
