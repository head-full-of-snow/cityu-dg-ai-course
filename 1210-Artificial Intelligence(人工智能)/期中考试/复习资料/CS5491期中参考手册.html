1. 搜索问题形式化 Search Problems (L01–02)

核心定义

一个搜索问题由四部分组成：

  • 状态空间 $S$：世界配置的抽象表示（只保留规划所需细节）
  • 后继函数 $succ(s) \to \{(action,\ s',\ cost)\}$
  • 初始状态 $s_0$ 与目标测试 $Goal(s)$

解 Solution：把 $s_0$ 变换到满足目标测试状态的动作序列（一个计划）。

Agent 与环境分类

  • 理性 Agent：选择最大化（期望）效用的动作。不是全知、不能预见未来，但自主。
  • 反射 Agent 只看当前感知；规划 Agent 基于动作的预测后果决策，需要转移模型 + 目标。
  • PEAS = Performance, Environment, Actuators, Sensors。
  • 环境维度：完全/部分可观测、单/多 agent、确定/随机、静态/动态、离散/连续。

状态空间图 vs 搜索树

状态空间图 State Space Graph搜索树 Search Tree
节点状态（每个状态只出现一次）路径/计划（同一状态可多次出现）
关系搜索树中每个节点 = 状态空间图中一整条路径；两者都按需、尽量少地构造
常见题型

① 给场景（Pacman / 罗马尼亚旅行）写出状态、后继函数、目标测试；② 判断某细节是否需要进入搜索状态（state abstraction）；③ 计算状态空间大小（各维度相乘）。

2. 无信息搜索 Uninformed Search (L03)

通用框架

所有搜索算法 = fringe（边缘队列） + expansion（扩展） + 探索策略（弹哪个节点）。树中节点数 $1+b+b^2+\cdots+b^m = O(b^m)$（$b$=分支因子，$m$=最大深度）。

算法策略Fringe 实现CompleteOptimalTimeSpace
DFS最深的先扩展栈 LIFO仅当 $m$ 有限且防环✗（找"最左"解）$O(b^m)$$O(bm)$
BFS最浅的先扩展队列 FIFO✓仅当代价全为 1$O(b^s)$$O(b^s)$
UCS累计代价 $g(n)$ 最小先扩展优先队列（key=$g$）✓（弧代价 $\epsilon>0$）✓$O(b^{C^*/\epsilon})$$O(b^{C^*/\epsilon})$
迭代加深限深 DFS：深度 1,2,3,…栈✓同 BFS（代价为 1）$O(b^s)$$O(bs)$
  • $s$ = 最浅解的深度；$C^*$ = 最优解代价；"有效深度" $\approx C^*/\epsilon$。
  • BFS 找的是动作数最少的路径，不是代价最小的路径 → 需要代价敏感时用 UCS。
  • UCS 沿等代价等值线（cost contours）向外扩展：没有目标方向信息 → 引出 A*。
  • 迭代加深看似重复浪费，但绝大多数节点在最后一层，代价可接受；兼得 DFS 空间与 BFS 完备性。
常见题型

① 在小图上按给定算法写出节点扩展顺序（注意 fringe 内容追踪）；② 判断 complete/optimal 并说明原因；③ 复杂度计算（给定 $b, m, s$）。

3. 有信息搜索 Informed Search (L04)

核心公式 $$f(n) = g(n) + h(n)$$
  • $g(n)$：向后代价（起点到 $n$ 的实际路径代价）——UCS 用
  • $h(n)$：向前代价估计（$n$ 到最近目标的估计）——Greedy 用
  • A* = UCS + Greedy：按 $f(n)$ 排序的优先队列

启发函数 Admissibility（可采纳性）

定义 $$0 \le h(n) \le h^*(n)\quad \text{（} h^*(n) \text{ 为到最近目标的真实代价）}$$

Admissible = 乐观。悲观（不可采纳）启发会因低估好计划而在 fringe 上被困，破坏最优性。

A* 关键考点

  • 终止条件：dequeue（弹出）目标时才停，不是 enqueue 时。目标入队后可能还有更便宜的路径。
  • 最优性（树搜索，$h$ 可采纳）证明骨架：设 $A$ 最优、$B$ 次优目标，$n$ 是 $A$ 在 fringe 上的祖先： $$f(n) \le g(A) = f(A) < f(B)$$ 故 $A$ 及其所有祖先都在 $B$ 之前弹出 → A* 最优。
  • 构造可采纳启发：解一个松弛问题（放宽约束、增加可用动作），其精确解即为原问题的乐观估计。例：忽略墙 → 曼哈顿距离；忽略只能向前翻 → 煎饼问题的最大错位索引。
  • UCS 均匀向各方向扩展；A* 主要朝目标扩展但保留少量对冲以保证最优性。
GreedyUCSA*
排序依据$h(n)$$g(n)$$f(n)=g(n)+h(n)$
最优✗（像被误导的 DFS）✓✓（$h$ 可采纳）
方向性直冲目标（可能错）全向朝目标 + 对冲
常见题型

① 给 $h$ 表，追踪 A* 扩展顺序并写出每个节点的 $g, h, f$；② 证明某 $h$ 是否 admissible（逐点验证 $h(n)\le h^*(n)$ 或说明它是松弛问题的精确解）；③ 解释为什么必须在 dequeue 目标时终止；④ Greedy / A* 在同一图上的行为对比。

4. 约束满足问题 CSP (L05–06)

定义

CSP = $(\mathbf{X}, D, C)$：变量 $X_i$ 取值于域 $D_i$，约束 $C$ 规定变量子集的合法组合。解 = 满足所有约束的完整赋值。

CSP 是"识别问题"（identification）：重要的是目标本身而非路径——与规划问题（路径重要）相对。

  • 例：地图着色（变量=区域，域={red,green,blue}，约束=相邻不同色）；N 皇后两种建模（$X_{ij}\in\{0,1\}$ vs $Q_k\in\{1..N\}$，后者变量更少更好）。
  • 约束图：节点=变量，弧=二元约束。塔斯马尼亚 = 独立子问题。
  • 约束种类：一元（等价于直接缩减域）、二元、高阶（如 cryptarithmetic 列约束）、软约束（偏好 → 约束优化）。
  • 域大小 $d$、变量数 $n$ → 完整赋值 $O(d^n)$ 个；布尔 CSP = SAT（NP-complete）。

回溯搜索 Backtracking

两个改进

回溯 = DFS + 以下两点：

  1. 每次只赋值一个变量（赋值可交换 commutative，固定变量顺序即可，砍掉 $n!$ 重复）；
  2. 边赋值边检查（incremental goal test）：只考虑与已赋值不冲突的值。

三大改进方向

方向技术规则要点
排序 OrderingMRV（变量排序）选剩余合法值最少的变量fail-fast；"最受约束变量"先赋值
LCV（值排序）选排除邻居选项最少的值给后续留最大余地
过滤 FilteringForward Checking赋值后划掉未赋值变量域中冲突的值任何域变空 → 立即回溯
弧一致 Arc Consistency弧 $X\to Y$ 一致 ⟺ 对尾 $X$ 的每个 $x$，头 $Y$ 中存在相容的 $y$（从尾删值）$X$ 丢值 → $X$ 的邻居需重检；AC-3 复杂度 $O(n^2d^3)$（可优化 $O(n^2d^2)$）
结构 Structure独立子问题约束图的连通分量$n$ 变量分成大小 $c$ 的子问题 → $O\big((n/c)\,d^c\big)$
树形 CSP无环约束图$O(nd^2)$ 可解（选根排序 → 反向 RemoveInconsistent → 正向赋值）
割集条件 Cutset实例化 $c$ 个变量使剩余图成树$O(d^c\,(n-c)\,d^2)$，$c$ 小则极快
易错点
  • 弧一致 ≠ 有解：弧一致后可能剩 1 个解、多个解、或 0 个解（却不知道）；弧一致仍需在回溯框架内运行。
  • Forward checking 只传播"已赋值→未赋值"，不做约束到约束的推理（例：NT、SA 都只剩 blue 却都未赋值 → 冲突检测不到，弧一致可以）。
常见题型

① 手动模拟回溯（含 MRV/LCV）过程；② 给定赋值后执行 forward checking（写域变化表）；③ 判断某弧是否一致 / 执行一轮 AC-3；④ 求树形 CSP 的解；⑤ 复杂度计算。

5. 对抗搜索 Adversarial Search (L07–08)

确定性博弈形式化

$(S, s_0, P, A, succ: S\times A\to S,\ terminal: S\to\{t,f\},\ utility: S\times P\to \mathbb{R})$；玩家的解是一个策略 policy $S\to A$。零和博弈：一方效用 = 另一方负效用 → 一方 max 一方 min。

Minimax

递归定义 $$V(s)=\begin{cases}\text{已知} & s\text{ 为终态}\\[2pt] \max_{s'\in succ(s)} V(s') & s\text{ 由 MAX 控制}\\[2pt] \min_{s'\in succ(s)} V(s') & s\text{ 由 MIN 控制}\end{cases}$$

时间 $O(b^m)$，空间 $O(bm)$（同穷举 DFS）。对完美对手最优；对非完美对手可能错过"诱饵"机会（100 的分支需要对手失误才拿得到）。

α-β 剪枝

剪枝规则（核心）
  • $\alpha$：MAX 在上方选择点已保证的最好值（下界/floor）；$\beta$：MIN 已保证的最好值（上界/ceiling）。
  • 只有严格介于 $\alpha,\beta$ 之间的值才可能影响根的决策。
  • MIN 节点：$v$ 只降不升，一旦 $v\le\alpha$ → 剪枝（MAX 上层不会选它）。
  • MAX 节点：$v$ 只升不降，一旦 $v\ge\beta$ → 剪枝（MIN 上层不会允许）。
  • 实现：根调用 $(-\infty,+\infty)$；每个子调用传递当前 $(\alpha,\beta)$；先测试后更新：MAX 每个孩子后 if $v\ge\beta$ return，else $\alpha\leftarrow\max(\alpha,v)$；MIN 对称。
  • 根的 minimax 值不变；中间节点值可能算错（含根的孩子）→ 朴素版不能直接做动作选择。
  • 剪枝效率依赖子节点顺序；完美排序 $O(b^{m/2})$（可搜深度翻倍）。
  • 深度受限搜索：用评价函数 eval 替代终局效用；失去最优保证（horizon effect）；迭代加深做 anytime。

Expectimax（含随机性）

机会节点 $$v = \sum_i p_i\, v_i \qquad \text{（加权平均；例：} \tfrac12(8)+\tfrac13(24)+\tfrac16(-12)=10\text{）}$$
  • MAX 节点同 minimax；MIN 节点换成机会节点（期望）。
  • Expectimax 一般不能剪枝——未见孩子可以任意大/小；只有当效用有界 $[lo, hi]$ 时才可用上界估计剪枝（例：$[0,10]$ 中 $(2+10+10)/3\approx 7.3<8$ → 剪）。
  • 混合博弈（西洋双陆棋）：Expectiminimax——max/min/chance 交替。骰子使 $b$ 增大（21 种掷法 × 20 步法）。

效用 Utilities

  • minimax 只需单调（对正单调变换不敏感，只要序不变）；expectimax 需要数值大小有意义（平方后 20 vs 25 变 800 vs 650，决策翻转）。
  • 最大期望效用原理：理性 agent 选择最大化期望效用的动作。von Neumann–Morgenstern 定理：理性偏好都可总结成效用函数。
  • 危险乐观（把对抗当随机）/ 危险悲观（把随机当最坏）：minimax Pacman 对随机鬼 493 分，expectimax 503 分；但对抗鬼下 expectimax 输惨。
常见题型

① 给博弈树算 minimax 值；② α-β 剪枝追踪（标出被剪节点 + 每个节点收到的 $(\alpha,\beta)$）；③ expectimax 计算（带概率的机会节点）；④ 混合树（max/min/chance）；⑤ 概念题：为什么 expectimax 不能直接剪枝 / 效用尺度何时重要。

6. 线性规划 LP (L09)

三种形式与转化

标准记法 $$\min_{\mathbf{x}}\ \mathbf{c}^T\mathbf{x}\quad s.t.\quad \mathbf{A}\mathbf{x}\le\mathbf{b} \qquad\text{（不等式形式）}$$ $$\min_{\mathbf{x}}\ \mathbf{c}^T\mathbf{x}\quad s.t.\quad \mathbf{A}\mathbf{x}=\mathbf{b},\ \mathbf{x}\ge\mathbf{0} \qquad\text{（标准形式，加松弛变量可得）}$$
  • $\ge$ 约束 → 两边乘 $-1$ 变 $\le$（$b$ 也变号）；min ↔ max 互转：$\max f = -\min(-f)$。
  • LP = 线性目标 + 线性约束 + 连续变量。

几何图解法（2D 必考）

  • 每个约束 $a_1x_1+a_2x_2\le b$ 是半平面；交集 = 可行多面体（凸）。
  • 代价等值线 $\mathbf{c}^T\mathbf{x}=k$ 是平行直线族；$\mathbf{c}$ 垂直于它们并指向代价增大方向 → 沿 $-\mathbf{c}$ 平移等值线找最小。
  • 顶点定理：非空有界的可行多面体，至少一个最优解在顶点（2D 顶点 = 两条独立约束边界的交点，且满足所有原约束）。

Diet 例子（课上完整推导）

建模→求解 $$\begin{aligned}\min\quad &x_1+0.4x_2\\ s.t.\quad &2000\le 100x_1+50x_2\le 2500\\ &3x_1+4x_2\le 100\\ &20x_1+70x_2\ge 700\\ &x_1,x_2\ge 0\end{aligned}$$

binding 约束（取等号）：热量下界 + 糖上界 → 解方程组 $100x_1+50x_2=2000,\ 3x_1+4x_2=100$ 得 $(x_1,x_2)=(12,16)$，最小代价 $12+0.4(16)=18.4$；其余顶点代价 $19.5,\ 24,\ 24\tfrac23$。

LP 的三种结局

结局例子含义
有限最优$\min x,\ x\ge 0$最优值 0，在 $x=0$
不可行 Infeasible$\min x,\ x\ge 1,\ x\le 0$没有点满足所有约束
无界 Unbounded$\min -x,\ x\ge 0$目标可无限下降

注意：可行域无界 ≠ 目标无界（第一个例子的可行域也无界却有有限最优）。

  • 算法概念：单纯形 simplex（顶点间移动）、内点法 interior-point（从内部逼近）；考试以图解法 + 顶点枚举为主。
常见题型

① 从文字题建 LP 模型（定变量和单位 → 目标 → 约束 → 非负）；② 图解：画可行域、枚举顶点、求最优；③ 识别 binding 约束；④ 判断 infeasible/unbounded/有限最优。

7. 整数规划与分支定界 Integer Programming (L10)

模型变量域
LP$x_i\in\mathbb{R}$
Pure ILP$x_i\in\mathbb{Z}$（全部整数）
Binary IP$x_i\in\{0,1\}$（选中/不选中）
MILP部分整数部分连续

LP 松弛 Relaxation

核心不等式 $$P_{\mathrm{IP}}\subseteq P_{\mathrm{LP}}\quad\Longrightarrow\quad z^*_{\mathrm{LP}}\le z^*_{\mathrm{IP}}\quad\text{（min 问题：LP 是下界）}$$
  • 做法：去掉整数约束，保留目标、约束、变量界。
  • 与 A* 的联系：松弛问题的解 = 乐观估计（admissible）；节点 LP 界 = 该节点内最优整数解的下界。
  • 三条判断：① $z^*_{LP}\le z^*_{IP}$ 恒成立；② $x^*_{LP}=x^*_{IP}$ 不一定（LP 最优可能分数）；③ 若 LP 最优点恰好整数坐标 → 它就是 IP 最优（可行 + 达到下界）。
四舍五入会失败

例（课上）：$\min x-4y$ s.t. $-10x+20y\le 22,\ 5x+10y\le 49,\ 0\le x\le 5, y\ge 0$，$x,y\in\mathbb{Z}$。LP 最优 $(3.8, 3)$ 值 $-8.2$；最近舍入 $(4,3)$ 违反 $5x+10y\le 49$（50>49）不可行；附近可行的 $(4,2)$ 值 $-4$，但真正的整数最优是 $(2,2)$ 值 $-6$ → 可行舍入也未必最优。

分支定界 Branch & Bound（重点大题）

规则集
  • Incumbent：迄今最好的可行整数解；全局上界 $U$ = 其目标值（初始 $+\infty$）。找到更好的整数解（值 $z$）→ $U\leftarrow z$。
  • 节点下界 $L$：该节点 LP 松弛的最优值。
  • 分支规则：选分数值的整数变量 $x_i^*$：左孩子加 $x_i\le\lfloor x_i^*\rfloor$，右孩子加 $x_i\ge\lceil x_i^*\rceil$（如 $3.8\to x\le 3$ 或 $x\ge 4$）。两个孩子排除当前分数解，且覆盖所有整数解。
  • 三种关闭节点：① LP 不可行 → 关；② LP 最优为整数 → 更新 incumbent 后关；③ $L\ge U$ → 剪枝（例：$L=-5.4\ge U=-6$ → 剪）。
  • 无节点可开时，incumbent 即最优（最优性证书：每个叶子都不可行/已整数解/无法改进 $U$）。
课上完整例子的树 
root LP: (3.8,3) L=-8.2, U=+∞ ── branch on x
├─ x≥4: LP (4,2.9) L=-7.6 ── branch on y
│   ├─ y≤2: (4,2) 整数 → U=-4
│   └─ y≥3: 不可行 → 关
└─ x≤3: LP (3,2.6) L=-7.4 (>-4? no: -7.4<-4 继续) ── branch on y
    ├─ y≥3: 不可行 → 关
    └─ y≤2: LP (1.8,2) L=-6.2 ── branch on x
        ├─ x≥2: (2,2) 整数 → U=-6
        └─ x≤1: LP (1,1.6) L=-5.4 ≥ U=-6 → 剪枝
最优: x*=(2,2), z*=-6（U: +∞ → -4 → -6）
常见题型

① 手动执行 B&B（画树：每节点写 LP 解、$L$、动作）；② 判断某节点该不该剪；③ "能否在第一个整数解就停？"（不能：例中 $-4$ 后来改进到 $-6$）；④ 解释松弛为何给下界。

8. 优化建模 Modeling Optimization (L11)

统一框架 $$\min_{\mathbf{x}\in\mathcal{F}} f(\mathbf{x})$$
组件含义
决策变量 $\mathbf{x}$我们选择的东西（vs 给定的数据）
可行集 $\mathcal{F}$满足所有域限制和约束的选择
目标 $f:\mathcal{F}\to\mathbb{R}$要最小化的值
  • argmin = 所有最优解的集合（点）；$f^*$ = 最优值（数）。例：$\min t^2$ over $\{-1,1\}$：argmin $=\{-1,1\}$，$f^*=1$。
  • 三种结局：取得最小（$\min t, t\in[0,1]$ → $t^*=0$）/ 无界（$\min t, t\in\mathbb{R}$）/ 不可行（$t\ge 1$ 且 $t\le 0$）。
  • min ↔ max：$\operatorname{argmin} f = \operatorname{argmax}(-f)$；$g^*=-f^*$。
  • 变量类型：连续 $\mathbb{R}$ / 离散 $\{0,1\}$ / 混合。先定单位再写模型（8 oz 一份 → amount $=8n$）。
  • 建模示例：TSP（$x$=排列，$f=\sum_{k=1}^{n-1}d(x_k,x_{k+1})+d(x_n,x_1)$，闭合边橙色部分别漏）；8 皇后 = 可行性问题（$f\equiv 0$，每个可行解都最优，约束 $x_i\ne x_j,\ |x_i-x_j|\ne|i-j|$）；过原点回归 $L_1=\sum|y_i-ax_i|$ vs $L_2=\sum(y_i-ax_i)^2$（$L_1$ 最优斜率可能是区间；$L_2$ 唯一；都凸，凸 ≠ 唯一）。
  • 解模型流程：写变量/约束/目标 → 按结构选方法 → 求解看状态 → 检查可行 + 重算目标 → 回到原问题解释。
常见题型

① 概念辨析：feasible / optimal / optimal value / argmin；② 判断问题是否有解、是否无界；③ 给场景指出变量/数据/可行集/目标；④ "这是 LP 吗？"（目标或约束非线性就不是）。

9. 凸优化与梯度下降 Convex Optimization (L12)

定义链

凸组合：$\mathbf{z}=\theta\mathbf{x}+(1-\theta)\mathbf{y},\ 0\le\theta\le1$。

凸集：$\mathbf{x},\mathbf{y}\in\mathcal{F} \Rightarrow \theta\mathbf{x}+(1-\theta)\mathbf{y}\in\mathcal{F}$（线段不出集）。

凸函数：$f(\theta\mathbf{x}+(1-\theta)\mathbf{y})\le\theta f(\mathbf{x})+(1-\theta)f(\mathbf{y})$（图在弦下方；严格凸取 $<$）。

凸优化问题：$\mathcal{F}$ 凸 + $f$ 凸（两个条件都要）。

凸性判断工具箱

工具判据
定义直接验证 Jensen 不等式
运算保凸凸函数非负加权和 $\sum w_if_i$；凸函数复合仿射映射 $g(A\mathbf{x}+\mathbf{b})$
二阶导（1D）$f''(t)\ge 0$ on 开区间 ⟺ 凸

最优性性质

  • 局部 = 全局：凸问题的每个局部最小都是全局最小（若有更优点，朝它挪一点立即改进）。
  • 凸性不保证存在性也不保证唯一性：
    凸问题结果
    $\min_{\mathbb{R}}[(t-2)^2+1]$仅在 $t=2$ 取得
    $\min_{\mathbb{R}} e^t$下确界 0，无取得点
    $\min_{[0,1]^2}(u+v-1)^2$$F^*=0$，argmin = 整条线段 $\{(u,1-u)\}$（无穷多）
  • 严格凸 → 至多一个最小点（存在性另论）。

梯度下降 Gradient Descent

更新公式 $$\mathbf{x}_{k+1}=\mathbf{x}_k-\alpha_k\nabla f(\mathbf{x}_k),\qquad \alpha_k>0$$
  • $\nabla f$ = 偏导向量；指向最速上升方向 → 负梯度是下降方向。
  • 例：$q(t)=(t-2)^2+1$，$t_0=0$，$\alpha=\tfrac14$：$q'(0)=-4$ → $t_1=0-\tfrac14(-4)=1$（$q:5\to2$）；$t_2=1-\tfrac14(-2)=\tfrac32$（$q=\tfrac54$）→ 单侧逼近 $t^*=2$。
  • 步长分析：每步把误差乘 $(1-2\alpha)$：$t_{k+1}-2=(1-2\alpha)(t_k-2)$。
    $\alpha$因子行为
    $\tfrac14$$\tfrac12$收敛到 2
    $1$$-1$振荡 $0,4,0,4,\dots$
    $\tfrac54$$-\tfrac32$发散
    收敛条件 $|1-2\alpha|<1$ 即 $0<\alpha<1$（本例）。
  • 停止与最优性：无约束可微凸问题，$\nabla f(\mathbf{x})=0$ 即全局最小证书；实用停止：梯度范数、目标变化量、迭代上限。小心：步长太小 → 更新量小但离最优还远（$f=t^2$, $t_0=100$, $\alpha=10^{-12}$：一步只挪 $2\times10^{-10}$）。
  • 投影梯度下降（带约束版，选学不考）：$\mathbf{x}_{k+1}=P_{\mathcal{F}}(\mathbf{x}_k-\alpha_k\nabla f)$。
常见题型

① 判断集合/函数凸性（用二阶导/Hessian/运算规则）；② 一步或多步 GD 迭代计算；③ 求全部最小点（如 $(u+v-1)^2$ 类）；④ 步长与收敛行为分析；⑤ "局部最优何时是全局"。

10. 高频题型 · 从零解题模板

考试大题的标准套路。每题先写清假设（题目歧义时明确写出，按假设评分）。

T1 · A* / UCS 搜索追踪

步骤
  1. 列表格：列 = 迭代轮次；每轮记录：弹出的节点（expand）、其 $g,h,f$、新生成的节点、fringe 内容（按 $f$ 排序）。
  2. 初始化：fringe = {起点}，$g(s_0)=0$。
  3. 循环：弹出 $f$ 最小的节点（并列时任选，写明你的打破平局规则，如字母序/后进先出）。
  4. 目标测试在弹出时做（dequeue 才停！A* 最优性的关键）。
  5. 展开：对每个后继 $s'$ 计算 $g(s')=g(s)+c(s,s')$，$f=g+h$，入队。树搜索：重复状态也再次入队；图搜索：已扩展过的跳过，未扩展但已在 fringe 的若新 $g$ 更小则更新。
  6. 写出解路径与代价；若题目问"为什么不是更早出现的目标"，引用 dequeue 终止规则。

T2 · 构造可采纳启发函数

步骤
  1. 识别原问题的约束（墙、只能向前翻、每步代价 …）。
  2. 放松：去掉一个或多个约束（增加可用动作 = 只会降低真实代价）。
  3. 精确求解松弛问题 → 其解即 $h(n)$（例：忽略墙 → 曼哈顿距离；任意翻转 → 错位数）。
  4. 验证 admissibility：$0\le h(n)\le h^*(n)$，一句话论证"松弛问题的最优代价 ≤ 原问题最优代价，因为原问题的每个解也是松弛问题的可行解"。

T3 · α-β 剪枝追踪（必考）

步骤
  1. 从左到右、自底向上（后序）遍历；根是 MAX，调用参数 $(-\infty,+\infty)$。
  2. 每个节点旁标注它收到的 $(\alpha,\beta)$（来自父辈的窗口）。
  3. MIN 节点：看完一个孩子得 $v$ 后：若 $v\le\alpha$ → 立即返回，剩余孩子画 X（剪枝）；否则 $\beta\leftarrow\min(\beta,v)$，把更新后的窗口传给下一个孩子。
  4. MAX 节点对称：$v\ge\beta$ → 剪枝返回；否则 $\alpha\leftarrow\max(\alpha,v)$。
  5. 叶节点直接返回效用值。
  6. 答案标注：根的最终值 = minimax 值（不变）；数出被剪的叶节点数；如被问"根的孩子值对不对"——可能错（剪枝版本不能做动作选择）。

课上例：左 MIN 返回 3（root 设 $\alpha=3$）→ 中间 MIN 第一个孩子 2 ≤ 3 → 其余两个孩子被剪 → 右 MIN 无剪枝返回 2 → root = max(3,2,2) = 3。若中间叶子顺序是 6,4,2 则一个都剪不掉——剪枝依赖顺序。

T4 · Expectimax 计算

步骤
  1. 自底向上：叶 = 效用；MAX 节点 = max；机会节点 = $\sum p_i v_i$（概率在枝上给定时直接加权；"equally likely" = 均匀分布取平均）。
  2. 决策节点选最大期望的分支。
  3. 概念追问：为何不能像 α-β 那样剪（未见孩子可任意大）→ 给效用界 $[lo,hi]$ 才能剪：上界 $=\frac{(\text{已见和})+(\text{未见数})\times hi}{\text{总数}}$，若仍 < 当前最好 → 剪。

T5 · 回溯搜索 + MRV + Forward Checking

步骤
  1. 选变量：MRV——数每个未赋值变量当前域大小，选最小（并列任选并注明）。
  2. 选值：LCV——试着数该值会删掉邻居多少个值，选删最少的；题目不要求时可按域顺序。
  3. 一致性检查：与所有已赋值变量的约束比对（增量目标测试）。
  4. Forward checking 表：每步赋值后，更新所有未赋值变量的域（划掉冲突值）；任何域空 → 回溯。
  5. 画出完整搜索过程（赋值序列 + 回溯箭头），直到得到一个满足所有约束的完整赋值。

T6 · 弧一致性检查

步骤
  1. 对弧 $X\to Y$：对 $X$ 域中每个 $x$，在 $Y$ 域中找至少一个 $y$ 使 $(x,y)$ 满足约束（"支持"）。
  2. 没有支持的 $x$ → 从 $X$ 的域（尾）中删除。
  3. $X$ 丢值后 → 所有指向 $X$ 的弧 $(Z\to X)$ 重新入队检查（AC-3 队列机制）。
  4. 结论表述：弧一致后域的最终状态；域空 → 无解；注意弧一致 ≠ 有解。

T7 · LP 图解法完整流程

步骤
  1. 定变量和单位：$x_1$ = …（oz），$x_2$ = …（fl oz）。
  2. 写模型：目标 $\mathbf{c}^T\mathbf{x}$；把每句话翻成线性约束；加非负约束。
  3. 标准化（如需）：$\ge$ 乘 $-1$ 变 $\le$。
  4. 画可行域：每约束一条边界线 + 阴影半平面；交集为凸多面体（标出顶点）。
  5. 枚举顶点：每个顶点选 $n$ 条（2D 即 2 条）独立约束令其取等，解线性方程组，代回所有原约束验证可行。
  6. 求最优：两条路线任选——(a) 顶点枚举：算每个顶点的 $\mathbf{c}^T\mathbf{x}$ 取最小；(b) 等值线：画 $\mathbf{c}^T\mathbf{x}=k$，沿 $-\mathbf{c}$ 方向平移到最后的接触点。
  7. 报告：最优解（变量值 + 单位）、最优值、binding 约束（取等的那些）、其他顶点的值（可验证）。
  8. 检查特判：无可行域 → infeasible；等值线可无限平移 → unbounded。

T8 · Branch & Bound 完整流程（必考大题）

步骤
  1. 根节点：解 LP 松弛（用 T7 的图解/顶点法）。得 $x^{LP}, L=z^{LP}$。
  2. 判定（按序检查三种关闭条件）：
    • LP 不可行 → 关闭该节点；
    • $x^{LP}$ 全整数 → 候选解：若 $z^{LP}<U$ 则更新 incumbent（$U\leftarrow z^{LP}$，记录解），关闭；
    • $L\ge U$ → 剪枝关闭（写明"$L\ge U$"作为理由）；
  3. 分支：选一个分数变量 $x_i^*$（任选，注明规则，通常选分数部分最大者或先出现的），生成两孩子：$x_i\le\lfloor x_i^*\rfloor$ 与 $x_i\ge\lceil x_i^*\rceil$。孩子继承全部祖先约束。
  4. 探索顺序：DFS（课上例子先探 $x\ge4$ 一侧）；每节点重复第 2 步。
  5. 终止：无开放节点 → incumbent 即最优。给出最优性证书一句话："每个叶子均为不可行 / 整数解 / 界 $L\ge U$，故无未探索分支含更优解"。

画树模板：每节点圆圈写「附加约束 | LP 解 | $L$ | 动作(关/剪/分支)」；旁边维护 $U$ 的变化链（$+\infty\to\cdots$）。

T9 · 梯度下降迭代计算

步骤
  1. 求 $\nabla f$（或 1D 的 $f'$），代 $\mathbf{x}_k$ 得梯度值。
  2. 套公式 $\mathbf{x}_{k+1}=\mathbf{x}_k-\alpha\nabla f(\mathbf{x}_k)$，逐步写出每个迭代点及 $f$ 值。
  3. 最优性：解 $\nabla f=0$ 得 $t^*$ 与 $f^*=f(t^*)$（无约束可微凸 = 全局最小证书）。
  4. 步长分析（二次目标 $q=(t-a)^2+c$）：误差每步乘 $(1-2\alpha)$；$|1-2\alpha|<1$ 收敛、$=1$ 振荡、$>1$ 发散。可与具体数列一起写出。
  5. 若给二变量 $F(u,v)$：分别求偏导，写向量更新。

T10 · 凸性判断流程

步骤
  1. 集合？→ 取任意两点看线段（或用已知：$\cap$ 保凸、$\cup$ 不保、仿射像/原像保凸）。
  2. 一元函数？→ 求 $f''$，全区间 $\ge 0$ 即凸（$>0$ 严格凸；变号 = 既非凸也非凹）。
  3. 多元函数？→ 求 Hessian $H$，验证 PSD：$\mathbf{z}^TH\mathbf{z}\ge0$ 或特征值全非负。
  4. 复合结构？→ 非负加权和、仿射复合、取负（凸↔凹）。
  5. 答"是否凸优化"要两个都查：$f$ 凸 + $\mathcal{F}$ 凸（整数约束 → 非凸）。
