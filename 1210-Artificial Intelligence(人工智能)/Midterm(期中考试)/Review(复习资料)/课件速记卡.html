搜索问题形式化 L01–02

  • 四要素：状态空间 S；后继 succ(s)→(action, s′, cost)；初始 s₀；目标测试 Goal(s)。解 = 动作序列
  • 理性 Agent：最大化期望效用；反射式只看当前感知，规划式需转移模型 + 目标
  • PEAS = Performance / Environment / Actuators / Sensors
  • 环境维度：完全/部分可观测、单/多 agent、确定/随机、静态/动态、离散/连续（井字棋 = 完全可观测·确定·静态）
  • 状态空间图：节点 = 状态（唯一）；搜索树：节点 = 路径（同状态可重复出现）

有信息搜索 L04

  • f(n) = g(n) + h(n)；Greedy 按 h，UCS 按 g，A* 按 f
  • 可采纳：0 ≤ h ≤ h*（乐观）；一致 |h(a)−h(b)| ≤ c(a,b) ⟹ 可采纳（更强）
  • A* 必须 dequeue 目标才停（入队时还有更便宜路径可能）
  • 最优性一行：fringe 上最优解 A 的祖先 n 满足 f(n) ≤ g(A) = f(A) < f(B) ⟹ A 先出
  • h = 0 ⟹ A* 退化 UCS；h 精确 ⟹ 只扩展最优路径
  • 构造 h：解松弛问题（去约束/加动作）取精确解 = 乐观估计（忽略墙→曼哈顿距离）

CSP L05

  • CSP = (X, D, C)；解 = 满足全部约束的完整赋值；识别问题（路径无关，与规划相对）
  • 约束：一元（直接缩域）/ 二元（约束图）/ 高阶 / 软（偏好→优化）
  • 穷举 O(dⁿ)；布尔 CSP = SAT (NP-complete)
  • 回溯 = DFS + ①每次只赋一个变量（赋值可交换）②边赋边查一致性
  • 状态抽象：N 皇后建模 Qₖ∈{1..N}（每列一皇后）优于 Xᵢⱼ∈{0,1}

  • 弧一致后可能：1 个解 / 多个解 / 0 个解而不知（弧一致 ≠ 有解，仍需回溯框架）

对抗搜索 L07

  • 形式化 (S, s₀, Player, A, succ, terminal, utility)；解 = 策略 S→A（非路径）
  • V(s) = max / min / 已知（终态）；零和：一方效用 = 另一方负值
  • Minimax：时间 O(bᵐ)，空间 O(bm)；对完美对手最优

α-β 剪枝 L07 · Q3

  • α = MAX 已保证的最好值（下界）；β = MIN 已保证（上界）；根起 (−∞,+∞)
  • MIN 节点 v ≤ α ⟹ 剪；MAX 节点 v ≥ β ⟹ 剪（先测试后更新窗口）
  • 根值不变；中间节点值可能错（含根的孩子）→ 不能直接做动作选择
  • 剪枝依赖顺序：MAX 先看大、MIN 先看小；完美排序 O(b^(m/2)) = 深度翻倍
  • 深度受限：eval 替代终局效用；失去最优保证（horizon effect）；迭代加深 = anytime

Expectimax L08

  • 机会节点 v = Σ pᵢvᵢ；MAX 层照旧；Expectiminimax = max/min/chance 交替（双陆棋）
  • 机会节点不能剪枝（未见孩子可任意大/小）；效用有界 [lo,hi] 才可估上界剪
  • minimax 只需效用序（单调变换不敏感）；expectimax 需要数值大小（平方可翻转决策）
  • MEU 最大期望效用原理；vNM 定理：理性偏好 ⟺ 存在效用函数
  • 把对抗当随机 = 危险乐观；把随机当最坏 = 危险悲观（对随机鬼 expectimax>minimax，对对抗鬼反之）

线性规划 L09 · Q5

  • min cᵀx s.t. Ax ≤ b（不等式形）；Ax = b, x ≥ 0（标准式，加松弛变量）
  • LP = 线性目标 + 线性约束 + 连续变量；可行域 = 凸多面体
  • 顶点定理：有界可行域必有顶点最优；顶点 = n 条独立约束取等联立 → 解方程组 → 代回全部约束验证
  • 等值线 cᵀx = k 一族平行线，c ⊥ 等值线指向代价增大 → 沿 −c 平移找最小
  • 三结局：有限最优 / 不可行 / 无界；可行域无界 ≠ 目标无界
  • 算法概念：单纯形（顶点间移动）、内点法；考试用图解 + 顶点枚举

整数规划 L10 · 新增

模型变量域
LP / ILP / Binary / MILPR / 全整数 Z / {0,1} / 部分整数
  • 松弛：P_IP ⊆ P_LP ⟹ z*_LP ≤ z*_IP（min 时 LP 是下界）
  • LP 最优点恰为整数坐标 ⟹ 即 IP 最优（可行且达下界）
  • rounding 可失败：LP (3.8,3) 舍入 (4,3) 不可行；可行舍入 (4,2)=−4 也非最优（真最优 (2,2)=−6）
  • 类比 A*：节点 LP 界 ≈ 乐观估计，用于排除分支

分支定界 B&B L10 · Q 大题

  • L = 节点 LP 松弛值（下界）；U = incumbent（迄今最优整数解）目标值，初始 +∞
  • 分支：分数变量 xᵢ* → xᵢ ≤ ⌊xᵢ*⌋ 或 xᵢ ≥ ⌈xᵢ*⌉（3.8 → ≤3 / ≥4）；孩子继承全部祖先约束
  • 三种关闭：① LP 不可行 ② LP 解整数（更好则更新 U）③ L ≥ U 剪枝
  • 不能停在第一个整数解（−4 后来改进到 −6）
  • 终止证书：每叶子 = 不可行 / 整数 / 界剪 ⟹ incumbent 最优

优化建模 L11

  • min_{x∈F} f(x)：决策变量（选什么）vs 数据（给定）；argmin = 解集，f* = 最优值
  • 三结局：取得 / 无界 / 不可行；argmin f = argmax(−f)，g* = −f*
  • TSP：x = 排列，f = Σd(xₖ,xₖ₊₁) + d(xₙ,x₁)（闭合边别漏）
  • 8 皇后 = 可行性问题：xᵢ≠xⱼ 且 |xᵢ−xⱼ|≠|i−j|，f ≡ 0
  • 拟合：L₁ = Σ|yᵢ−axᵢ|（最优可为区间）vs L₂ = Σ(yᵢ−axᵢ)²（唯一）；a* = Σxᵢyᵢ/Σxᵢ²
  • 先定单位再建模（8oz 一份 → amount = 8n）

梯度下降 L12 · 新增

  • xₖ₊₁ = xₖ − αₖ∇f(xₖ)；∇f = 最速上升方向 → 负梯度 = 下降方向
  • 二次目标 (t−a)²：误差每步 ×(1−2α)；|1−2α| < 1 ⟺ 0 < α < 1 收敛；= 1 振荡；> 1 发散
  • 课件例：q=(t−2)²+1, t₀=0, α=¼：q′=2(t−2)，t₁=1, t₂=3/2 → t*=2, q*=1
  • 无约束可微凸：∇f = 0 = 全局最小证书；停机：梯度范数 / 目标变化 / 迭代上限
  • 更新量小 ≠ 收敛（可能步长小）；投影梯度下降不考

考试约定（模拟卷原话，答题必须遵守）

  • 树搜索：同状态不同路径分开保留；再 visit 就再写；visit = 出队/出栈那一刻做目标测试（生成时不做）
  • 平局：先按端点字母序，同字母按先入队
  • IDS：限深从 0 起；cutoff 节点 visit 计数；孩子按字母序
  • "Path length" = 总边代价（非边数）｜ Expand = 生成后继（visit at limit ≠ expand）
  • FC 只改新赋值变量的未赋值邻居域
  • α-β：左到右探索，α ≥ β 即剪（含等号）；剪后返回的是界不必真值
  • 区间 [start, end)：back-to-back 不算重叠
  • LP：含 x,y ≥ 0，变量视作连续；超出绘图窗口的可行域用箭头标出
  • 猜错倒扣（正式考试）；歧义题自行补假设并明确写出；冗长扣分——先想后写
