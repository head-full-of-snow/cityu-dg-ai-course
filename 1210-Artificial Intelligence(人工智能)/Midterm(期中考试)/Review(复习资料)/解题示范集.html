D1 · BFS 与迭代加深 IDS 追踪L03 · 模拟卷 Q2a 型
例题（示范数据）：无向图边：S–A=2，S–B=4，A–C=3，A–G=9，B–C=2，C–G=4。起点 S，目标 G。 按模拟卷约定：树搜索（不同路径分开保留，visit 时重复照写）；visit = 出队/出栈那一刻，目标测试在 visit 时做；生成孩子时排除父节点；孩子按字母序探索；IDS 深度限制从 0 起，cutoff 节点的 visit 也要数。
解：BFS（队列，FIFO）
步Visit入队（按字母序）队列快照
1SA, B[A, B]
2AC, G[B, C, G]
3BC（重复也入队）[C, G, C]
4C（经 A）B, G[G, C, B, G]
5G ✔目标，停——
Visit 序：S, A, B, C, G。沿父指针回溯：解路径 S–A–G（2 条边，边代价 11）。
解：IDS（限深 DFS，L = 0,1,2,…）
限深 Lvisit 序说明
0S深度即达限制 → cutoff（仍算 visit）
1S, A, BS 扩展；A、B 深度 1 = cutoff
2S, A, C, G ✔S→A（扩展）→A 的孩子 C(cutoff visit)、G(visit→目标测试→停)
合并 visit 序：S, A, B, S, A, C, G。解路径 S–A–G（深度 2，最优深度）。
注意 L=2 内 A 的孩子按字母序 C 先于 G：C 被 visit（cutoff，不扩展），随后 G 被 visit → 命中目标。若目标藏在更深的字母序靠前分支，需继续加大 L。
要点：① BFS/IDS 以边数最优（返回 S–A–G，2 边），不管边代价（11）；代价最优见 D2 的 UCS/A*（S–A–C–G，代价 9）——两类算法的"最优"含义不同，答题时点明。② cutoff visit 计数是常见丢分点。③ "path length"=总边代价，不是边数。

D3 · 可采纳启发函数组合判定L04 · 模拟卷 Q1b 型
例题：f(s), g(s), h(s) 均可采纳（admissible：0 ≤ h ≤ h*）。判定下列哪些仍保证可采纳：(1) f+g+h；(2) f/3+g/3+h/3；(3) f/6+g/3+h/2；(4) f·g·h；(5) min(f,g,h)；(6) max(f,g,h)。
判定工具
  • 凸组合规则：若 Σwᵢ = 1 且 wᵢ ≥ 0，则 h = Σwᵢhᵢ 可采纳。证明一行：每个 hᵢ ≤ h* ⟹ Σwᵢhᵢ ≤ Σwᵢh* = h*；非负性显然。
  • min / max 规则：min ≤ 某个 hᵢ ≤ h*；max = 某个 hᵢ ≤ h*（max 恰取到某一个，而那个 ≤ h*）。两者均可采纳。
  • 反例构造法（证"不保证"）：取 h*=2，f=g=h=2 代入。
逐项：
选项判定理由 / 反例
f+g+h✗权重和=3≠1；反例 2+2+2=6 > 2
f/3+g/3+h/3✓凸组合（1/3+1/3+1/3=1）
f/6+g/3+h/2✓凸组合（1/6+2/6+3/6=1）
f·g·h✗反例 2×2×2=8 > 2（均大于 1 的数相乘会爆）
min(f,g,h)✓min ≤ h*
max(f,g,h)✓max 是三者之一，该值 ≤ h*
要点：① "guaranteed"类题目证 ✓ 要一般证明、证 ✗ 只要一个反例；② 常见陷阱：max 看起来"激进"，但它只是取到某一个可采纳函数，所以仍 ≤ h*；乘积才是爆掉的那个。③ 一致性（consistent，|h(a)−h(b)| ≤ c(a,b)）是更强性质：可采纳 ⊅ 一致；一致 ⟹ 可采纳。
D4 · CSP：回溯 + MRV + Forward Checking + AC-3L05–06 · 模拟卷 Q1c/Q4 型
例题（澳大利亚地图着色，课件 L05–06 原例）：变量 {WA, NT, SA, Q, NSW, V, T}，域 {r, g, b}，相邻不同色。邻接（9 条边）：WA–NT, WA–SA, NT–SA, NT–Q, SA–Q, SA–NSW, SA–V, Q–NSW, NSW–V；T 无邻接。
解 1：回溯 + MRV + Forward Checking 全程
步赋值（MRV 选变量）FC 域收缩（只改未赋值邻居）各域快照（未赋值变量）
1WA = rNT, SA 各删 rNT{g,b}, SA{g,b}, Q{rgb}, NSW{rgb}, V{rgb}, T{rgb}
2NT = g（MRV：NT/SA 并列 2 值，字母序取 NT）SA 删 g；Q 删 gSA{b}, Q{r,b}, NSW{rgb}, V{rgb}, T{rgb}
3SA = b（MRV：只剩 1 值）Q, NSW, V 各删 bQ{r}, NSW{r,g}, V{r,g}, T{rgb}
4Q = r（MRV：1 值）NSW 删 rNSW{g}, V{r,g}, T{rgb}
5NSW = g（1 值）V 删 gV{r}, T{rgb}
6V = r；T = r（T 无约束，任取）—完成 ✔
解：WA=r, NT=g, SA=b, Q=r, NSW=g, V=r, T=r。逐边验证 9 条不等约束全部满足。
解 2：AC-3 单弧执行示范（在 WA=r, NT=g 已赋值后）
弧 X→Y 一致 ⟺ X 域中每个 x，在 Y 域中存在 y 使 (x,y) 满足约束；不满足的 x 从尾 X 删除；X 有删减 ⟺ 邻居弧 (Xₖ, X) 重新入队。
取弧 Q→SA（此时 Q{r,b}，SA{b}，约束 ≠）：r≠b 有支撑 ✓ 保留；b≠b 无支撑 ✗ 删 b → Q{r}。因 Q 的域变了，(NT,Q)、(NSW,Q)、(SA,Q) 重新入队检查。
对比 FC：FC 只在赋值后改未赋值邻居的域；AC-3 还能传播"域与域之间"的矛盾（如课件例：NT 和 SA 都只剩 blue 时，FC 察觉不到，AC-3 能删空一个域报错）。AC-3 复杂度 O(n²d³)；弧一致后仍可能无解（不保证有解，也不保证解唯一）。
要点：① MRV = 最少剩余值（fail-fast）选变量；LCV = 最少约束值选值（留余地给邻居）——两者方向相反，别混；② 模拟卷约定"FC 只改新赋值变量的未赋值邻居"——非邻居、已赋值变量都不改（Q1c 陷阱：A、B 都赋值后，FC for B 不再动 A 的域）；③ 域被删空 = 立即回溯。
D5 · Minimax 填值 + α-β 剪枝全过程L07 · 模拟卷 Q3 型
例题：根为 MAX，三个 MIN 子节点，叶值从左到右：MIN₁=[3, 12, 8]，MIN₂=[2, 4, 6]，MIN₃=[14, 5, 2]。约定：从左到右探索；α ≥ β 即剪（含等号）；剪枝后返回的是"界"不必写真值。
解 (a)：minimax 值（自底向上） 
                 ROOT (MAX) = 3
        ┌──────────┼──────────┐
      MIN₁       MIN₂       MIN₃
      = 3        = 2         = 2
   ┌──┴──┐    ┌──┴──┐     ┌──┴──┐
   3    12    2     4     14    5    2   （MIN₂ 三叶、MIN₃ 三叶）
MIN₁ = min(3,12,8) = 3；MIN₂ = min(2,4,6) = 2；MIN₃ = min(14,5,2) = 2；ROOT = max(3,2,2) = 3。七个内部值（含根）全填。
解 (b)：α-β（窗口写在节点旁：α | β） 
根 (α=-∞, β=+∞)
├─ MIN₁ (α=-∞, β=+∞)：看叶 3 → β=min(+∞,3)=3；看 12 → β 仍 3；看 8 → β 仍 3
│   返回 3 → 根 α = max(-∞, 3) = 3   ← 这个 3 是后面所有 MIN 的"砍刀"
├─ MIN₂ (α=3, β=+∞)：看叶 2 → v=2 ≤ α=3 → 立即剪掉剩余两叶(4, 6)，返回界 2
└─ MIN₃ (α=3, β=+∞)：看 14 → β=14；看 5 → β=5；看 2 → β=2（无剪，2 > 3 不成立…）
    返回 2 → 根 α 不变（max(3,2)=3）
最终根值 = 3，与 (a) 相同 ✔（α-β 不改变根值）
未探索叶子：2 个（MIN₂ 的 4 和 6）
规则原文：MAX 节点每看完一个孩子，若 v ≥ β 立即返回，否则 α ← max(α, v)；MIN 节点若 v ≤ α 立即返回，否则 β ← min(β, v)。窗口由父辈传入：子节点初始窗口 = 父的 (α, β)。
解 (c)：更优的孩子顺序：原则 MAX 先看大的、MIN 先看小的。把 MIN₃ 的叶序改为 [2, 5, 14]：看 2 → v=2 ≤ α=3 → 第一叶后就剪掉 (5, 14)。加上 MIN₂ 原有 2 个，未探索叶共 4 个 > (b) 的 2 个——好顺序显著增加剪枝。（若再把根的孩子按 (a) 值降序排 3,2,2，效果相同。）
要点：① 每个节点旁写 (α, β) 窗口是给过程分的最好方式；② 剪枝后返回值可以只是界（题目明说 bounds need not be identical）——阅卷看过程；③ 被剪的枝画斜线、未探索叶涂阴影并数出个数；④ 验证：根值与纯 minimax 一致。
D6 · Expectimax（期望最大值，防考）L08 · 模拟卷未直接考
例题：根为 MAX；左孩子为机会节点（chance，概率各 1/2，叶 [2, 6]）；右孩子为机会节点（概率各 1/2，叶 [5, 1]）。求根值。
解： 
              MAX = 4
        ┌────────┴────────┐
   chance×0.5         chance×0.5
   = (2+6)/2 = 4     = (5+1)/2 = 3
   ┌─┴─┐             ┌─┴─┐
   2   6             5   1
机会节点取期望（加权平均），MAX 层照常取 max。根值 = max(4, 3) = 4。
要点：① 机会节点不能剪枝：右边看到 5 时不能像 MIN 那样砍掉 1——期望还可能被拉低/拉高，除非概率为 0；② 区分三层算子：MAX 取 max，MIN 取 min，chance 取 Σp·v；③ expectiminimax（混合层）同理逐层换算子；④ 深度受限时叶用评估函数值。
D7 · LP：建模 + 顶点枚举图解法L09 · 模拟卷 Q5 型
例题：两种食物 X（¥4/单位）、Y（¥3/单位）。营养约束：A: x+y ≥ 4；B: 2x+y ≥ 6；C: x+6y ≥ 12；x, y ≥ 0。求 min 4x+3y。
解：顶点枚举法（课件"Finding a Vertex"方法：每条约束边界取等式，两两联立 → 解出交点 → 代回全部约束验证）
交点来源联立求解验证其余约束可行?目标 4x+3y
A ∩ B(2, 2)C: 2+12=14 ≥ 12 ✓✓14 ← 最优
A ∩ C(2.4, 1.6)B: 4.8+1.6=6.4 ≥ 6 ✓✓14.4
B ∩ C(24/11, 18/11)A: 42/11 ≈ 3.8 < 4 ✗舍弃—
x=0 轴(0, 6)A ✓ B ✓ C: 36 ≥ 12 ✓✓18
y=0 轴(12, 0)A ✓ B ✓ C ✓✓48
全部为 ≥ 约束 ⟹ 可行域在三条线上方，无上界（向右上方开放，图上用箭头标出超出窗口部分）。等值线 4x+3y=k 沿 −c=(−4,−3) 方向平移，最后触点 = 顶点 (2,2)。
最优解 x* = (2, 2)，z* = 4(2)+3(2) = 14（代回三条约束：4 ✓ / 6 ✓ / 14 ✓ 全部达标）
要点：① 交点必须代回所有约束（B∩C 交点掉队是本例考点）；② n 个变量取 n 条独立约束边界联立（课件记号 A_I x = b_I）；③ 无界域别慌——最优点仍在顶点，答题时说明"沿无界方向目标增加"；④ 坐标轴 x,y≥0 也是约束边界，别漏轴上顶点；⑤ 建模套路：决策变量→单位统一→每营养素一行"含量×数量 ≥/≤ 需求"→目标为价格和。
D8 · 整数规划：分支定界全流程（课件 L10 原例）L10 · 今年新增考点
例题（课件原数值）：min x − 4y（整数规划，x, y ∈ Z≥0；约束含 5x+10y ≤ 49 等）。LP 松弛最优 (3.8, 3)，值 −8.2。
规则框
  • 节点下界 L = 该节点 LP 松弛最优值；U = 当前最优整数解（incumbent）的目标值，初始 +∞。
  • 分支：取分数变量 xᵢ*，分 xᵢ ≤ ⌊xᵢ*⌋ 与 xᵢ ≥ ⌈xᵢ*⌉（如 3.8 → ≤3 或 ≥4）；两子树覆盖全部整数解且都不含当前分数点。
  • 三种关闭节点：① LP 不可行；② LP 解已是整数（更好则更新 U）；③ L ≥ U（剪枝：该子树不可能改进 incumbent）。
  • LP 松弛是下界：整数可行集 ⊆ LP 可行集 ⟹ z*_LP ≤ z*_IP。
完整搜索表（课件数值，逐节点核对过）
节点（继承约束）LP 解L动作
根(3.8, 3)−8.2分数 → 分支 x≤3 / x≥4，先探 x≥4
x ≥ 4(4, 2.9)−7.6y 分数 → 分支 y≤2 / y≥3
　x≥4, y≤2(4, 2)−4整数 → incumbent U=−4
　x≥4, y≥3——不可行 → 关闭
x ≤ 3(3, 2.6)−7.4y 分数 → 分支（进入时 U=−4）
　x≤3, y≥3——不可行 → 关闭
　x≤3, y≤2(1.8, 2)−6.2x 分数 → 分支 x≤1 / x≥2
　　x≤3, y≤2, x≥2(2, 2)−6整数且 −6 < −4 → 更新 U=−6
　　x≤3, y≤2, x≤1(1, 1.6)−5.4L=−5.4 ≥ U=−6 → 剪枝
最优证书：x* = (2, 2)，z*_IP = 2 − 4(2) = −6；所有叶子均已关闭（不可行 / 整数 / 被界剪掉）⟹ 无未探索分支能含更优解。
要点：① 不能在第一个整数解就停（−4 后来改进到 −6）；② 剪枝判断写成不等式（−5.4 ≥ −6）给过程分；③ 为什么 LP 是下界要会一句话证（更大可行集上的 min 不会更大）；④ rounding 不可靠（课件例：LP (3.8,3) 取整 (4,3) 违反 5x+10y≤49 不可行）；⑤ 与 A* 类比：节点 LP 界 ≈ f(n) 的乐观估计，用于排除分支。
D9 · 凸集 / 凸函数判断L12 · 今年新增考点 · Q1d-v 型
例题：(1) 证明 Zⁿ（整数格点）不是凸集；(2) 判断 f(t)=(t−2)²+1、f(x,y)=x²−y² 的凸性；(3) 两个凸集的并/交是否必凸？
解 (1)：取 x=(0,…,0), y=(2,…,0) ∈ Zⁿ，中点 θ=1/2 得 (1,…,0) ∈ Zⁿ？若取 x=(0,0), y=(1,0)：中点 (0.5, 0) ∉ Zⁿ —— 中点不必是整数，违反凸集定义 ⟹ 非凸。 解 (2)：f(t)=(t−2)²+1：f''(t) = 2 > 0 对所有 t ⟹ 凸（且严格凸）。f(x,y)=x²−y²：H = diag(2, −2)，特征值 2 与 −2 一正一负（不定）⟹ 非凸（原点是鞍点）。 对照正例：f(x,y)=x²+2y²：H = diag(2,4) ⪰ 0 ⟹ 凸。 解 (3)：交 ✓（两个凸集的交集仍凸：交集中的线段同时在两个集内）；并 ✗ 不必凸——反例：两个不相交圆盘各自凸，取各一点连线穿过中间空隙。判定工具表：
工具用法
定义法x, y ∈ F, θ∈[0,1] ⟹ θx+(1−θ)y ∈ F
二阶导（1 维）f 凸 ⟺ f'' ≥ 0（开区间上）

D11 · 优化建模三经典（L11）L11 · 建模题模板
① TSP（旅行商）：数据 d(i,j)；决策 = 访问序 x = (x₁,…,xₙ)（n 城市的排列）；可行域 = 全体排列；
f(x) = Σₖ₌₁ⁿ⁻¹ d(xₖ, xₖ₊₁) + d(xₙ, x₁)　（闭合边回到起点）
② 八皇后（可行性问题）：xᵢ = 第 i 列皇后所在行，xᵢ ∈ {1,…,8}；对每对 i < j：
xᵢ ≠ xⱼ（不同行）　且　|xᵢ − xⱼ| ≠ |i − j|（不同对角线）
"每列一个皇后"已含在表示法里；目标取常量 f ≡ 0——可行即最优。
③ 过原点直线拟合：观测 (1, 2.1), (2, 3.98), (3, 7.0)；决策 = 斜率 a；预测 ŷᵢ = a·xᵢ；残差 eᵢ = yᵢ − a·xᵢ。 平方损失 L₂(a) = Σ(yᵢ − a·xᵢ)²，令导数为零：
a* = Σxᵢyᵢ / Σxᵢ² = (2.1 + 7.96 + 21) / (1 + 4 + 9) = 31.06 / 14 ≈ 2.22
（课件在 a=2 处对比：残差 (0.10, −0.02, 1.00)，L₁(2) = 1.12，L₂(2) = 1.0104——不同损失最优解不同。）
