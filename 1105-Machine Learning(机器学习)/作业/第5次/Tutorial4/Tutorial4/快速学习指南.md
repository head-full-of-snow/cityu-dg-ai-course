## 1. 任务与数据

- **数据集**：Mashable 在线新闻（39,644 篇文章 × 58 个特征），预测分享数 `shares`
- **预处理流水线**（4 步，每步都有考点）：

| 步骤 | 代码 | 为什么要这么做 |
|---|---|---|
| 抽样 | `dataX = dataX[::6]` | 每 6 条取 1 条，加快实验（剩 6,608 条） |
| 划分 | `train_test_split(..., train_size=0.5, random_state=4487)` | 50% 训练 / 50% 测试，固定随机种子保证可复现 |
| 标准化 | `StandardScaler().fit_transform(trainX)` | 各特征均值 0、方差 1 → **权重的大小才有可比性**，也是正则化的前提 |
| 目标变换 | `trainY = log10(trainYo)` | shares 范围跨度极大（长尾分布），取 log 压缩动态范围、更接近正态 |

⚠️ Scaler 只在训练集上 `fit`，测试集只 `transform`（否则信息泄露）。

## 2. 评价指标：MAE（平均绝对误差）

```python
metrics.mean_absolute_error(testY, model.predict(testXn))
```

- 在 **log 空间**计算：AE = 0.27 意味着预测的分享数平均偏离真实值约 10^0.27 ≈ **1.9 倍**（不是差 0.27 次！）
- 回归为什么常用 MAE 而不是分类的 accuracy：回归输出连续值，没有"对/错"只有"差多少"

## 3. 三个线性模型（核心考点）

| 模型 | 损失函数 | 特点 | 本例结果 (train / test AE) |
|---|---|---|---|
| OLS 普通最小二乘 | $\sum(y-\hat y)^2$ | 无正则化；**特征共线性 → 系数爆炸** | 0.287 / **187.4** 💥 |
| Ridge 岭回归 (L2) | $\sum(y-\hat y)^2 + \alpha\|w\|_2^2$ | 权重整体收缩 → 抗共线性 | 0.289 / **0.285** ✅ |
| LASSO (L1) | $\sum(y-\hat y)^2 + \alpha\|w\|_1$ | 稀疏解 → **自动特征选择** | 0.290 / 0.285 |

**必会解释的两个现象：**

1. **为什么 OLS 训练误差最低、测试误差却是 187？**
   数据里有很多强相关特征（如 `n_unique_tokens` / `n_non_stop_words` / `n_non_stop_unique_tokens`；`rate_positive_words + rate_negative_words ≈ 1`）。OLS 会学出一堆**巨大且符号相反、彼此抵消**的权重：训练集上抵消得很好，测试集上微小差异被放大成离谱预测。这就是**高方差/过拟合**；Ridge 的 L2 惩罚把权重压小，用一点偏差换掉大量方差。
2. **L1 为什么能选特征、L2 不能？**
   L1 约束的等高线是菱形，最优解容易落在坐标轴上 → 系数恰好为 0；L2 约束是圆形，只会把系数**压小但压不为 0**。本例 LASSO 把 58 个特征压到 35 个非零。

**超参数选择**：`RidgeCV(alphas=..., cv=5)` / `LassoCV(...)` —— 在**训练集内部**做 5 折交叉验证选 α，测试集只在最后评估一次。

## 4. 非线性模型（第 3 节）

| 模型 | 核心思想 | 关键超参数 | 本例 test AE |
|---|---|---|---|
| KRR-rbf 核岭回归 | 核技巧把特征映射到高维空间再做岭回归 | α（正则）、γ（核宽度） | 0.281 |
| SVR 支持向量回归 | **ε-不敏感损失**：误差 < ε 完全不罚 → 只关心支持向量 | C、γ、ε、kernel | **0.272** 🏆 |
| 随机森林 | 多棵决策树平均 | n_estimators、max_depth | 0.285 |
| LASSO + 多项式特征 | 显式构造 2 次特征（58→1770 维）再用 LASSO 筛 | degree | 0.285 |

**SVR 夺冠的三个原因**（文字题答案要点）：
1. RBF 核捕捉**平滑非线性关系**（CV 选了小 γ=0.001 → 函数平滑不过拟合）
2. ε-不敏感损失**对噪声鲁棒**（分享数噪声很大，小于 0.1 的误差直接忽略）
3. C 控制拟合 vs 平滑的平衡（⚠️ C 太大 → 每个点都要拟合 → 过拟合，课件特意提醒）

**随机森林的教训**：`max_depth=None` 时 train AE 0.109 ≪ test AE 0.285 → 典型过拟合，树深不限制就是死记硬背训练集。

**LASSO-poly 的启示**：多项式特征没带来提升 → 数据里**缺少有用的高阶交互结构**，收益主要来自"平滑非线性"，正是 RBF 核擅长的。

## 5. 结果总览（背这张表就够）

```
SVR-rbf 0.272 < SVR-poly 0.281 ≈ KRR-rbf 0.281 < RF 0.285 ≈ las-poly 0.285
≈ LASSO 0.285 ≈ Ridge 0.285 ≪≪≪ OLS 187  (全部为 test AE)
```

**一句话结论**：正则化的线性模型 ≈ 0.285 是基线；平滑非线性（SVR-rbf）小幅提升到 0.272；无正则化的 OLS 完全不可用。

## 7. 高频问答（考试/答辩向）

| 问题 | 答题要点 |
|---|---|
| 为什么要对 y 取 log？ | 长尾分布 → 压缩动态范围，让误差度量不被极端值主导 |
| 为什么要标准化？ | 权重可比 + 正则化公平惩罚各特征 + 核方法/距离计算的数值稳定 |
| OLS 什么时候失效？ | 特征共线性（n_features 多且相关）、样本少 → 方差爆炸 |
| Ridge vs LASSO 怎么选？ | 要可解释/特征筛选 → LASSO；只要稳定预测 → Ridge；特征强相关时 LASSO 会随机挑一个 |
| 过拟合怎么判断和解决？ | train ≪ test 差距大；解决：正则化、限制模型复杂度、更多数据、CV 选超参 |
| SVR 的 ε 和 C 各管什么？ | ε 管"多小的误差忽略"（管噪声）；C 管"违反 ε 的惩罚强度"（管拟合程度） |
| 为什么 CV 只用训练集？ | 测试集代表未见过数据，只能在最终评估用一次，否则信息泄露导致高估 |
