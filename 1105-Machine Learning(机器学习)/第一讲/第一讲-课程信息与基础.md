### 课程摘要

本课程的目的是向学生介绍机器学习领域

- 机器学习算法使计算机能够自动学习从经验数据（如文本和网页文档、声音、图像和视频）中识别复杂模式
- 本课程旨在从理论和实践两方面对机器学习进行广泛概述，重点是将其应用于解决实际问题
- 课程结束时，学生将对机器学习算法有数学和实践经验

因此，在某些情况下，你可能感觉像是在上数学课。如果你在跟上课程方面有困难，应该在加退选期间退出。不允许延迟退选。

### 学习的定义

- **行为主义**（斯金纳，1900-1950）：学习是由于经验而导致的行为的长期变化
- **认知主义**（格式塔学派，1920-）：学习是将新信息整合到已有心理框架中并随时间更新这些框架的内部心理过程
- **连接主义**（赫布，1949）：学习是神经元通过发展突触连接而结合的物理过程

### 机器学习的观点

- **萨缪尔（1959）**："机器学习是一个让计算机具有无需显式编程就能学习能力的研究领域"

- **乔丹（2015）**："它是当今发展最快的技术领域之一，位于计算机科学和统计学的交叉点，也是人工智能和数据科学的核心"

### 米切尔的观点

### 线性代数

#### 定义：向量空间

实向量空间R^N是元素x = [x_1, ..., x_N]^T的集合，其中每个x_j ∈ R。元素x称为向量，它们满足以下性质：

**加法**：如果x ∈ R^N且y ∈ R^N，则
x + y = [x_1 + y_1, ..., x_N + y_N]^T ∈ R^N

**标量积**：如果x ∈ R^N且a ∈ R，则
ax = [ax_1, ..., ax_N]^T ∈ R^N

**内积**：如果x ∈ R^N且y ∈ R^N，则x^Ty = Σ_{j=1}^N x_j y_j

### 线性代数

#### 定义：矩阵

矩阵X ∈ R^{M×N}支持以下运算：

**加法**：如果X ∈ R^{M×N}, Y ∈ R^{M×N}且Z = X + Y，则
Z ∈ R^{M×N}且z_ij = x_ij + y_ij

**标量积**：如果X ∈ R^{M×N}, a ∈ R且Z = aX，则
Z ∈ R^{M×N}且z_ij = ax_ij

**矩阵乘法**：如果X ∈ R^{M×N}, Y ∈ R^{N×C}且Z = XY，则
Z ∈ R^{M×C}且z_ij = Σ_{k=1}^N x_ik y_kj

你应该熟悉基本矩阵类型（方阵、对角矩阵、单位矩阵）、基本矩阵运算（转置、逆、迹等）以及矩阵概念（特征值、正交性等）。

### 概率

#### 定义：概率分布

样本空间Ω上的概率分布p是从Ω的元素/子集到实数的函数，满足以下条件：

- **非负性**：p(A) ≥ 0，对所有A ⊆ Ω
- **归一化**：p(Ω) = 1
- **可加性**：对于所有互不相交的A, B ⊆ Ω，
p(A ∪ B) = p(A) + p(B)

### 随机变量

#### 定义：随机变量

随机变量X由函数f_X定义，该函数将样本空间Ω的每个元素ω映射到集合X中的值x = f_X(ω)（称为随机变量的值域）

对于每个x ∈ X，事件{X = x}指的是样本空间的子集{ω ∈ Ω | f_X(ω) = x}

对于每个x ∈ X，概率p(X = x) = p({ω ∈ Ω | f_X(ω) = x})

### 概率与随机变量

我们也可以直接为值域为X的随机变量X指定概率分布，而不是通过底层样本空间Ω。必须满足以下条件：

- 离散概率质量函数：
  p(X = x) ≥ 0 对所有x ∈ X，且Σ_{x∈X} p(X = x) = 1
- 连续概率密度函数：
  p(X = x) ≥ 0 对所有x ∈ X，且∫_X p(X = x)dx = 1
