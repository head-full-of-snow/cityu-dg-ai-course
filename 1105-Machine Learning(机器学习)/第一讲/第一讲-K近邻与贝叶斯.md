## K近邻（KNN）分类

KNN分类器是机器学习中最简单但最重要的分类器之一

它存储训练集 D，并对每个新实例 x 使用其 K 个最近邻（索引为 Nₖ(x) ⊂ {1, ..., M}）进行多数投票来分类

使用 KNN 需要选择距离函数 d : ℝᴺ × ℝᴺ → ℝ 和邻居数量 K

---

## 最大值与取最大坐标

**最大值算子**

对于定义在 x ∈ D 上的函数 f(x)，最大值算子返回函数的最大值：

max f(x) = {f(x) | x ∈ D 且 ∀y ∈ D, f(y) ≥ f(x)}
  x∈D

**取最大坐标算子**

对于定义在 x ∈ D 上的函数 f(x)，取最大坐标算子给出使 f(x) 达到最大值的点集：

argmax f(x) = {x | x ∈ D 且 ∀y ∈ D, f(y) ≤ f(x)}
   x∈D

---

## KNN分类

**KNN分类函数**

f_KNN(x) = argmax Σ I[y⁽ⁱ⁾ = c]
                c∈{1,...,C} i∈Nₖ(x)

---

## 距离函数

通常，KNN 可以与任何满足非负性 d(x, x) ≥ 0 和不可区分性同一性 d(x, x) = 0 的距离函数配合使用

一般来说，距离函数的结构越多（对称性、三角不等式），在设计算法时可以利用的结构就越多

---

## 距离度量

**定义：闵可夫斯基距离（p-范数）**

给定两个数据向量 x, x' ∈ ℝᴺ，带参数 p 的闵可夫斯基距离（p-范数）是一个合适的度量，定义如下：

d_p(x, x') = ||x - x'||ₚ = (Σ |xⱼ - x'ⱼ|ᵖ)^(1/p)
                              j=1

特殊情况包括欧几里得距离（p = 2）、曼哈顿距离（p = 1）和切比雪夫距离（p = ∞）

---

## 暴力法KNN

对于任意距离函数 d，暴力法 KNN 的工作原理是：
计算从目标点 x 到所有训练点 x⁽ⁱ⁾ 的距离 dᵢ = d(x⁽ⁱ⁾, x)

对距离 {dᵢ, i = 1, ..., M} 排序，选择 K 个最小距离的数据案例形成邻居索引集 Nₖ(x)

一旦选定了 K 个邻居，应用分类规则就很容易了

---

## KNN变体

与在多数投票中给所有 K 个邻居相等的权重不同，可以使用距离加权的多数投票：

f_KNN(x) = argmax Σ wᵢ I[y⁽ⁱ⁾ = c]
                c∈{1,...,C} i∈Nₖ(x)

           其中 wᵢ = exp(-dᵢ)

除了暴力法最近邻搜索，还可以在训练数据上构建如 K-d 树这样的数据结构，以更低的计算成本支持最近邻搜索

---

## KNN权衡

**优点：**
- 不涉及训练期（即惰性学习），并且可以无缝添加新数据而无需重新训练模型
- 当数据趋于无穷大时，会收敛到正确的决策面

**缺点：**
- 不适用于大型数据集。由于 KNN 需要存储所有训练数据，执行邻居搜索需要大量内存和花费大量时间
- 不适用于高维数据。KNN 很难计算每个维度的距离。此外，在高维空间中一切都相互远离（即所谓的"维度灾难"）

## 概率分类器

代表一类对数据进行建模的分类器

使用概率分布（即生成分布）对数据生成方式进行建模

定义生成分类模型：
- 世界上的对象/模式属于不同类别
- 观察者从对象/模式测量特征/观察
- 每类对象/模式都有特定的（可能不同的）特征分布

---

## 类别模型

可能的类别是 Y
- 例如，在鸢尾花数据集中，Y = {"versicolor", "virginica"}，或更一般地，Y = {1, 2}

在现实世界中，类别 y 发生的频率由概率分布 p(y) 给出

p(y) 称为先验分布

**示例：**
p(y = 1) = 0.4 且 p(y = 2) = 0.6
这意味着在鸢尾花世界中，40% 属于类别 1（versicolor），60% 属于类别 2（virginica）

从训练数据中估计：

p(y = c) = (1/M) Σ I[y⁽ⁱ⁾ = c]，c ∈ {1, 2}
            i=1

---

## 观察模型

我们测量/观察一个特征向量 x
特征的取值取决于类别

观察按照分布 p(x|y) 绘制
p(x|y) 称为类别条件分布
它表示给定对象属于类别 y 时，观察到特定特征向量 x 的概率

从训练数据中估计：
在鸢尾花数据集中，我们为每个类别绘制"瓣长"特征的直方图

## 高斯分布

每个类别都被建模为特征值的单独高斯分布

p(x|y = c; μ_c, σ_c²) = (1/√(2πσ_c²)) exp(-(x-μ_c)²/(2σ_c²))

每个类别有自己的均值和方差参数 (μ_c, σ_c²)

---

## 从数据学习参数

**最大似然估计（MLE）**
- 设置参数 (μ_c, σ_c²) 以最大化类别 c 的样本的似然（概率）
- 设 D_c = {x⁽ⁱ⁾, y⁽ⁱ⁾}ᵢᴹ=c₁ 为类别 c 的数据（即 y⁽ⁱ⁾ = c）：

(μ̂_c, σ̂_c²) = argmax Σ log p(x⁽ⁱ⁾|y⁽ⁱ⁾; μ_c, σ_c²)
                  μ_c,σ_c² i=1

上述目标是观察数据的对数似然，作为参数 (μ_c, σ_c²) 的函数

**解：**

样本均值：μ̂_c = (1/M_c) Σ x⁽ⁱ⁾
                         i=1

样本方差：σ̂_c² = (1/M_c) Σ (x⁽ⁱ⁾ - μ̂_c)²
                            i=1

## 贝叶斯决策规则

贝叶斯决策规则（BDR）在涉及概率（不确定性）的问题上做出最优决策

- 最小化做出错误预测的概率

**贝叶斯最优分类器**
- 给定一个观察 x，选择具有最大后验概率 p(y = c|x) 的类别 c：

f_B(x) = argmax p(y = c|x)
              c∈{1,...,C}

**示例：**
- 如果 p(y = 1|x) > p(y = 2|x)，则选择类别 1
- 如果 p(y = 1|x) < p(y = 2|x)，则选择类别 2

**问题：** 我们没有 p(y|x)
- 我们只有 p(y) 和 p(x|y)

---

## 贝叶斯规则

后验概率可以使用贝叶斯规则计算：

p(y|x) = p(x|y)p(y) / p(x)

其中分母是 x 的概率：
p(x) = Σ p(x, y) = Σ p(x|y)p(y)
        y∈Y           y∈Y

分母使 p(y|x) 求和为 1

贝叶斯规则：

p(y|x) = p(x|y)p(y) / [p(x|y=1)p(y=1) + p(x|y=2)p(y=2)]

## 决策边界

决策边界是两个后验概率相等的地方

p(y = 1|x) = p(y = 2|x)

---

## 贝叶斯规则再探讨

贝叶斯规则：

p(y|x) = p(x|y)p(y) / p(x)

注意，分母对每个类别 y 是相同的
- 因此，我们可以只比较分子 p(x|y)p(y)
- 这也称为观察和类别的联合似然

p(x, y) = p(x|y)p(y)

**示例：**
使用联合似然的 BDR：

如果 p(x|y=1)p(y=1) > p(x|y=2)p(y=2)，则选择类别 1
否则，选择类别 2

## 贝叶斯规则再探讨

也可以应用严格单调递增函数（如对数）进行比较

使用对数似然：
log p(x|y=1) + log p(y=1) > log p(x|y=2) + log p(y=2)

当似然值很小时，这在数值上更稳定

## 贝叶斯分类器总结

**训练：**

1. 从每个类别收集训练数据
2. 对于每个类别 c，估计类别条件密度 p(x|y = c)：
   - 选择分布形式（例如，高斯）
   - 用 MLE 估计其参数
3. 用 MLE 估计类别先验 p(y)

**分类：**

1. 给定一个新样本 x，计算每个类别 c 的似然 p(x|y = c)
2. 选择具有最大后验概率 p(y = c|x) 的类别 c

等效地，使用 p(x|y = c)p(y = c) 或 log p(x|y = c) + log p(y = c)
