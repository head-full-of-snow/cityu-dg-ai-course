## 回归任务定义与曲线拟合问题

- **回归任务基本形式**
  - 输入为d维特征向量x，输出为实数值响应y，目标是学习从$R^d$到$R$的映射函数f
  - 训练集D包含m个样本对$(x_i, y_i)$，采用均方误差（MSE）作为损失度量
- **曲线拟合四个核心问题**
  - **观测数量影响**：通常越多越好，信息量大的观测能改善估计
  - **观测位置要求**：应覆盖整个输入范围，避免聚集导致部分曲线未被描述，最大曲率点更具几何信息
  - **唯一确定性**：未限定函数类时有限观测不能唯一确定曲线；已知多项式类等特定形式才可能唯一确定
  - **模型选择标准**：需平衡拟合精度与模型复杂度，遵循"尽可能简单但不过分简单"原则
- **Boston房价预测示例**
  - 房间数与房价正相关，低收入人群比例与房价负相关
  - 双特征模型可用颜色编码房价，三维可视化展示预测面

## OLS推导与矩阵形式求解

- **单特征线性回归标量推导**
  - 预测函数$\hat{y} = wx + b$，通过最小化MSE对w和b分别求导并令为零
  - 得到两个线性方程，写成2×2矩阵形式，要求矩阵可逆即行列式非零
  - 可逆条件等价于矩阵满秩（rank=2）
- **多特征矩阵形式与增广表示**
  - 将截距b并入权重向量，特征向量首位补1构成增广表示
  - 数据矩阵X维度为m×(n+1)，每行为一个样本的转置
  - 预测函数写为$\hat{y} = Xw$，训练目标MSE写为$\frac{1}{m}\|y - Xw\|^2$
- **矩阵求导与正规方程**
  - 对w求梯度得$\frac{2}{m}(X^TXw - X^Ty)$，令为零得到正规方程$X^TXw = X^Ty$
  - 当$X^TX$可逆时解唯一，要求rank(X)=n+1
  - 可逆性等价于$X^TX$满秩，即数据矩阵无冗余特征且样本数m≥n+1
- **Mini-batch梯度下降中的维度差异**
  - 全量梯度下降使用$X^TXw$，Mini-batch使用$xx^Tw$
  - 原因在于数据矩阵按行堆叠样本，单样本外积为$xx^T$而非$x^Tx$
  - 当n过大导致$X^TX$计算或求逆不可行时，改用梯度下降

## 概率解释与伪逆解法

- **高斯噪声假设下的MLE等价性**
  - 假设观测噪声$\epsilon \sim N(0, \sigma^2)$且独立同分布
  - 条件响应$y|x \sim N(x^Tw, \sigma^2)$
  - 最大化对数似然等价于最小化平方误差和（非MSE，差常数因子1/m不影响优化）
  - $\sigma^2$的最优估计为目标输出的MSE，可解释为不确定性度量
- **伪逆与不可逆情形处理**
  - $X^\dagger = (X^TX)^{-1}X^T$称为伪逆，是方阵逆到非方阵的推广
  - 当m < n+1（数据少于参数）时$X^TX$不可逆，需增加数据或施加正则化
  - 当m ≥ n+1但仍不可逆时存在冗余特征，可移除冗余或正则化
  - 多解情况下取最小范数解，对应约束优化问题
- **计算可行性考量**
  - 即使$X^TX$理论可逆，n过大时计算代价过高
  - 此时采用梯度下降替代闭式解

## Ridge回归原理与系数收缩

- **正则化三个核心动机**
  - 减少过拟合，抑制过大系数
  - 特征强相关时稳定估计，设计矩阵秩亏时仍保证唯一解
  - 诱导系数向量特定结构（如稀疏性）
- **Shrinkage降低方差的数学解释**
  - 将系数w缩放为aw（a<1），方差变为$a^2Var(w)$，严格减小
  - 以引入偏差为代价换取方差降低
- **Ridge回归优化目标与闭式解**
  - 目标函数：$\frac{1}{2}\|y - Xw\|^2 + \frac{\alpha}{2}\|w\|^2$
  - 前置1/2使求导后系数抵消
  - 闭式解$w^* = (X^TX + \alpha I)^{-1}X^Ty$
  - $\alpha=0$退化为OLS；$\alpha \to \infty$所有系数趋于零
- **$X^TX + \alpha I$恒可逆的正定性证明**
  - 对任意非零向量v，$v^T(X^TX + \alpha I)v = \|Xv\|^2 + \alpha\|v\|^2 > 0$
  - 第一项≥0，第二项α>0时严格>0，故矩阵正定从而可逆
- **系数路径与超参数选择**
  - α增大时各系数绝对值总体趋零，但非单调递减，个别系数可能先升后降
  - 通过交叉验证选择α，保留测试集做最终评估
- **系数解释的注意事项**
  - 系数符号表示条件相关方向（固定其他特征），非因果关系
  - 系数大小依赖特征尺度，归一化后才可比较
  - 高度相关特征的系数分配不唯一（如9/1与0.1/9.9等效），不能据此判断重要性

## Lasso回归与稀疏性机制

- **L1惩罚与稀疏性**
  - 将L2惩罚替换为L1范数$\sum|w_j|$
  - L1惩罚可使部分系数精确为零，实现特征选择
  - 目标凸但一般无闭式解
- **求解算法**
  - Coordinate Descent、近似梯度法
  - Least Angle Regression（LARS）为专用高效算法
- **Orthonormal设计下的闭式解**
  - 当$X^TX = I$时，Lasso系数为OLS系数的Soft-thresholding
  - $w_j^{lasso} = sign(w_j^{OLS}) \cdot max(|w_j^{OLS}| - \alpha, 0)$
  - 当$|w_j^{OLS}| \leq \alpha$时系数精确为零，形成"死区"
  - 该闭式解仅在正交设计下成立，一般情形仍需迭代算法
- **零系数的解释局限**
  - 系数为零不代表特征无信息，仅表示在当前α和数据实现下未被选中
  - 相同特征可能被随机保留其一，结果依赖具体实现

## OLS局限性与课程实践资源

- **OLS对异常值的敏感性**
  - 平方误差放大大残差，异常点主导优化目标
  - 后续课程将介绍鲁棒回归技术，包括识别/剔除异常值及使用绝对误差

- **线性模型的"线性"含义**
  - 指对系数线性，非对原始输入线性
  - 可通过基函数/特征变换映射到高维空间，模型在变换空间线性
