## RANSAC算法流程与迭代次数推导

- **RANSAC内点识别与最大共识集选取**
  - 通过设定阈值（tube）区分管内点与管外点，拒绝离群值后以最大共识集作为训练集拟合模型
  - 示例中三次采样的内点数分别为31、6×88、11，第三次采样得到最大共识集11个点用于最终模型拟合
- **超参数定义与迭代次数公式推导**
  - 模型包含两个超参数：迭代次数t和阈值h
  - 期望成功概率δ定义为至少一次采样全为内点的概率，公式为 $1-(1-q)^t \geq \delta$，其中q为单次采样全内点概率
  - 对不等式两边取对数时，因 $\log(1-q)$ 为负数，除法导致不等号方向反转，最终得到 $t \geq \frac{\log(1-\delta)}{\log(1-q)}$
  - 当固定δ=0.99、异常比例从5%增至50%时，所需迭代次数t随样本量增加而显著上升

## 多项式回归嵌套结构与模型选择

- **多项式特征映射与嵌套定义**
  - p阶多项式回归将一维输入x映射为 $[1, x, x^2, ..., x^p]^T$ 的特征向量，模型对系数仍为线性
  - 嵌套特性指高阶模型包含所有低阶项，若低阶模型最优，高阶模型可通过将高阶项系数置零退化为低阶模型
- **过拟合风险与验证集选择**
  - 训练MSE随阶数增加单调不增，但高阶模型易过拟合，需使用验证集MSE而非训练MSE选择最优阶数
  - Boston Housing数据示例中，以房间数和低收入家庭比例为特征，二阶模型在验证集上表现优于三阶，尽管三阶训练误差更低
- **特征缩放对模型的影响**
  - 特征尺度差异会影响系数可比性及距离计算，正则化模型尤其需要特征缩放以保证惩罚公平

## 核技巧与岭回归对偶形式

- **核函数替代显式特征构造**
  - 核函数 $K(x, x') = \phi(x)^T\phi(x')$ 可直接计算高维空间内积，无需显式构造特征向量
  - 多项式核、RBF核等可使线性模型在原输入空间实现非线性决策
- **岭回归闭式解与对偶等价性**
  - 岭回归原始解为 $w^* = (X^TX + \alpha I)^{-1}X^Ty$，其中单位矩阵维度为 $(n+1) \times (n+1)$
  - 通过对偶推导可得 $w^* = X(X X^T + \alpha I)^{-1}y$，表明最优解位于训练样本的张成空间内
  - 预测表达式 $y^* = x^{*T}w^*$ 可完全用训练样本与新样本的内积表示，从而支持核化
- **矩阵求逆选择原则**
  - 当样本数m小于特征数n时，优先求逆 $m \times m$ 矩阵而非 $(n+1) \times (n+1)$ 矩阵以降低计算成本
  - Assignment3将要求证明上述矩阵恒等式

## SVR目标函数与松弛变量等价性

- **ε-不敏感损失与管状区域**
  - SVR在预测值周围构建宽度为2ε的管，管内误差不计惩罚，仅对超出管的误差施加线性惩罚
  - 该损失函数称为ε-insensitive loss，相比平方损失对离群点更鲁棒
- **松弛变量引入与约束条件**
  - 每个样本引入两个松弛变量ξ_i（上界违规）和ξ_i*（下界违规），分别对应管上方和下方的偏差
  - 约束条件要求ξ_i ≥ 0、ξ_i* ≥ 0，且ξ_i · ξ_i* = 0，即同一数据点不能同时位于管的上下两侧
- **目标函数等价性与对偶核化**
  - 带松弛变量的优化问题与ε-insensitive loss形式等价，通过最小化下界并令松弛变量取其最优值可证
  - 对偶形式仅依赖样本间内积，可替换为核函数实现非线性SVR
  - 超参数C控制正则化与误差权衡，ε控制管宽，均需通过验证集选择

## 回归方法体系总结

- **五类回归方法对比**
  - 普通最小二乘：闭式解 $(X^TX)^{-1}X^Ty$，无正则化
  - 岭回归：L2正则化，闭式解含αI项，减少过拟合
  - Lasso：L1正则化，产生稀疏解，具备特征选择能力
  - 核回归：通过核技巧实现非线性，需计算核矩阵，预测依赖所有训练样本
  - SVR：ε-insensitive loss，对偶形式稀疏（仅支持向量参与预测），可核化
- **预处理与输出变换**
  - 特征缩放对正则化模型至关重要，确保各特征系数可比
  - 目标变量可进行对数等变换以适配模型假设，预测后需逆变换恢复原始尺度

## 无监督学习任务分类与密度估计定位

- **三类无监督学习任务**
  - 聚类：将数据划分为互斥且穷尽的组，如Iris数据集按测量值分为三簇
  - 密度估计：建模数据生成分布，被视为"所有无监督问题之母"，因各类无监督任务均可转化为密度估计
  - 流形嵌入：将高维数据投影至低维空间保持几何结构，如Zip Code Atlas Map保留测地距离而非欧氏距离
- **监督学习与无监督学习的衔接**
  - 监督学习利用标签y提供条件信息，无监督学习仅依赖输入x的结构
  - 条件密度估计可作为半监督学习的桥梁，当部分样本有标签时融合两类信息

## K-means算法机制与初始化改进

- **坐标下降与收敛性质**
  - K-means交替执行分配步（固定中心更新归属）和更新步（固定归属重算中心），每步不增目标函数
  - 目标函数为簇内平方和，算法保证收敛但不保证全局最优，结果依赖初始化
  - 空簇处理：若某簇无样本，保留上一轮中心避免除零错误
- **K-means++初始化策略**
  - 首个中心均匀随机选取，后续中心按与最近已选中心的平方距离成比例的概率采样
  - 该策略使初始中心彼此远离，降低陷入差局部最优的风险
- **K值选择与局限性**
  - 肘部法则：绘制不同K对应的最低簇内平方和，寻找下降速率明显减缓的拐点
  - K-means假设簇为紧凑球形且规模相近，对非球形、尺度差异大或密度不均的数据效果不佳
  - 特征缩放直接影响距离计算，进而改变聚类结果

## GMM软聚类与协方差结构约束

- **GMM作为密度估计与软聚类**
  - GMM将数据建模为K个高斯分量的混合，每个分量由均值μ_j、协方差Σ_j和权重π_j参数化
  - 责任度r_ij表示样本i属于簇j的后验概率，构成软分配，满足 $\sum_j r_{ij} = 1$
- **EM算法与奇异性问题**
  - E步计算责任度，M步以加权方式更新μ_j、Σ_j和π_j，直至似然收敛
  - 若某分量坍缩至单点，方差趋零导致似然无界，需通过协方差约束或正则化避免
- **协方差矩阵的四种约束形式**
  - Full：每个分量独立全协方差矩阵，参数最多，灵活性最高
  - Tied：所有分量共享同一协方差矩阵
  - Diag：协方差为对角阵，主轴与坐标轴对齐
  - Spherical：协方差为标量倍单位阵，各向同性，不同分量可有不同半径
- **GMM与K-means的关系**
  - 当GMM协方差为σ²I且权重相等时，软分配退化为K-means硬分配
  - GMM可学习椭圆形状与方向，适应非球形簇，但对初始化同样敏感
