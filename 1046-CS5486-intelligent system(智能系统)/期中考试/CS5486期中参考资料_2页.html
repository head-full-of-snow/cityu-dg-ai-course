弱项⚠ 易错急救卡（我的丢分点，先看这个）

①收敛定理必须答全三件事：前提 linearly separable ＋ in a finite number of steps（有限次更新）＋ 结果得正确分类的 weights and threshold——漏前提或漏"有限"＝丢分。拼写：boundary（非 boundry）、in a finite number of steps。

②XOR 原因＝not linearly separable（正类两点对角，无直线可分）——绝不是"权重数量/神经元数量不足"！标准句：A single-layer perceptron can only form a linear decision boundary, but the XOR problem is not linearly separable.

③ADALINE 题必说 minimize the MSE：误差基于线性输出 y=wᵀx（非二值输出）；梯度 ≠ 误差函数本身：∇E=−Σₚeₚxₚ，更新用梯度。

④对比题用完整句（主语＋双方＋whereas）：The perceptron updates weights based on classification errors, whereas ADALINE uses gradient descent to minimize the mean squared error.

⑤细节分：η＝learning rate，controls the size of weight updates（别写成 n，n 常是样本数）；batch 更新 Σₚ 别丢。

概念1 · 基础速答

ANN=(ARCH, RULE)；ARCH=(u,v,w,x,y)；RULE=(E,F,G,H,L)：E 评价（误差/能量函数）、F 激活、G 聚合（加权和）、H 输出、L 学习（迭代调 w）。

分类四维度：确定性/随机（F）｜前馈/循环（G,H）｜半线性/高阶（G）｜有监督/无监督（L）。短期记忆＝u,v 快动态；长期记忆＝w 慢动态。

一般增量学习规则：w(t+1)=w(t)+η·r(x,y,d,w)（连续 ẇ=η·r）；一切规则皆为 r 的特例。

M-P 神经元（1943）：{0,1} 二值；权重 ±1；抑制输入=1 ⇒ 输出必 0；否则加权和 ≥θ ⇒ 1。三命题：①任意逻辑函数可由两层 M-P 网实现；②无抑制连接只能实现单调逻辑函数；③任意有限自动机可由 M-P 循环网络模拟。

里程碑：43 M-P｜50s末 Rosenblatt 感知机｜60s Widrow ADALINE｜70s Zadeh 模糊·Grossberg ART·Kohonen SOM｜74 Werbos BP｜82 Hopfield｜86 PDP 推广 BP｜88 Broomhead&Lowe RBF｜90s Vapnik SVM｜06– Hinton DL；2024 诺贝尔物理奖＝Hopfield & Hinton。

推导2 · Perceptron

2.1 输出规则＋线性可分定义

单层自适应阈值逻辑单元前馈网（Rosenblatt，Cornell，1950s 末，首个硬件实现）。y=1 ⟺ u=Σwᵢxᵢ≥θ，否则 0（hard-limit）。

线性可分（课件定义）：存在 n+1 个实权重（含阈值）使一组加权和恒 ≥（>）θ、另一组恒 <θ。有限集线性可分 ⇒ 绝对线性可分。

2.2 学习规则【默写】

仅当 y≠d 才更新：
wᵢ(t+1)=wᵢ(t)+η(d−y)xᵢ；θ(t+1)=θ(t)−η(d−y)
迭代学习（Lippmann）：d=1,y=0 → w←w+ηx, θ←θ−η；d=0,y=1 → w←w−ηx, θ←θ+η；正确不动。

2.3 收敛定理【英文必背】

If two sets of data are linearly separable, the perceptron learning algorithm converges to a set of weights and a threshold in a finite number of steps.

⚠ 三要素答全：前提线性可分＋有限步＋结果含 threshold（急救卡①）。不可分则不收敛（震荡）。

2.4 手推例：AND（η=1, W(0)=0, b=0）

逐样本错才更：6 轮收敛 w=[2,1], b=−3，边界 2x₁+x₂−3=0（四点全对＝零误差区）。陷阱：(0,0) 首轮 y=1≠0 触发更新，但 x=0 ⇒ 权重不变、仅 b 动。

2.5 XOR＋权重空间几何

XOR 非线性可分 ⇒ 单层感知机/ADALINE ✗（⚠ 原因＝非线性可分，不是权重/单元数量不足，急救卡②）；两层感知机、RBF、核SVM ✓。局限：仅线性可分；高维/大样本收敛慢。

m 个样本面切 n 维权空间：区域数＝m 的 n−1 次多项式；1面→2，2→4，3→8，4→最多14。阈值函数 ~O(2n(n−1)) ≪ 逻辑函数 22ⁿ ⇒ learnability 问题（s114 两问：解在权空间是否存在？存在时如何求？——两层可分但缺学习算法）。

bipolar {−1,+1} 优于 unipolar {0,1}：代数结构更好＋权空间可行区域占比更大。

推导3 · ADALINE / LMS

定义：Adaptive Linear Elements（Widrow & Hoff，Stanford，60s 初）：单层线性单元，学习时 y=wᵀx。

LMS 四步推导【默写】

①目标：E(w)=½Σₚ(dₚ−wᵀxₚ)²，eₚ=dₚ−wᵀxₚ

②求导：∇E(w)=−Σₚeₚxₚ（∂E/∂wᵢ=−Σₚeₚxₚᵢ）

③下降 w(t+1)=w(t)−η∇E ⇒ ④批量更新

w(t+1)=w(t)+ηΣₚeₚxₚ；序贯 Delta：Δw=ηex

训练模式（课件）：Perceptron 序贯或 batch 均可；ADALINE 仅 batch。η 过大→震荡，过小→极慢。⚠ 答题必带 minimize the MSE；误差基于线性输出（急救卡③）。

一步数值例：x=[2,1]ᵀ, d=1, w=[0,0], η=0.1 ⇒ y=wᵀx=0, e=d−y=1, Δw=ηex=[0.2,0.1]ᵀ ⇒ w=[0.2,0.1]ᵀ（批量＝Σₚeₚxₚ 累加）。感知机对照：同输入 d=1,y=0 ⇒ w←w+ηx, θ←θ−η（误分类驱动，非梯度）。

推导4 · 多层前馈与 BP

4.1 一句话定义【英文】

Backpropagation (generalized delta rule, PDP 1986; Werbos 1974) is a recursive gradient-descent learning algorithm for multilayer feedforward networks of sigmoid activation functions; it computes error gradients backward from output to input layer to minimize the mean squared error. BP 是算法非结构，≠ recurrent.

4.2 Sigmoid 导数【必背】

单极 σ(s)=1/(1+e⁻ˢ)，σ′=y(1−y)｜双极 σ(s)=tanh s，σ′=1−y²

4.3 三层 delta 链【默写】

记号：隐层 zⱼ=σ(Σᵢvᵢⱼxᵢ)，输出 yₖ=σ(Σⱼwⱼₖzⱼ)，E=½ΣₚΣₖ(dₚₖ−yₚₖ)²

①通用更新 Δₚwⱼₖ=ηδₖzⱼ（δ×该权输入信号）

②输出层（链式 ∂E/∂w=∂E/∂y·∂y/∂s·∂s/∂w）：
δₖ=(dₖ−yₖ)·yₖ(1−yₖ)

③隐层（上层 δ 按权回传求和）：
δⱼ=zⱼ(1−zⱼ)·Σₖwⱼₖδₖ

双极 sigmoid 时导数换 1−y²。

四步：随机初始化→前向→反向逐层 δ→更新；循环至收敛。动量：Δw(t)=−η∂E/∂w+αΔw(t−1)（0<α<1）防震荡。

4.4 理论三句话【概念】

Kolmogorov：f(x)=Σ_{j=1}^{2n+1}gⱼ(Σᵢwᵢhᵢ(xᵢ)) ⇒ MLP 是通用逼近器（存在权重使误差任意小）但 BP 不保证找到（局部极小）；过拟合＝训练好测试差；一般学习问题是 NP-complete（s187）。

推导5 · RBF 网络

RBF：取值只依赖到中心距离 r；Gaussian 最常用；另有 MQ √(r²+c²)、逆MQ 1/√(r²+c²)、薄板 r²ln r。

结构（Broomhead & Lowe 1988）：两层＝隐层 RBF＋输出层线性（同 ADALINE）
φⱼ(x)=exp(−‖x−cⱼ‖²/(2σⱼ²))；y=Σⱼwⱼφⱼ(x)+w₀

Cover 定理【英文】：a complex pattern-classification problem, cast nonlinearity in a high-dimensional space, is more likely to be linearly separable than in a low-dimensional space（φ-separable：wᵀφ(x)>0 / <0）。

RBF 解 XOR【例题】：c₁=[1,1]ᵀ, c₂=[0,0]ᵀ 两高斯元 → 四点映到 (φ₁,φ₂) 面线性可分，线性输出层分类。

概念FLN（Pao, CWRU, 80s末）：单层＋高阶聚合（xᵢxⱼ 项），快、局部极小可消除。ELM（黄广斌, NTU, 2000s中）：输入→隐层权重随机固定，只解输出层最小二乘：极快、无局部极小。

5.5 常用激活函数速查【概念】

函数式导数用于
hard-limitf(s)=1(s≥θ)—（不可微）感知机/MAXNET
线性f(s)=s1ADALINE/RBF输出
单极 sigmoid1/(1+e⁻ˢ)y(1−y)BP（可微）
双极 sigmoidtanh(s)1−y²BP（对称）
高斯 RBFe^{−‖x−c‖²/2σ²}−(x−c)/σ²·φRBF 隐层

为何 BP 要可微：梯度下降需 ∂E/∂w＝∂E/∂y·σ′(s)·输入；hard-limit 在跳变点无导数 ⇒ 无法直接梯度训练（感知机只能用误分类规则）。

5.6 RBF 中心选择与训练实务【概念】

中心 c 选取：随机抽训练样本｜k-means 聚类｜正交最小二乘(OLS)逐个加入｜全监督梯度同训（慢）。σ：按最近邻中心间距设定或交叉验证。两阶段优势：输出层线性 ⇒ 最小二乘闭式解（解线性方程组/伪逆），无局部极小、极快；缺点＝维数灾难（高斯基随维数指数需更多中心）。

5.7 MLP+BP 训练实务【概念】

过拟合对策：early stopping（验证集误差回升即停）｜正则化（加 λ‖w‖²）｜减隐元｜增数据。权重初始化：小随机数（全 0 会因对称性卡死）；隐元数按经验/试凑。批 vs 序贯：批稳定、序贯（online）可逃离浅坑。η 自适应：震荡减半、下降缓慢则增大。

5.8 误差曲面与收敛性【概念】

单层线性网（LMS）：误差曲面是 w 的二次碗形（凸）⇒ 唯一全局极小，梯度下降必收敛（η 小）；多层 sigmoid：误差曲面非凸 ⇒ 局部极小/平台/鞍点，BP 收敛到某个局部极小，且不保证全局最优——对比题必写这一条。

推导6 · SVM（最重点）

6.1 判别函数与距离【推导第一步】

g(x)=wᵀx+b=0；w＝法向量（面上任两点差 v 满足 wᵀv=0；b 只平移不改方向）。
点距（投影推导）：dist(x₀)=|wᵀx₀+b|/‖w‖

6.2 最大间隔四步【默写】

①线性分类器有无穷多个→选泛化最好的＝最大 margin（对 outlier 鲁棒）；标签 yᵢ∈{−1,+1}，正确 ⇔ yᵢ(wᵀxᵢ+b)≥0

②w,b 同比缩放不改变平面 ⇒ 取缩放使最近样本 |wᵀxᵢ+b|=1

③边界 wᵀx+b=±1 ⇒ margin=2/‖w‖

④max 2/‖w‖ ⇔ 凸 QP：min ½‖w‖² s.t. yᵢ(wᵀxᵢ+b)≥1, ∀i

6.3 拉格朗日→对偶【默写】

L=½‖w‖²−Σᵢαᵢ[yᵢ(wᵀxᵢ+b)−1]，αᵢ≥0；
∂L/∂w=0 ⇒ w=Σᵢαᵢyᵢxᵢ；∂L/∂b=0 ⇒ Σᵢαᵢyᵢ=0；代入 ⇒

maxα Σᵢαᵢ−½ΣᵢΣⱼαᵢαⱼyᵢyⱼxᵢᵀxⱼ s.t. Σαᵢyᵢ=0, αᵢ≥0

6.4 KKT 与支持向量【概念＋推导】

αᵢ[yᵢ(wᵀxᵢ+b)−1]=0：margin 上点 αᵢ>0＝SV（唯一决定平面）；面外 αᵢ=0（删之无影响）。
g(x)=Σᵢαᵢyᵢ(xᵢᵀx)+b —— 训练/判别只用内积 ⇒ 核技巧前提。

6.5 软间隔【默写】

不可分/噪声：松弛 ξᵢ≥0：
min ½‖w‖²+CΣξᵢ s.t. yᵢ(wᵀxᵢ+b)≥1−ξᵢ, ξᵢ≥0
对偶仅加箱 0≤αᵢ≤C。C 大→重罚误分类（易过拟合）；C 小→重间隔。0<α<C 在面上；α=C 在带内/越界。

6.6 核技巧＋Mercer【默写】

Φ:x→φ(x) 高维可分；只需内积 ⇒ K(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ)，g(x)=ΣαᵢyᵢK(xᵢ,x)+b，无需显式 φ。
Mercer：对称半正定（Gram 阵 PSD）⇔ 合法核。

6.7 常用核【必背】

核公式
线性K=xᵢᵀx
多项式K=(1+xᵢᵀx)p（一般式 (γxᵢᵀx+r)d）
高斯 RBFK=exp(−‖xᵢ−xⱼ‖²/(2σ²))
SigmoidK=tanh(β·xᵢᵀx−b)

核验证例题：(1+xᵢᵀxⱼ)²=φᵢᵀφⱼ，φ(x)=[1, x₁², √2x₁x₂, x₂², √2x₁, √2x₂]ᵀ（逐项展开对照）。

6.8 流程与设计【概念】

①选核 ②选 C ③解 QP ④由 SV 构 g(x)。σ 取不同类最近点距离量级；无准则→验证集/交叉验证；hard/soft 靠实验。SVM＝结构风险最小化（Vapnik，90s初），仅依赖 SV ⇒ 小样本优于深度学习、抗过拟合泛化强。

6.9 SVR【推导】

ε-不敏感管道（|y−f|≤ε 不计损失）：
min ½‖w‖²+CΣ(ξᵢ+ξᵢ*) s.t. yᵢ−wᵀφ(xᵢ)−b≤ε+ξᵢ；wᵀφ(xᵢ)+b−yᵢ≤ε+ξᵢ*；ξ,ξ*≥0
解 f(x)=Σ(αᵢ−αᵢ*)K(xᵢ,x)+b

6.10 LS-SVM【推导＋对比】

Suykens & Vandewalle（KU Leuven, 1999）：不等式→等式约束＋平方误差：
min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ=wᵀφ(xᵢ)+b+eᵢ
KKT ⇒ 线性方程组：快；代价＝α 多非零，失稀疏性。应用：双螺旋分类、电力负荷预测。

6.11 软间隔对偶与求 b【推导细节】

软间隔对偶：max Σαᵢ−½ΣᵢΣⱼαᵢαⱼyᵢyⱼxᵢᵀxⱼ s.t. Σαᵢyᵢ=0, 0≤αᵢ≤C（比硬间隔仅多箱约束）。
求 b：任取 SV（0<αᵢ<C）代入 yᵢ(wᵀxᵢ+b)=1 ⇒ b=yᵢ−Σⱼαⱼyⱼxⱼᵀxᵢ；多 SV 取平均更稳。

6.12 SVM 解题自查【得分点】

①dist=|wᵀx+b|/‖w‖ ②margin=2/‖w‖ ③缩放使最近点=±1 ④min ½‖w‖² s.t. yᵢ(wᵀxᵢ+b)≥1 ⑤写 L、∂L/∂w=0、∂L/∂b=0 ⑥对偶式含全约束 ⑦KKT 点明 SV ⑧核替换 K=φᵢᵀφⱼ ⑨结论句（最大间隔/稀疏/泛化）。漏步＝漏分。

概念7 · 无监督与竞争学习

无监督：无标签学结构（聚类：按相似度分组，主观无唯一解）。强化学习（课件口径）：输入刺激强化权重/阈值以增强期望输出再现，例 Hebbian。竞争学习：单元竞争产出权（例 Kohonen）。

算法：X={x¹..xᴾ} 归 K 簇：①随机初始化 ②随机取 xⱼ 算 wᵢᵀxⱼ ③选 w*=argmax ④只更新赢家 w(t+1)=w(t)+η(xⱼ−w(t))（可再归一化）⑤重复至收敛。
能量函数：E=Σₚ‖xₚ−w(xₚ)‖²（样本到赢家权重距离平方和），学习使之下降。

概念8 · MAXNET 与 kWTA

MAXNET：选最大输入的子网络（WTA），靠相互抑制保最大压其余；循环网络；自兴奋权重=1，侧抑制权重=−w，w<1/m（m＝单元数）；动力学 xⱼ(t+1)=f(xⱼ(t)−wΣᵢ≠ⱼxᵢ(t))；常作输出层。
kWTA：选前 k 大响应、抑制其余；Heaviside 激活（σ(s)=1 if s>0 else 0）版全局稳定、有限时间收敛到 kWTA 解（有收敛时间上下界）。

T7 Hebbian vs 竞争学习 vs Delta【范式】

Hebbian：Δw=η·d·x 或 ηyx（同兴奋，无教师信号方向校正，权重无界增长需归一化）｜竞争学习：仅赢家 w←w+η(x−w)（无监督、聚类、权重向输入移动）｜Delta/LMS：Δw=η(d−y)x（有监督、误差驱动、降 MSE）。共同点＝都是增量规则 w(t+1)=w(t)+η·r 的特例。

公式补遗【推导速查】

范数/距离：‖w‖=√(Σwᵢ²)；margin=2/‖w‖；点距 |wᵀx+b|/‖w‖；高斯基 exp(−‖x−c‖²/(2σ²))。

梯度对照：LMS ∇E=−Σₚeₚxₚ ⇒ w+=ηΣₚeₚxₚ｜BP 输出 δₖ=(dₖ−yₖ)yₖ(1−yₖ)｜隐层 δⱼ=zⱼ(1−zⱼ)Σₖwⱼₖδₖ｜SVM 对偶 max Σα−½ΣΣαᵢαⱼyᵢyⱼKᵢⱼ。

约束形式对照：硬间隔 yᵢ(wᵀxᵢ+b)≥1｜软间隔 ≥1−ξᵢ, ξᵢ≥0｜SVR 双不等式 ≤ε+ξ｜LS-SVM 等式 y=wᵀφ+b+e。

目标函数对照：LMS/BP ½Σ(d−y)²｜SVM ½‖w‖²(+CΣξ)｜LS-SVM ½‖w‖²+(γ/2)Σe²｜竞争 Σ‖x−w(x)‖²。

易错公式急救【弱项】

①margin 分母是 ‖w‖一次方，距离公式分母也是 ‖w‖；②软间隔约束右边是 1−ξ 不是 1+ξ；③对偶目标是 max Σα−½…（别写成 min）；④SVM 判别式含 yᵢ：g=ΣαᵢyᵢK(xᵢ,x)+b；⑤隐层 δ 无 d、须乘 自身导数；⑥MAXNET 侧抑制 w<1/m 且自兴奋=1；⑦σ′(单极)=y(1−y)、σ′(双极)=1−y² 别混。

英文答题句【背诵】

  • A dataset is linearly separable if a linear decision boundary can classify all samples correctly.
  • The hidden-layer delta sums the error contributions of all output neurons it feeds, weighted by the connecting weights.
  • An RBF network has a Gaussian hidden layer and a linear output layer; inputs become linearly separable in the feature space (Cover's theorem).
  • Support vectors are the samples on the margin (αᵢ>0); they alone determine the optimal hyperplane.
  • The kernel trick computes inner products in a high-dimensional feature space without the explicit mapping: K(x,z)=φ(x)ᵀφ(z).
  • C trades off margin maximization versus violation penalty: large C → fewer violations, small C → wider margin.
  • MLPs are universal approximators, but BP is not guaranteed to find the optimal weights (local minima).

对比11 · 对比题答题骨架＋加分句

骨架（五要素）：①结构（层/前馈·循环/激活）→②学习规则（谁更新、公式、监督否）→③优化目标（min MSE / max margin / 聚类误差）→④性质（收敛条件/局部极小/稀疏性/XOR）→⑤适用与弱点。每对比至少写 4 要素，用完整句＋whereas。

加分句：The key difference lies in the objective: ADALINE minimizes the MSE of the linear output, whereas the perceptron only corrects misclassifications.｜SVM maximizes the margin subject to constraints, which yields a convex problem without local minima.｜RBF networks transform the input into a higher-dimensional feature space where linear separation is more likely (Cover).

概念12 · 选择/填空陷阱清单【弱项】

①M-P：抑制输入为 1 ⇒ 输出必 0（不是看加权和）；②两层 M-P＝任意逻辑函数；无抑制＝单调函数；③收敛定理前提线性可分、有限步、得 w和θ；④XOR 原因非线性可分（不是权不够）；⑤ADALINE 仅 batch、误差来自线性输出；⑥∇E=−Σeₚxₚ（符号别反）；⑦σ′(单极)=y(1−y)，σ′(双极)=1−y²；⑧隐层 δ 无 d；⑨MLP 逼近存在但 BP 不保证；⑩Cover 是“更可能”非“必然”；⑪KKT：α>0⇔在 margin 上；⑫C 大重罚误分类；⑬Mercer＝对称半正定；⑭LS-SVM 失稀疏；⑮MAXNET：自兴奋 1、侧抑制 −w<1/m；⑯kWTA Heaviside 版全局稳定有限时间；⑰样本 4 面→最多 14 区（非 16）；⑱Hopfield、ART1 属期末范围，别写进期中对比。
