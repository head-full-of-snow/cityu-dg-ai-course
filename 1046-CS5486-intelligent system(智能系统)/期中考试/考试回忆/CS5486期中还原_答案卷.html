1(a) M-P 阈值逻辑网 vs. 感知机 · Threshold Logic Network (M-P) vs. Perceptron

ENBoth networks are built of threshold logic (hard-limit) units: the output is 1 iff the weighted sum of the inputs is not less than the threshold θ. The M-P neuron (1943) uses binary inputs/outputs {0,1} with fixed unity weights +1/−1 and no learning algorithm — an inhibitory input of 1 forces the output to 0; its networks perform logic computation: two layers realize any logical function, uninhibited units only monotonic logical functions, and recurrent M-P networks simulate any finite automaton. The perceptron (Rosenblatt, late 1950s) is a single adaptive layer of a feedforward network of pure threshold logic units: it receives n real inputs through adjustable real-valued weights, learned from examples by w←w+η(d−y)x, θ←θ−η(d−y) (update only on misclassification); if the data are linearly separable, it converges in a finite number of steps. In short: the M-P network is a fixed, hand-designed logic device, whereas the perceptron is an adaptive pattern classifier limited to linearly separable data.
中文两者都由阈值逻辑（硬限幅）单元构成（加权和 ≥ θ 输出 1）。M-P 神经元（1943）二值输入输出，权重固定 ±1、无学习算法（抑制输入=1 ⇒ 输出 0）；其网络做逻辑运算：两层实现任意逻辑函数、无抑制只能单调逻辑函数、循环 M-P 网模拟任意有限自动机。感知机（Rosenblatt，1950s 末）是单层自适应阈值逻辑单元前馈网：n 个实数输入、可调实数权重，由样本学习（仅误分类时更新）；线性可分时有限步收敛。一句话：M-P＝固定手工设计的逻辑器件；感知机＝限线性可分数据的自适应分类器。

1(b) Perceptron vs. ADALINE

EN(slide s104, quotable verbatim) Architecture: Perceptron uses a bipolar or unipolar hardlimiter activation function, whereas ADALINE (Adaptive Linear Elements, Widrow & Hoff, 1960s) uses a linear activation function. Learning rule: the perceptron learning algorithm is not gradient-descent and can operate in either sequential or batch training mode, whereas the ADALINE learning (LMS / Delta / Widrow–Hoff) algorithm is gradient descent, minimizing the mean squared error of the linear output, but can only operate in batch mode. Both are single adaptive layers of feedforward networks; both fail on XOR (not linearly separable).
中文（s104 课件原句，可直接默写）结构：感知机用双极/单极硬限幅激活函数，而 ADALINE 用线性激活函数。学习规则：感知机学习算法不是梯度下降，可工作于序贯或批量模式；ADALINE 学习算法（LMS／Delta／Widrow–Hoff）是梯度下降，最小化线性输出的均方误差，但仅能批量模式。两者同为单层自适应前馈网；XOR 均不可解（非线性可分）。

1(c) MLP vs. RBF Network

ENBoth are multilayer feedforward networks with a linear output layer. The MLP uses global sigmoid hidden units (monotone, nonzero almost everywhere) and trains all weights iteratively by backpropagation — a recursive gradient-descent algorithm: slow, possibly stuck in local minima. The RBF network (Broomhead & Lowe, 1988) uses local Gaussian hidden units φⱼ(x)=exp(−‖x−cⱼ‖²/2σⱼ²) that respond only near their centers, and trains in two stages: unsupervised center selection (random / k-means / OLS) followed by a linear least-squares (pseudoinverse) solution for the output weights — closed-form, fast, no local minima. The MLP is a global approximator, the RBF a local approximator (both universal). Both solve XOR (RBF via Cover's theorem). Weaknesses: MLP — slow, local minima, overfitting; RBF — curse of dimensionality, center selection.
中文两者都是带线性输出层的多层前馈网络。MLP 隐层用全局 sigmoid（单调、几乎处处非零），全部权重由 BP 迭代训练（递归梯度下降）：慢、可能局部极小。RBF 网络（1988）隐层用局部高斯 φⱼ(x)=exp(−‖x−cⱼ‖²/2σⱼ²)（仅中心附近响应），两阶段训练：无监督选中心（随机/k-means/OLS）＋输出层线性最小二乘（伪逆）闭式解：快、无局部极小。MLP 全局逼近、RBF 局部逼近（均通用）；都能解 XOR（RBF 依 Cover 定理）。弱点：MLP 慢/局部极小/过拟合；RBF 维数灾难/选中心。

1(d) SVM vs. LS-SVM

ENThe SVM (Vapnik, early 1990s) solves min ½‖w‖²+CΣξᵢ subject to inequality constraints yᵢ(wᵀφ(xᵢ)+b) ≥ 1−ξᵢ (hinge loss): a convex QP whose solution is sparse — only support vectors (αᵢ>0) determine the hyperplane. The LS-SVM (Suykens & Vandewalle, KU Leuven, 1999) uses equality constraints with squared errors: min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ=wᵀφ(xᵢ)+b+eᵢ; the KKT conditions reduce to a linear system of equations — much faster — at the cost of losing sparsity (most αᵢ≠0). Both follow structural risk minimization and are kernelizable.
中文SVM（Vapnik，1990s 初）：min ½‖w‖²+CΣξᵢ，不等式约束（hinge 损失），凸二次规划，解稀疏（仅支持向量 αᵢ>0 决定超平面）。LS-SVM（Suykens & Vandewalle，1999）：等式约束＋平方误差 min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ=wᵀφ(xᵢ)+b+eᵢ；KKT 化为线性方程组——快得多，但失去稀疏性（多数 αᵢ≠0）。两者同属结构风险最小化、均可核化。

1(e) Feedforward vs. Recurrent

EN(classification dimension s47: "Feedforward vs. recurrent, in terms of G and H") A feedforward network propagates signals strictly from input to output, layer by layer, without feedback — in terms of the aggregation rule G and the output rule H, no neuron's output H ever feeds back into the aggregation input G of a neuron in the same or an earlier layer. It implements a static mapping x→y with no internal state (perceptron, ADALINE, MLP, RBF, SVM). A recurrent network contains feedback connections: outputs feed back (via H) into the aggregation inputs G of themselves or earlier layers, forming loops; it is a dynamical system with internal state whose feedback provides short-term memory (fast dynamics of u, v; weights w = long-term memory), enabling sequence/time-dependent processing (MAXNET, ART1, Hopfield, Boltzmann machine); recurrent M-P networks can simulate any finite automaton. Dynamical stability (e.g., MAXNET requires w<1/m) is a concern unique to recurrent networks.
中文（s47：就 G、H 区分）前馈网络信号自输入向输出单向逐层传播，无反馈——任何神经元的输出 H 都不回馈到同层或前层的聚合输入 G；实现静态映射 x→y、无内部状态（感知机、ADALINE、MLP、RBF、SVM）。循环网络含反馈连接：输出经 H 回馈到自身或前层的聚合输入 G 形成回路，是具有内部状态的动态系统；反馈提供短期记忆（u、v 快动态；权重 w＝长期记忆），可处理序列/时变信号（MAXNET、ART1、Hopfield、Boltzmann 机）；循环 M-P 网可模拟任意有限自动机。动力学稳定性（如 MAXNET 要求 w<1/m）是循环网络特有问题。

例子 ExamplesP / ADALINE / MLP / RBF / SVMMAXNET、ART1、Hopfield、Boltzmann

Question 2 · 双极 Sigmoid 最大斜率 Maximum Slope of the Bipolar Sigmoid

Solution 解答

EN Step 1 — Direct differentiation. Let q ≜ e−λu, so q′ = −λq:
dv/du = [λq(1+q) + λq(1−q)] / (1+q)² = 2λe−λu / (1+e−λu)²
Step 2 — Derivative in terms of v. From v=(1−q)/(1+q): 1−v = 2q/(1+q), 1+v = 2/(1+q), hence 1−v² = 4q/(1+q)². Substituting:
dv/du = (λ/2)(1 − v²)
Step 3 — Maximization. For every finite u, −1 < v < 1 ⟹ 0 < 1−v² ≤ 1, equality iff v = 0. Therefore dv/du ≤ λ/2, with the maximum attained exactly when v=0, i.e. e−λu=1 ⟺ u=0:
(dv/du)max = λ/2, attained at u = 0 (v = 0). ∎
Alternatives: (i) g′(u)=2λ²q(q−1)/(1+q)³ is >0 for u<0, <0 for u>0 ⟹ global max at u=0, g(0)=λ/2. (ii) AM–GM: (1+q)² ≥ 4q ⟹ dv/du ≤ λ/2, equality iff q=1.
中文 第 1 步·直接求导：记 q ≜ e−λu（q′=−λq），商规则得 dv/du = 2λe−λu/(1+e−λu)²。 第 2 步·用 v 表示：由 v=(1−q)/(1+q) 得 1−v=2q/(1+q)、1+v=2/(1+q)，故 1−v²=4q/(1+q)²，代回得 dv/du=(λ/2)(1−v²)。 第 3 步·求最大：−1<v<1 ⟹ 0<1−v²≤1，等号当且仅当 v=0（⟺ u=0）。故 dv/du ≤ λ/2，最大值 λ/2 在 u=0 处取得。∎ 备选：①g′(u)=2λ²q(q−1)/(1+q)³，u<0 增、u>0 减；②AM-GM：(1+q)²≥4q。
备注 Remarks：f(u)=tanh(λu/2) 为双极 sigmoid（s125）；"导数用输出表示"正是 BP 双极 δ 规则 σ′=1−y² 的来源；单极对照 σ(u)=1/(1+e−λu)：dσ/du=λσ(1−σ)，最大斜率 λ/4 在 σ=1/2 处；λ 为增益参数，λ→∞ 退化为 hard-limiter。
出处：s124–125（Sigmoid Activation Functions）
Question 3 · RBF 解 XOR RBF Network Solves XOR

Solution 解答

ENThe grouping {(0,0),(1,1)} vs. {(1,0),(0,1)} is the XOR grouping — not linearly separable in the input space. The RBF network = Gaussian hidden layer + linear output layer y=Σwⱼφⱼ(x)+w₀. Step 1 — Hidden mapping (x₂ and x₄ collapse onto the same hidden point — same class, harmless):
input 输入class 类hidden point 隐层点 (φ₁, φ₂)
x₁=(0,0)1(1, e⁻²)
x₃=(1,1)1(e⁻², 1)
x₂=(1,0)0(e⁻¹, e⁻¹)
x₄=(0,1)0(e⁻¹, e⁻¹)
Step 2 — Linear separability in the hidden space. Along u=φ₁+φ₂: class 1 gives 1+e⁻² ≈ 1.135, class 0 gives 2e⁻¹ ≈ 0.736, and
1 + e⁻² − 2e⁻¹ = (1 − e⁻¹)² > 0
so the classes are strictly linearly separable in the hidden space. (General σ, t=e−1/(2σ²): (1+t²)−2t=(1−t)²>0.) Step 3 — Construct output weights and verify. Take w₁=w₂=1, w₀=−1 (θ=1; any θ ∈ (2e⁻¹, 1+e⁻²) works), y=f(φ₁+φ₂−1): x₁,x₃ ⟹ e⁻²>0 ⟹ y=1 ✓; x₂,x₄ ⟹ 2e⁻¹−1<0 (since 2<e) ⟹ y=0 ✓. All four points are classified correctly. ∎ This is an instance of Cover's theorem: the nonlinear Gaussian mapping casts the problem into a higher-dimensional hidden space where the classes become linearly separable, and the linear output layer (as in ADALINE) suffices.
中文该分组即 XOR 分组，输入空间非线性可分。RBF 网络＝高斯隐层＋线性输出层。 第 1 步·隐层映射：x₁→(1, e⁻²)、x₃→(e⁻², 1)（类 1）；x₂、x₄→同一点 (e⁻¹, e⁻¹)（类 0；同类坍缩无碍）。 第 2 步·隐空间线性可分：沿 u=φ₁+φ₂，类 1 之和 1+e⁻²≈1.135，类 0 之和 2e⁻¹≈0.736，1+e⁻²−2e⁻¹=(1−e⁻¹)²>0 ⟹ 严格线性可分（一般 σ：(1+t²)−2t=(1−t)²>0）。 第 3 步·构造输出层并验证：取 w₁=w₂=1、w₀=−1（θ=1）：x₁,x₃ 输出 1（e⁻²>0）✓；x₂,x₄ 输出 0（2e⁻¹−1<0，因 2<e）✓。四点全部分类正确。∎ 课程意义：Cover 定理实例——非线性映射到高维隐空间后线性可分，线性输出层即可完成分类；隐空间边界为直线 φ₁+φ₂=1（2e⁻¹<1<1+e⁻² 恰好夹住两类）。
