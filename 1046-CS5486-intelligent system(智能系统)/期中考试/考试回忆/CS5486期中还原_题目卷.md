## Question 2 · Maximum Slope of the Bipolar Sigmoid（双极 Sigmoid 的最大斜率）

Let

$$v = f(u) = \frac{1 - e^{-\lambda u}}{1 + e^{-\lambda u}}, \qquad \lambda > 0 .$$

**Prove that the derivative of v with respect to u attains its maximum when v = 0, and find this maximum value.**
（设 v=f(u)=(1−e^(−λu))/(1+e^(−λu))，λ>0。**证明当 v=0 时，v 对 u 的导数取得最大值，并求出该最大值。**）

## Question 3 · RBF Network Solves XOR（RBF 网络解 XOR）

Consider an RBF network with two Gaussian hidden units

$$\varphi_i(x) = \exp\big(-\|x - c_i\|^2\big),$$

with centers $c_1=(0,0)^T$ and $c_2=(1,1)^T$, and a linear output layer. Given the data

$$x_1=(0,0)^T,\quad x_2=(1,0)^T,\quad x_3=(1,1)^T,\quad x_4=(0,1)^T,$$

where $x_1, x_3$ belong to one class and $x_2, x_4$ to the other, **prove that this network can correctly discriminate (classify) the data**.
（考虑含两个高斯隐单元 φᵢ(x)=exp(−‖x−cᵢ‖²) 的 RBF 网络，中心 c₁=(0,0)ᵀ、c₂=(1,1)ᵀ，输出层为线性。给定数据 x₁=(0,0)ᵀ、x₂=(1,0)ᵀ、x₃=(1,1)ᵀ、x₄=(0,1)ᵀ，其中 x₁、x₃ 为一类，x₂、x₄ 为另一类，**证明该网络能正确区分（分类）这些数据**。）

## Question 4 · LS-SVM Computation（LS-SVM 计算题）

Consider an LS-SVM classifier with two training points $x_1=0\ (y_1=+1)$ and $x_2=1\ (y_2=-1)$, polynomial kernel $K(x_i,x_j)=(x_i x_j + 1)^2$, and regularization parameter $\gamma = 1$.
（考虑 LS-SVM 分类器：训练样本 x₁=0（y₁=+1）、x₂=1（y₂=−1），多项式核 K(xᵢ,xⱼ)=(xᵢxⱼ+1)²，正则参数 γ=1。）

**(1)** Compute the 2×2 kernel matrix.（求 2×2 核矩阵。）

**(2)** Set up the 3×3 linear system for the unknowns $b, \alpha_1, \alpha_2$.（列出关于未知量 b、α₁、α₂ 的 3×3 线性方程组。）

**(3)** Solve the linear system.（解该线性方程组。）

**(4)** Write the LS-SVM decision function.（写出 LS-SVM 判决函数。）

**(5)** Find the decision boundary $g(x)=0$ and give its **positive root**.（求决策边界 g(x)=0 并给出其**正根**。）
