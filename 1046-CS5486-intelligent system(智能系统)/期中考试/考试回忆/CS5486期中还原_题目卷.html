Question 1 · 不同网络的架构与功能对比 Comparison of Neural Network Architectures and Functions
Compare the following pairs of neural network models in terms of their architecture and functionality.
就结构与功能比较下列各对神经网络模型。
  1. The threshold logic network composed of McCulloch–Pitts (M-P) units and the (simple) perceptron.
    由 McCulloch–Pitts（M-P）单元构成的阈值逻辑网络与（简单）感知机。
  2. The perceptron and ADALINE.
    感知机与 ADALINE。
  3. The multilayer perceptron (MLP) and the RBF network.
    多层感知机（MLP）与 RBF 网络。

    SVM 与 LS-SVM（最小二乘支持向量机）。
  5. Feedforward and recurrent neural networks.

Question 2 · 双极 Sigmoid 的最大斜率 Maximum Slope of the Bipolar Sigmoid
Let v = f(u) = (1 − e−λu) / (1 + e−λu), λ > 0. Prove that the derivative of v with respect to u attains its maximum when v = 0, and find this maximum value.
设 v = f(u) = (1 − e−λu)/(1 + e−λu)，λ > 0。证明当 v = 0 时，v 对 u 的导数取得最大值，并求出该最大值。
Question 3 · RBF 网络解 XOR RBF Network Solves XOR
Consider an RBF network with two Gaussian hidden units φᵢ(x) = exp(−‖x − cᵢ‖²), with centers c₁ = (0,0)ᵀ and c₂ = (1,1)ᵀ, and a linear output layer. Given the data
x₁=(0,0)ᵀ,　x₂=(1,0)ᵀ,　x₃=(1,1)ᵀ,　x₄=(0,1)ᵀ,
where x₁, x₃ belong to one class and x₂, x₄ to the other, prove that this network can correctly discriminate (classify) the data.
考虑含两个高斯隐单元 φᵢ(x)=exp(−‖x−cᵢ‖²) 的 RBF 网络，中心 c₁=(0,0)ᵀ、c₂=(1,1)ᵀ，输出层为线性。给定数据 x₁=(0,0)ᵀ、x₂=(1,0)ᵀ、x₃=(1,1)ᵀ、x₄=(0,1)ᵀ，其中 x₁、x₃ 为一类，x₂、x₄ 为另一类，证明该网络能正确区分（分类）这些数据。
Question 4 · LS-SVM 计算题 LS-SVM Computation
Consider an LS-SVM classifier with two training points x₁ = 0 (y₁ = +1) and x₂ = 1 (y₂ = −1), polynomial kernel K(xᵢ, xⱼ) = (xᵢxⱼ + 1)², and regularization parameter γ = 1.
考虑 LS-SVM 分类器：训练样本 x₁=0（y₁=+1）、x₂=1（y₂=−1），多项式核 K(xᵢ,xⱼ)=(xᵢxⱼ+1)²，正则参数 γ=1。
  1. Compute the 2×2 kernel matrix.
    求 2×2 核矩阵。
  2. Set up the 3×3 linear system for the unknowns b, α₁, α₂.
    列出关于未知量 b、α₁、α₂ 的 3×3 线性方程组。
  3. Solve the linear system.
    解该线性方程组。
  4. Write the LS-SVM decision function.
    写出 LS-SVM 判决函数。
  5. Find the decision boundary g(x)=0 and give its positive root.
    求决策边界 g(x)=0 并给出其正根。
