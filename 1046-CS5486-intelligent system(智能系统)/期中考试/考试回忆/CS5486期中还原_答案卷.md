# Question 1 · 网络对比 Network Comparison

**对比题骨架 Skeleton（五要素，每题至少 4 项）**：①结构 Architecture（层数 layers、前馈/循环 feedforward/recurrent、激活 activation）②学习规则 Learning rule（谁更新、公式、有/无监督）③优化目标 Objective（min MSE / max margin / 聚类 clustering）④性质 Properties（收敛条件 convergence、局部极小 local minima、稀疏性 sparsity、XOR）⑤功能与弱点 Functionality & weaknesses。

## 1(a) M-P 阈值逻辑网 vs. 感知机 Threshold Logic Network (M-P) vs. Perceptron

**EN**: Both networks are built of **threshold logic (hard-limit) units**: the output is 1 iff the weighted sum of the inputs is not less than the threshold θ, and 0 otherwise. The **M-P neuron** (McCulloch & Pitts, 1943) uses binary inputs/outputs {0,1} with **fixed unity connection weights +1/−1 and no learning algorithm** — an inhibitory input of 1 forces the output to 0. Networks of such units perform **logic computation**: a two-layer M-P network can realize any logical function, uninhibited units can only realize monotonic logical functions, and recurrent M-P networks can simulate any finite automaton. The **perceptron** (Rosenblatt, late 1950s) is a **single adaptive layer of a feedforward network of pure threshold logic units**: it receives n **real** inputs through real-valued **adjustable** weights and learns them from examples by the perceptron rule w←w+η(d−y)x, θ←θ−η(d−y) (update only on misclassification); if the data are linearly separable, the algorithm converges to a set of weights and a threshold in a finite number of steps. In short: the M-P network is a fixed, hand-designed logic device, whereas the perceptron is an **adaptive pattern classifier** limited to linearly separable data.

**中文**：两者都由**阈值逻辑（硬限幅）单元**构成：加权和 ≥ θ 时输出 1，否则 0。**M-P 神经元**（1943）输入输出为二值 {0,1}，连接权重**固定为 ±1 且无学习算法**——抑制输入为 1 时输出必为 0；其网络做**逻辑运算**：两层 M-P 网可实现任意逻辑函数，无抑制单元只能实现单调逻辑函数，循环 M-P 网可模拟任意有限自动机。**感知机**（Rosenblatt，1950s 末）是**单层自适应阈值逻辑单元前馈网**：接收 n 个**实数**输入，权重**可调**并由样本学习（规则 w←w+η(d−y)x、θ←θ−η(d−y)，仅误分类时更新）；数据线性可分时有限步收敛。一句话：M-P 是固定手工设计的逻辑器件，感知机是**只限线性可分数据的自适应模式分类器**。

| 维度 Dimension | M-P 阈值逻辑网（1943） | 感知机 Perceptron（1950s 末） |
|---|---|---|
| 结构 Structure | 阈值逻辑单元（可多层、可循环 multi-layer / recurrent） | 单层自适应阈值逻辑单元前馈网 single adaptive layer, feedforward |
| 权重 Weights | 固定 ±1，人工设计 fixed, hand-designed | 实数权重，可调 real-valued, adjustable |
| 学习 Learning | 无学习算法 none | 感知机规则＋收敛定理 perceptron rule + convergence theorem |
| 输入 Inputs | 二值 {0,1}（抑制=1 ⇒ 输出 0） | n 个实数 n real inputs |
| 功能 Function | 逻辑运算（任意逻辑函数/有限自动机） logic computation | 线性可分二分类 linearly separable classification（XOR ✗） |

> 出处：s51–52（M-P）、s63–64（有限自动机）、s65 / s68（感知机定义）。

## 1(b) Perceptron vs. ADALINE

**EN** *(slide s104, quotable verbatim)*:
> **Architecture**: Perceptron uses a bipolar or unipolar hardlimiter activation function, whereas ADALINE (Adaptive Linear Elements, Widrow & Hoff, 1960s) uses a **linear** activation function.
> **Learning rule**: The perceptron learning algorithm is **not gradient-descent** and can operate in either **sequential or batch** training mode, whereas the ADALINE learning (**LMS / Delta / Widrow–Hoff**) algorithm **is gradient descent**, minimizing the **mean squared error** of the linear output, but can only operate in **batch** mode.

Both are single adaptive layers of feedforward networks; both fail on XOR (not linearly separable in the input space).

**中文**（s104 课件原句，可直接默写）：
> **结构**：感知机使用双极或单极硬限幅激活函数，而 ADALINE（自适应线性元，Widrow & Hoff，1960s）使用**线性**激活函数。
> **学习规则**：感知机学习算法**不是梯度下降**，可工作于**序贯或批量**两种训练模式；而 ADALINE 学习算法（**LMS／Delta／Widrow–Hoff**）**是梯度下降**，最小化线性输出的**均方误差**，但**只能以批量模式**运行。

两者同为单层自适应前馈网；XOR 均不可解（输入空间非线性可分）。

| 维度 Dimension | Perceptron | ADALINE |
|---|---|---|
| 激活 Activation | hard-limiter（bipolar/unipolar） | 线性 linear（误差基于线性输出 y=wᵀx） |
| 更新 Update | w←w+η(d−y)x（误分类驱动 non-gradient） | w(t+1)=w(t)+ηΣₚeₚxₚ（梯度下降 gradient descent） |
| 训练模式 Mode | 序贯或批量 sequential or batch | 仅批量 batch only |
| 目标 Objective | 分类正确即收敛 correct classification | minimize MSE |
| XOR | ✗ | ✗ |

> 出处：s104（对比页）、s100–104（ADALINE/LMS）。

## 1(c) MLP vs. RBF Network

**EN**: Both are multilayer feedforward networks with a linear output layer. The **MLP** uses **global sigmoid** hidden units (monotone, nonzero almost everywhere) and trains all weights iteratively by **backpropagation** — a recursive gradient-descent algorithm, so it is slow and may get stuck in local minima. The **RBF network** (Broomhead & Lowe, 1988) uses **local Gaussian** hidden units φⱼ(x)=exp(−‖x−cⱼ‖²/2σⱼ²) that respond only near their centers, and trains in **two stages**: unsupervised selection of centers (random / k-means / OLS) followed by a **linear least-squares (pseudoinverse)** solution for the output weights — closed-form, fast, no local minima. The MLP is a global approximator, the RBF a local approximator (both universal). Both solve XOR; the RBF does so via Cover's theorem. Weaknesses: MLP — slow, local minima, overfitting; RBF — curse of dimensionality, center selection.

**中文**：两者都是带线性输出层的多层前馈网络。**MLP** 隐层用**全局 sigmoid** 单元（单调、几乎处处非零），全部权重由 **BP** 迭代训练（递归梯度下降）——慢、可能陷入局部极小。**RBF 网络**（Broomhead & Lowe, 1988）隐层用**局部高斯**单元 φⱼ(x)=exp(−‖x−cⱼ‖²/2σⱼ²)（仅中心附近响应），**两阶段**训练：无监督选中心（随机/k-means/OLS）＋输出层**线性最小二乘（伪逆）**闭式解——快、无局部极小。MLP 全局逼近、RBF 局部逼近（均为通用逼近器）；都能解 XOR（RBF 依据 Cover 定理）。弱点：MLP 慢/局部极小/过拟合；RBF 维数灾难/选中心。

| 维度 Dimension | MLP（+BP） | RBF（1988） |
|---|---|---|
| 隐层激活 Hidden activation | sigmoid，全局 global | 高斯 Gaussian，局部 local |
| 输出层 Output | 线性 linear | 线性 linear（同 ADALINE as ADALINE） |
| 训练 Training | BP 全权重迭代 all weights iteratively | 两阶段 two-stage：中心＋最小二乘 LS |
| 优化性质 Optimization | 非凸，可能局部极小 nonconvex, local minima | 输出层闭式解，无局部极小 closed-form, none |
| 逼近 Approximation | 全局 global | 局部 local |
| XOR | ✓ | ✓（Cover 定理） |
| 弱点 Weakness | 慢、过拟合 slow, overfitting | 维数灾难 curse of dimensionality |

> 出处：s124–126（激活函数）、s136–140 区段（RBF／通用逼近器）、《期中参考资料 2 页》T3。

## 1(d) SVM vs. LS-SVM

**EN**: The **SVM** (Vapnik, early 1990s) solves min ½‖w‖²+CΣξᵢ subject to **inequality constraints** yᵢ(wᵀφ(xᵢ)+b) ≥ 1−ξᵢ (hinge loss); this is a convex **QP** whose solution is **sparse** — only support vectors (αᵢ>0) determine the hyperplane. The **LS-SVM** (Suykens & Vandewalle, KU Leuven, 1999) replaces them by **equality constraints** with **squared errors**: min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ=wᵀφ(xᵢ)+b+eᵢ; the KKT conditions then reduce to a **linear system of equations** — much faster to train — at the cost of **losing sparsity** (most αᵢ≠0). Both follow structural risk minimization and both are kernelizable.

**中文**：**SVM**（Vapnik，1990s 初）解 min ½‖w‖²+CΣξᵢ，**不等式约束** yᵢ(wᵀφ(xᵢ)+b) ≥ 1−ξᵢ（hinge 损失），是凸**二次规划**，解**稀疏**——仅支持向量（αᵢ>0）决定超平面。**LS-SVM**（Suykens & Vandewalle，1999）改用**等式约束＋平方误差**：min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ=wᵀφ(xᵢ)+b+eᵢ；KKT 条件化为**线性方程组**——训练快得多，但**失去稀疏性**（多数 αᵢ≠0）。两者同属结构风险最小化、均可核化。

| 维度 Dimension | SVM | LS-SVM |
|---|---|---|
| 目标 Objective | ½‖w‖²+CΣξᵢ | ½‖w‖²+(γ/2)Σeᵢ² |
| 约束 Constraints | 不等式 inequalities（hinge） | 等式 equalities（平方误差 squared error） |
| 求解 Solver | 凸 QP（对偶 dual，0≤α≤C） | 线性方程组 linear system（快 fast） |
| 稀疏性 Sparsity | 稀疏：仅 SV | 失稀疏：多数 α≠0 most α≠0 |
| 共同 Common | 结构风险最小化 SRM、核技巧 kernel trick | 同左 same |

> 出处：s182–184（LS-SVM）、s185（双螺旋应用）、《期中参考资料 2 页》§6.10 / T4。

## 1(e) Feedforward vs. Recurrent

**EN** *(classification dimension s47: "Feedforward vs. recurrent, in terms of G and H")*: A **feedforward** network propagates signals strictly from input to output, layer by layer, **without feedback** — in terms of the aggregation rule G and the output rule H, no neuron's output H ever feeds back into the aggregation input G of a neuron in the same or an earlier layer. It therefore implements a **static mapping** x→y with no internal state; examples: perceptron, ADALINE, MLP, RBF, SVM. A **recurrent** network contains **feedback connections**: outputs are fed back (via H) into the aggregation inputs G of themselves or earlier layers, forming loops. It is a **dynamical system** with internal state; the feedback provides **short-term memory** (the fast dynamics of u, v; the weights w are the long-term memory), enabling sequence/time-dependent processing and attractor computation. Examples: MAXNET (winner-take-all subnet), ART1 (two-layer recurrent clustering network), Hopfield networks (post-midterm), Boltzmann machine; recurrent M-P networks can simulate any finite automaton. Stability of the dynamics (e.g., MAXNET requires lateral inhibition w<1/m) is a concern unique to recurrent networks.

**中文**（s47 分类维度：就 G、H 区分前馈/循环）：**前馈**网络信号自输入向输出**单向逐层**传播，**无反馈**——就聚合规则 G 与输出规则 H 而言，任何神经元的输出 H 都不会回馈到同层或前层神经元的聚合输入 G。故其为**静态映射** x→y、无内部状态；例：感知机、ADALINE、MLP、RBF、SVM。**循环**网络含**反馈连接**：输出经 H 回馈到自身或前层的聚合输入 G 形成回路，是具有内部状态的**动态系统**；反馈提供**短期记忆**（u、v 快动态；权重 w 为长期记忆），可处理序列/时变信号与吸引子计算。例：MAXNET（WTA 子网）、ART1（两层循环聚类网）、Hopfield 网（期中后）、Boltzmann 机；循环 M-P 网可模拟任意有限自动机。动力学稳定性（如 MAXNET 要求 w<1/m）是循环网络特有的问题。

| 维度 Dimension | 前馈 Feedforward | 循环 Recurrent |
|---|---|---|
| 信号流 Signal flow | 单向、无反馈 unidirectional, no feedback | 有反馈回路 feedback loops |
|（G,H 视角） | H 不回接 G H never feeds G | H 回接 G H feeds back to G |
| 动力学 Dynamics | 静态映射 static mapping | 动态系统＋内部状态 dynamical, internal state |
| 记忆 Memory | 无（每次独立） none | 短期记忆＝u,v；长期＝w short-term u,v; long-term w |
| 例子 Examples | P/ADALINE/MLP/RBF/SVM | MAXNET、ART1、Hopfield、Boltzmann |

> 出处：s47（四维度）、s62 / s64（循环网与有限自动机）。

# Question 2 · 双极 Sigmoid 最大斜率 Maximum Slope of the Bipolar Sigmoid

**Solution（EN）.**

**Step 1 — Direct differentiation.** Let q ≜ e^{−λu}; then q′ = −λq and

$$\frac{dv}{du} = \frac{\lambda q(1+q) + \lambda q(1-q)}{(1+q)^2} = \frac{2\lambda e^{-\lambda u}}{\left(1+e^{-\lambda u}\right)^2}.$$

**Step 2 — Derivative in terms of v.** From v = (1−q)/(1+q):

$$1-v = \frac{2q}{1+q}, \qquad 1+v = \frac{2}{1+q} \;\Rightarrow\; 1-v^2 = \frac{4q}{(1+q)^2}.$$

Substituting into Step 1:

$$\frac{dv}{du} = \frac{2\lambda q}{(1+q)^2} = \frac{\lambda}{2}\,(1-v^2).$$

**Step 3 — Maximization.** For every finite u, −1 < v < 1, hence 0 < 1−v² ≤ 1, with equality iff **v = 0**. Therefore dv/du ≤ λ/2, and the maximum is attained exactly when v = 0, i.e. e^{−λu}=1 ⟺ u=0:

$$\left(\frac{dv}{du}\right)_{\max} = \frac{\lambda}{2} \quad \text{at } u=0\;(v=0).\;\blacksquare$$

*Alternatives*: (i) with g(u)=dv/du, g′(u)=2λ²q(q−1)/(1+q)³ is positive for u<0 and negative for u>0, so u=0 is the global maximum, g(0)=λ/2. (ii) AM–GM: (1+q)² ≥ 4q ⟹ dv/du ≤ 2λq/(4q) = λ/2, equality iff q=1 (u=0).

**解答（中文）.**

**第 1 步·直接求导**：记 q ≜ e^{−λu}（q′=−λq），商规则得 dv/du = [λq(1+q)+λq(1−q)]/(1+q)² = **2λe^{−λu}/(1+e^{−λu})²**。

**第 2 步·用 v 表示**：由 v=(1−q)/(1+q) 得 1−v=2q/(1+q)、1+v=2/(1+q)，相乘 1−v²=4q/(1+q)²，代回得 **dv/du = (λ/2)(1−v²)**。

**第 3 步·求最大**：对一切有限 u 有 −1<v<1 ⟹ 0<1−v²≤1，等号当且仅当 **v=0**（⟺ u=0）。故 dv/du ≤ λ/2，**最大值 (dv/du)max = λ/2，在 u=0（v=0）处取得**。∎

备选：①g′(u)=2λ²q(q−1)/(1+q)³，u<0 增、u>0 减 ⟹ u=0 全局最大；②AM-GM：(1+q)²≥4q ⟹ dv/du≤λ/2。

**Remarks 备注**: f(u)=tanh(λu/2) 为双极 sigmoid（s125）；"导数用输出表示"正是 BP 双极 δ 规则 σ′=1−y² 的来源；对照单极 σ(u)=1/(1+e^{−λu})：dσ/du=λσ(1−σ)，最大斜率 λ/4 在 σ=1/2（u=0）处。λ 为增益参数，λ→∞ 时退化为 hard-limiter。

# Question 3 · RBF 解 XOR RBF Network Solves XOR

**Solution（EN）.**

The grouping {(0,0),(1,1)} vs. {(1,0),(0,1)} is the XOR grouping — **not linearly separable** in the input space (no single-layer perceptron/ADALINE can separate it). The RBF network has a Gaussian hidden layer and a linear output layer y=Σwⱼφⱼ(x)+w₀.

**Step 1 — Hidden mapping** (φᵢ(x)=exp(−‖x−cᵢ‖²)):

| input | class | hidden point (φ₁, φ₂) |
|---|---|---|
| x₁=(0,0) | 1 | (1, e⁻²) |
| x₃=(1,1) | 1 | (e⁻², 1) |
| x₂=(1,0) | 0 | (e⁻¹, e⁻¹) |
| x₄=(0,1) | 0 | (e⁻¹, e⁻¹) |

(x₂ and x₄ collapse onto the same hidden point — same class, harmless.)

**Step 2 — Linear separability in the hidden space.** Along u = φ₁+φ₂: class 1 gives 1+e⁻² ≈ 1.135; class 0 gives 2e⁻¹ ≈ 0.736; and

$$1+e^{-2} - 2e^{-1} = (1-e^{-1})^2 > 0,$$

so the two classes are **strictly linearly separable** in the hidden space. (For general σ, with t=e^{−1/(2σ²)}: 1+t² − 2t = (1−t)² > 0.)

**Step 3 — Construct the output weights and verify.** Take w₁=w₂=1, w₀=−1 (threshold θ=1; any θ ∈ (2e⁻¹, 1+e⁻²) works). Then y = f(φ₁+φ₂−1):
- x₁, x₃: φ₁+φ₂−1 = e⁻² > 0 ⟹ y = 1 ✓
- x₂, x₄: φ₁+φ₂−1 = 2e⁻¹−1 < 0 (since 2 < e) ⟹ y = 0 ✓

All four points are classified correctly — the network discriminates the data. ∎

This is an instance of **Cover's theorem**: the nonlinear Gaussian mapping casts the problem into a higher-dimensional hidden space where the classes become linearly separable, and the linear output layer (as in ADALINE) suffices.

**解答（中文）.**

该分组即 XOR 分组，输入空间**非线性可分**（单层感知机/ADALINE ✗）。RBF 网络＝高斯隐层＋线性输出层 y=Σwⱼφⱼ(x)+w₀。

**第 1 步·隐层映射**：x₁→(1, e⁻²)、x₃→(e⁻², 1)（类 1）；x₂、x₄→**同一点** (e⁻¹, e⁻¹)（类 0，同类坍缩无碍）。

**第 2 步·隐空间线性可分**：沿 u=φ₁+φ₂，类 1 之和 1+e⁻²≈1.135，类 0 之和 2e⁻¹≈0.736，**1+e⁻²−2e⁻¹=(1−e⁻¹)²>0** ⟹ 严格线性可分。（一般 σ：t=e^{−1/(2σ²)}，(1+t²)−2t=(1−t)²>0。）

**第 3 步·构造输出层并验证**：取 w₁=w₂=1、w₀=−1（θ=1，任何 θ∈(2e⁻¹,1+e⁻²) 均可）：x₁,x₃ 输出 1（e⁻²>0）✓；x₂,x₄ 输出 0（2e⁻¹−1<0，因 2<e）✓。四点全部分类正确。∎

**课程意义**：**Cover 定理**实例——非线性映射到高维隐空间后线性可分，线性输出层即可完成分类；隐空间边界为直线 φ₁+φ₂=1（数值上 2e⁻¹<1<1+e⁻² 恰好夹住两类）。

> 出处：s136–140 区段（RBF）、《期中参考资料 2 页》§5。

# Question 4 · LS-SVM 计算题 LS-SVM Computation

**Preliminaries（EN）.** The LS-SVM primal (Suykens & Vandewalle 1999, s182–184): min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ[wᵀφ(xᵢ)+b] = 1−eᵢ. The Lagrangian conditions ∂L/∂w=0 ⟹ w=Σαᵢyᵢφ(xᵢ); ∂L/∂b=0 ⟹ **Σαᵢyᵢ=0**; ∂L/∂eᵢ=0 ⟹ αᵢ=γeᵢ; ∂L/∂αᵢ=0 ⟹ yᵢ[ΣⱼαⱼyⱼK(xᵢ,xⱼ)+b]+αᵢ/γ=1. Final model:

$$\begin{bmatrix} 0 & y^T \\ y & \Omega + \gamma^{-1}I \end{bmatrix}\begin{bmatrix} b \\ \alpha \end{bmatrix} = \begin{bmatrix} 0 \\ \mathbf{1} \end{bmatrix},\qquad \Omega_{ij}=y_iy_jK(x_i,x_j).$$

**预备（中文）**：LS-SVM primal：min ½‖w‖²+(γ/2)Σeᵢ² s.t. yᵢ[wᵀφ(xᵢ)+b]=1−eᵢ。四个偏导条件（见上），最终 3×3 线性系统 [0 yᵀ; y Ω+γ⁻¹I][b;α]=[0;1]，Ωᵢⱼ=yᵢyⱼK(xᵢ,xⱼ)。

## (1) 2×2 核矩阵 Kernel Matrix

K₁₁=(0·0+1)²=1，K₂₂=(1·1+1)²=4，K₁₂=K₂₁=(0·1+1)²=1：

$$K = \begin{bmatrix} 1 & 1 \\ 1 & 4 \end{bmatrix}.$$

（对称半正定/正定 ✓ symmetric PSD ✓）

## (2) 3×3 线性系统 The Linear System

y=[1,−1]ᵀ ⟹ Ω=[[1,−1],[−1,4]]；γ=1 ⟹ Ω+γ⁻¹I=[[2,0],[0,5]]：

$$\begin{bmatrix} 0 & 1 & -1 \\ 1 & 2 & 0 \\ -1 & 0 & 5 \end{bmatrix}\begin{bmatrix} b \\ \alpha_1 \\ \alpha_2 \end{bmatrix} = \begin{bmatrix} 0 \\ 1 \\ 1 \end{bmatrix}$$

- Row 1（Σαᵢyᵢ=0）：α₁ − α₂ = 0
- Row 2（i=1）：b + 2α₁ = 1
- Row 3（i=2）：−b + 5α₂ = 1

## (3) 求解 Solution

Row 1 ⟹ α₁=α₂；代入 Row 2：b=1−2α₁；代入 Row 3：−(1−2α₁)+5α₁=1 ⟹ 7α₁=2：

$$\boxed{\alpha_1=\alpha_2=\tfrac{2}{7},\quad b=\tfrac{3}{7}}$$

（校验 check：−3/7+10/7=1 ✓）

## (4) 判决函数 Decision Function

$$g(x)=\sum_i \alpha_i y_i K(x_i,x)+b = \tfrac{2}{7}(0\cdot x+1)^2-\tfrac{2}{7}(x+1)^2+\tfrac{3}{7} = \frac{3-4x-2x^2}{7},\qquad \hat y=\mathrm{sign}\,g(x).$$

校验 Verification：g(0)=3/7>0→+1 ✓；g(1)=−3/7<0→−1 ✓。

## (5) 决策边界与正根 Decision Boundary and the Positive Root

g(x)=0 ⟹ 2x²+4x−3=0 ⟹ x=(−4±√40)/4=(−2±√10)/2：

$$\boxed{x^*=\frac{\sqrt{10}-2}{2}\approx 0.581 \text{（正根 positive root，落在 0 与 1 之间 between the two samples）}}$$

负根 negative root：(−2−√10)/2 ≈ −2.581（区间外，非有效边界 outside the data range）。

**Remarks 备注（EN）**: both αᵢ≠0 — no sparsity (every sample is an SV; contrast standard SVM), because the equality constraints force αᵢ=γeᵢ≠0. The 3×3 linear system replaces the QP — the source of LS-SVM's speed. The boundary is quadratic: the x² term comes from the degree-2 polynomial kernel with φ(x)=[1, x², √2x]ᵀ for 1-D inputs (1-D analogue of the slide-171 expansion). **中文**：α₁、α₂ 均非零——无稀疏性（人人都是 SV；等式约束 ⇒ αᵢ=γeᵢ≠0），呼应 Q1(d)；线性方程组取代 QP，是 LS-SVM 快的来源；边界为二次曲线，x² 项来自 2 次多项式核（一维 φ(x)=[1, x², √2x]ᵀ，s171 的退化情形）。
