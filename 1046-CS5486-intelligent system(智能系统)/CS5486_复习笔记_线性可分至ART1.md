# 1. Perceptron：线性可分性、收敛定理、XOR

## 练习题与标准答案

### Q1（2 分）：Define linear separability.

**标准答案：**

> A dataset is linearly separable if all data points can be correctly classified by a linear decision boundary.

**中文解释：** 如果能用一条直线（二维）、一个平面（三维）或更高维空间中的超平面，把不同类别的样本完全分开，那么数据集是线性可分的。

### Q2（4 分）：State the Perceptron Convergence Theorem.

**标准答案：**

> If the training data are linearly separable, the perceptron learning algorithm converges after a finite number of updates to weights and a threshold that correctly classify all training samples.

**中文解释：** 前提是训练数据线性可分；结论是标准感知机学习算法在有限次更新后能找到正确分类所有训练样本的权重与阈值。该定理不保证对线性不可分数据收敛。

### Q3（4 分）：Why can a single-layer perceptron not solve XOR?

**标准答案：**

> A single-layer perceptron can only form a linear decision boundary, but the XOR problem is not linearly separable. Therefore, a single-layer perceptron cannot solve XOR.

**中文解释：** XOR 的输出为 1 的两个点是对角位置，无法通过一条直线与输出为 0 的点完全分开。

## 本节重点

- 线性可分：存在一个线性决策边界把不同类别完全分开。
- 感知机收敛定理：**线性可分 → 有限次更新后收敛**。
- XOR：单层线性分类器无法解决；多层网络或非线性特征映射可以解决。

## 易错英语

- `boundry` → `boundary`
- `in finite number of step` → `in a finite number of steps`
- `XOR is not linearly separable data` → `The XOR problem is not linearly separable.`

# 2. ADALINE 与 LMS

## 练习题与标准答案

### Q1（2 分）：What does ADALINE stand for, and which learning algorithm does it use?

**标准答案：**

> ADALINE stands for Adaptive Linear Elements. It is a single-layer feedforward network of linear units trained using the LMS algorithm, also called the Delta Rule.

**中文解释：** ADALINE 是单层前馈线性网络，使用 LMS（Least Mean Squares，最小均方）算法，也称 Delta Rule（增量/δ 规则）训练。

### Q2（3 分）：Write the MSE objective and explain why gradient descent is used.

**标准答案：**

\[
E(w)=\frac12\sum_{p=1}^{N}(d_p-y_p)^2
\]

> The error function measures the difference between the desired outputs and the actual outputs. Gradient descent uses its gradient to update the weights and reduce the error.

若题目严格要求“平均平方误差”，可以写为：

\[
\operatorname{MSE}(w)=\frac1N\sum_{p=1}^{N}(d_p-y_p)^2
\]

**中文解释：** 前一个形式是半平方误差和；平均平方误差通常再除以样本数。因子 \(1/2\) 是为了求导时抵消平方产生的系数 2。梯度指示误差函数增长最快的方向，梯度下降沿负梯度更新权重。

### Q3（3 分）：Write the LMS batch weight-update formula and define the learning rate.

误差定义：

\[
e_p=d_p-y_p,\qquad y_p=w^Tx_p
\]

**标准答案：**

\[
\nabla E(w)=-\sum_{p=1}^{N}e_px_p
\]

\[
\boxed{w^{new}=w^{old}+\eta\sum_{p=1}^{N}e_px_p}
\]

> The learning rate is denoted by \(\eta\). In batch LMS learning, the weights are updated by \(w^{new}=w^{old}+\eta\sum_p e_px_p\), where \(e_p=d_p-y_p\).

**中文解释：** 不能把误差函数本身直接当作梯度。更新权重需要计算误差函数对权重的导数；批量 LMS 汇总所有训练样本的误差信号与输入向量。

### Q4（2 分）：State one difference between Perceptron and ADALINE.

**标准答案：**

> Perceptron uses a hard-limit activation function and a perceptron learning rule. ADALINE uses a linear activation function during learning and the LMS algorithm to minimize the mean squared error using gradient descent.

**中文解释：** 感知机根据分类错误进行更新；ADALINE 在学习时使用线性输出，并通过梯度下降最小化均方误差。二者都不能单独用线性边界解决 XOR。

## 本节重点

- ADALINE = Adaptive Linear Elements。
- LMS = Delta Rule；目标是最小化平方误差。
- 梯度下降：\(w^{new}=w^{old}-\eta\nabla E(w)\)。
- 对本节误差定义，批量更新可写为：\(w^{new}=w^{old}+\eta\sum_p e_px_p\)。
- \(\eta\) 是学习率；不要把它写成与样本数 \(N\) 容易混淆的字母 `n`。

# 3. Backpropagation（反向传播）

本节采用约定：误差项以“期望输出减实际输出”为基础，因此权重更新公式使用加号。不同教材可能使用不同的 delta 符号约定，公式符号必须前后一致。

## 练习题与标准答案

### Q1（2 分）：What is backpropagation, and what is its main purpose?

**标准答案：**

> Backpropagation is a recursive gradient-descent learning algorithm for multilayer feedforward neural networks. It computes error gradients backward through the network to minimize the mean squared error.

**中文解释：** 反向传播是一种多层前馈网络的梯度下降训练算法，借助链式法则从输出层向隐藏层计算误差梯度。

### Q2（3 分）：Write the sigmoid derivative and the output-layer delta formula.

Sigmoid：

\[
f(s)=\frac{1}{1+e^{-s}}
\]

导数：

\[
\boxed{f'(s)=f(s)(1-f(s))=y(1-y)}
\]

输出层误差项：

\[
\boxed{\delta_k=(d_k-y_k)y_k(1-y_k)}
\]

**中文解释：** \(s\) 是神经元净输入，\(y=f(s)\) 是输出。输出误差项等于预测误差乘以激活函数导数。

### Q3（3 分）：Write the hidden-layer delta formula and explain the summation.

**标准答案：**

\[
\boxed{\delta_j=z_j(1-z_j)\sum_k w_{jk}\delta_k}
\]

> The summation combines the error contributions from all connected output neurons.

**中文解释：** 隐藏层一个神经元会影响多个输出神经元，因此要将它连接到的输出端误差信号按权重汇总，再乘以隐藏层自身的 Sigmoid 导数。

### Q4（2 分）：What is the difference between feedforward and backpropagation? Does backpropagation mean that the network is recurrent?

**标准答案：**

> Feedforward describes the direction of signal flow from the input layer to the output layer. Backpropagation is a learning algorithm that propagates error gradients backward to update the weights. It does not mean that the network is recurrent.

**中文解释：** 前馈描述网络结构中的信号流向；反向传播描述训练时梯度的计算过程。误差反向传递不意味着网络具有循环连接。

## 本节重点

BP 四步骤：

1. 前向计算输出。
2. 计算误差。
3. 从输出层向隐藏层反向计算梯度。
4. 更新权重，反复迭代。

常见局限：迭代训练可能受到局部极小值影响；网络存在理想权重，不代表 BP 一定能找到该权重。

# 4. RBF Networks（径向基函数网络）

## 练习题与标准答案

### Q1（2 分）：What is an RBF, and what is the most commonly used RBF?

**标准答案：**

> A radial basis function produces a high activation when the input is close to its center and a low activation when the input is far from its center. The Gaussian RBF is the most commonly used radial basis function.

**中文解释：** 常见高斯 RBF 根据输入与中心之间的距离产生响应；距离近时输出大，距离远时输出趋近于零。

### Q2（2 分）：Describe the hidden and output layers of an RBF network.

**标准答案：**

> The hidden layer uses radial basis functions, while the output layer uses a linear activation function.

**中文解释：** RBF 隐藏层不是 Sigmoid 层；输出层为线性激活。

### Q3（3 分）：Write the Gaussian RBF formula and define its variables.

\[
\boxed{\phi_j(x)=\exp\left(-\frac{\|x-c_j\|^2}{2\sigma_j^2}\right)}
\]

- \(x\)：输入向量。
- \(c_j\)：第 \(j\) 个 RBF 的中心。
- \(\sigma_j\)：宽度参数。

**标准英文答案：**

> The Gaussian RBF is \(\phi_j(x)=\exp(-\|x-c_j\|^2/(2\sigma_j^2))\), where \(x\) is the input vector, \(c_j\) is the center, and \(\sigma_j\) is the width parameter.

### Q4（3 分）：Why can an RBF network solve XOR although a single-layer perceptron cannot?

**标准答案：**

> An RBF network maps the input data into a new feature space, where the XOR data become linearly separable. A linear output layer can then classify the data correctly.

**中文解释：** RBF 先把数据映射到新特征空间，使 XOR 数据在线性意义上可分，再用线性输出层分类。

## 本节重点

- 两层结构：RBF 隐藏层 + 线性输出层。
- 高斯 RBF 关键公式中要有 `exp`、负号、平方距离和 \(\sigma^2\)。
- RBF 是一种网络结构；Backpropagation 是一种学习算法，二者不能混为一谈。

# 5. SVM（支持向量机）

## 练习题与标准答案

### Q1（3 分）：For labels \(y_i\in\{-1,+1\}\), write the hard-margin SVM objective and constraints.

**标准答案：**

\[
\boxed{\min_{w,b}\frac12\|w\|^2}
\]

subject to

\[
\boxed{y_i(w^Tx_i+b)\geq1,\quad \forall i}
\]

两条间隔边界：

\[
w^Tx+b=+1,\qquad w^Tx+b=-1
\]

间隔宽度：

\[
\boxed{\text{Margin}=\frac{2}{\|w\|}}
\]

**中文解释：** 最大化间隔等价于最小化 \(\frac12\|w\|^2\)，并要求所有训练样本满足分类约束。注意间隔宽度分母是范数 \(\|w\|\)，不是向量 \(w\) 本身。

### Q2（2 分）：What are support vectors, and why are they important?

**标准答案：**

> Support vectors are the training samples closest to the decision boundary. They determine the maximum-margin hyperplane and play a key role in the SVM solution.

**中文解释：** 支持向量是对最终间隔边界起关键作用的训练样本。硬间隔情况下，它们位于间隔边界上；软间隔情况下也可能落在间隔内部。

### Q3（2 分）：What are slack variables, and what does parameter \(C\) control?

**标准答案：**

> Soft-margin SVM introduces slack variables to allow violations of the margin constraints. The parameter \(C\) controls the trade-off between maximizing the margin and penalizing constraint violations.

软间隔目标：

\[
\min_{w,b,\xi}\frac12\|w\|^2+C\sum_i\xi_i
\]

约束：

\[
y_i(w^Tx_i+b)\geq1-\xi_i,\qquad \xi_i\geq0
\]

**中文解释：** 松弛变量 \(\xi_i\) 允许样本违反间隔约束。较大的 \(C\) 更重视惩罚违反约束；较小的 \(C\) 相对更重视较大的间隔。

### Q4（3 分）：Define a kernel function and explain the kernel trick.

**标准答案：**

\[
\boxed{K(x,z)=\phi(x)^T\phi(z)}
\]

> A kernel function computes the inner product of two feature vectors in an expanded feature space. The kernel trick allows SVM to classify nonlinearly separable data without explicitly computing the feature mapping.

**中文解释：** 核函数间接计算映射后特征向量的内积，不需要明确构造高维向量，因此可在更高维空间中完成线性分类。

## 本节重点

- 判别函数：\(g(x)=w^Tx+b\)。边界：\(w^Tx+b=0\)。
- 最大间隔：\(2/\|w\|\)。
- 硬间隔目标：最小化 \(\frac12\|w\|^2\)，约束 \(y_i(w^Tx_i+b)\geq1\)。
- 支持向量决定最优边界。
- 软间隔用松弛变量处理噪声和约束违反；\(C\) 平衡间隔与违反约束的惩罚。
- 核技巧：\(K(x,z)=\phi(x)^T\phi(z)\)，避免显式计算特征映射。

# 6. 无监督学习与竞争学习

## 无监督学习：基本概念

无监督学习不依赖每个输入样本对应的目标标签，而是从输入数据中学习结构，例如聚类。课件介绍了竞争学习（competitive learning）和聚类（clustering）。

**标准英文答案：**

> Unsupervised learning discovers structure in data without using target labels. Clustering groups similar data according to a chosen similarity measure.

**中文解释：** 无监督学习从没有目标标签的数据中发现结构；聚类是按某种相似度度量把相似样本归为一组。聚类通常没有唯一答案，其结果依赖相似度定义与设计选择。

## 竞争学习（Competitive Learning）

核心思想：多个神经元竞争对输入作出响应，通常由响应最强的神经元获胜，再调整其权重。

**常见流程：**

1. 随机初始化权重与阈值。
2. 选取一个输入样本。
3. 计算各候选神经元与输入之间的响应（课件以权重与输入的内积表示）。
4. 选出响应最大的获胜神经元。
5. 更新获胜神经元的权重，反复迭代直至权重收敛。

**标准英文答案：**

> In competitive learning, neurons compete to respond to an input pattern. The winning neuron is selected according to its response, and its weights are adapted. Repeating this process can form clusters of similar input patterns.

**中文解释：** 竞争学习通过“选赢家—更新赢家”的方式，让不同神经元逐渐对不同的输入模式产生响应，从而形成聚类。

# 7. MAXNET 与 k-WTA

## MAXNET

MAXNET 是一个用于选择最大输入的竞争子网络，采用 **winner-takes-all（赢家通吃）** 机制。它通过侧向抑制保留最大响应并压低其他响应，常用作其他网络的输出层。

课件给出的特点：

- 循环（recurrent）网络。
- 自连接为兴奋性，权重为 1。
- 不同神经元之间有侧向抑制，权重为 \(-w\)，课件给出的条件是 \(w<1/m\)，其中 \(m\) 是输出神经元数量。
- 竞争迭代使最大响应胜出，其余响应被压低。

**标准英文答案：**

> MAXNET is a recurrent winner-takes-all network. It uses self-excitatory connections and lateral inhibitory connections to keep the largest input and suppress the other responses.

**中文解释：** MAXNET 的作用是从多个候选响应中选出最大者，而不是对数据进行一般意义上的多类别聚类。

## k-WTA（k-Winners-Take-All）

k-WTA 表示 **k 个赢家通吃**：选择响应最大的 k 个神经元，使它们胜出，而其他神经元受到抑制。

与 MAXNET 的区别：

- MAXNET：选择 1 个最大响应。
- k-WTA：选择前 k 个最大响应。

课件指出，使用 Heaviside 激活函数的 k-WTA 模型可全局稳定，并在有限时间内收敛至 k-WTA 解。

**标准英文答案：**

> The k-WTA model selects the k neurons with the largest responses and suppresses the others. With a Heaviside activation function, the course notes state that the model is globally stable and converges to a k-WTA solution in finite time.

# 8. ART1 网络

## ART1 是什么？

ART1（Adaptive Resonance Theory 1）由 Stephen Grossberg 在 1970 年代提出。根据课件，ART1：

- 用于二进制数据聚类。
- 类别数量事先未知。
- 是双层循环神经网络。
- MAXNET 充当输出层，用于选择当前最合适的候选类别。
- 具有双向自适应连接：bottom-up（自底向上）与 top-down（自顶向下）。

**标准英文答案：**

> ART1 is a two-layer recurrent neural network used to cluster binary data when the number of clusters is unknown. MAXNET serves as its output layer, and the network uses adaptive bottom-up and top-down connections.

## ART1 聚类过程

按课件流程可记为：

1. 初始化连接权重。
2. 输入一个二进制模式，计算候选类别的响应。
3. 使用 MAXNET 选出最佳匹配的候选类别。
4. 执行 vigilance（警戒）测试。
5. 如果匹配程度达到要求，则接受该类别并更新连接权重；如果未通过，则禁用该候选神经元并继续寻找下一个候选类别。

**标准英文答案：**

> ART1 first selects the best-matching category using MAXNET. It then performs a vigilance test. If the match satisfies the vigilance requirement, the category is accepted and the weights are adapted; otherwise, the candidate is rejected and another category is tested.

## Vigilance parameter（警戒参数）

警戒参数通常记为 \(\rho\)，取值范围是 \([0,1]\)。它控制聚类的敏感度与颗粒度。

- **低警戒阈值：** 容许较大差异，通常形成较少、较大的簇。
- **高警戒阈值：** 只接受更相似的样本，通常形成更多、较小、更均一的簇。

**标准英文答案：**

> The vigilance parameter controls the granularity of ART1 clustering. A low vigilance threshold accepts larger mismatches and tends to form fewer, larger clusters. A high threshold allows only smaller mismatches and tends to form more, smaller, homogeneous clusters.

**中文解释：** 警戒参数越高，系统对样本相似度要求越严格，聚类更细；参数越低，更多差异较大的样本也可能被分到同一个簇。

> 注：课件文本提取没有完整显示 ART1 vigilance test 的具体不等式，因此此笔记不把公式硬写成课件原式。复习时应以课堂幻灯片原图中该公式的符号与归一化方式为准。

# 9. 易混淆点速记表

| 概念对比 | 区别 |
|---|---|
| Perceptron vs. ADALINE | 硬阈值/分类错误更新 vs. 线性学习输出/LMS 最小化 MSE |
| Feedforward vs. Backpropagation | 网络信号结构方向 vs. 训练时梯度反向计算 |
| BP vs. Recurrent Network | BP 不意味着网络循环；前者是算法，后者是连接结构 |
| RBF vs. BP | RBF 是网络结构；BP 是学习算法 |
| RBF vs. sigmoid hidden layer | RBF 隐藏层用径向基函数；课件中的 BP 网络重点使用 sigmoid |
| SVM margin vs. constraints | 间隔宽度为 \(2/\|w\|\)；硬间隔约束为 \(y_i(w^Tx_i+b)\geq1\) |
| Support vectors | 对最优边界起关键作用的训练样本 |
| Hard margin vs. soft margin | 不容许违反约束 vs. 通过松弛变量容许违反约束 |
| SVM \(C\) | 在间隔大小与约束违反惩罚之间进行权衡 |
| MAXNET vs. k-WTA | 选出 1 个赢家 vs. 选出 k 个赢家 |
| ART1 vigilance | 低阈值容忍更多差异；高阈值形成更细、更同质的簇 |

## 最后冲刺：必须会默写的 8 组公式/关键词

1. **Perceptron convergence:** linearly separable → finite updates → correct classification.
2. **LMS batch update:** \(w^{new}=w^{old}+\eta\sum_p e_px_p\)，其中 \(e_p=d_p-y_p\)。
3. **Sigmoid derivative:** \(f'(s)=y(1-y)\)。
4. **BP output delta:** \(\delta_k=(d_k-y_k)y_k(1-y_k)\)（本笔记采用的符号约定）。
5. **Gaussian RBF:** \(\phi_j(x)=\exp(-\|x-c_j\|^2/(2\sigma_j^2))\)。
6. **Hard-margin SVM:** \(\min \frac12\|w\|^2\)，s.t. \(y_i(w^Tx_i+b)\geq1\)。
7. **SVM margin/kernel:** \(2/\|w\|\)；\(K(x,z)=\phi(x)^T\phi(z)\)。
8. **ART1 vigilance:** low threshold → fewer/larger clusters; high threshold → more/smaller homogeneous clusters.
