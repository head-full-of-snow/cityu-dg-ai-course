## 三、实际授课内容（从 324 页合并讲义提取的完整结构）

1. **导论 + 神经网络发展史**：Wiener、McCulloch、Widrow、Zadeh、Werbos、Kohonen、Hopfield、Hinton
2. **McCulloch-Pitts 神经元**、阈值逻辑、逻辑门实现
3. **Perceptron**：迭代学习、误差地形、XOR 问题、权重空间区域数
4. **多层前馈网络**：Sigmoid 激活、局部极小、过拟合
5. **RBF 网络**（径向基函数）、Functional Link Network
6. **线性判别 + SVM**：最大间隔、对偶问题、KKT 条件、核技巧、QP 求解
7. **MAXNET / kWTA**（侧抑制竞争网络）
8. **ART1**（Grossberg 自适应共振，二进制聚类）
9. **Hopfield 网络**：外积规则、联想记忆、能量函数、作优化器
10. **BAM**（双向联想记忆）
11. **模拟退火 + Boltzmann 机**
12. **SOM**（Kohonen 自组织映射）
13. **Echo State Network**（储备池计算）
14. **模糊逻辑**：Type-1 → Type-2 模糊集、模糊运算
15. **演化计算**：EP/ES/GA 遗传算法、流程图与优化过程
16. **粒子群优化 PSO**、全局优化

## 九、备考建议（基于以上情报）
