## 一、Round 1：感知机与 ADALINE

### Q1. Perceptron Convergence Theorem（3 分）

**题目**

Explain the perceptron convergence theorem.

**标准英文答案**

> The perceptron convergence theorem states that if the training data are linearly separable, the perceptron will find a suitable set of weights and threshold after a finite number of updates.

**中文解释**

如果训练数据线性可分，感知机经过有限次权重和阈值更新，就能找到能够正确分类数据的参数。

**核心知识点**

- `linearly separable`：线性可分。
- `convergence theorem`：收敛定理。
- `a finite number of updates`：有限次更新。
- 定理的重点是：在线性可分的条件下，感知机可以在有限次更新后收敛。
- 不要只描述感知机的输出规则；题目问收敛定理时，必须说明“线性可分”和“有限次更新”。

**感知机输出规则补充**

设加权输入为：

\[
u=\sum_i w_i x_i
\]

则阈值输出可写为：

\[
y=
\begin{cases}
1, & u\geq\theta\\
0, & u<\theta
\end{cases}
\]

感知机使用 `hard-limit activation function`（硬阈值激活函数）。

**容易混淆的概念**

输出规则说明如何得到分类结果；收敛定理说明在什么条件下，学习过程能够在有限次更新后找到合适的参数。

### Q2. Perceptron vs. ADALINE（3 分）

**题目**

What is the main difference between the learning rules of the perceptron and ADALINE?

**标准英文答案**

> The perceptron uses a hard-limit activation function and updates its weights based on classification errors. ADALINE uses a linear activation function during learning and applies the LMS (Delta) rule to minimize the mean squared error using gradient descent.

**中文解释**

- **Perceptron（感知机）**：使用硬阈值激活函数，根据分类错误更新权重。
- **ADALINE**：学习时使用线性输出，并通过 LMS / Delta Rule 和梯度下降来最小化均方误差（MSE）。

**核心知识点**

| 比较项目 | Perceptron | ADALINE |
|---|---|---|
| 激活 / 学习时的输出 | Hard-limit activation | Linear activation during learning |
| 学习规则 | Perceptron learning rule | LMS / Delta Rule |
| 更新依据 | Classification errors | Linear output error |
| 优化方法 | 不使用梯度下降 | Gradient descent |
| 误差目标 | 分类结果是否正确 | Mean squared error (MSE) |

**易背对比句**

> The perceptron updates weights based on classification errors. ADALINE uses gradient descent to minimize the mean squared error.

**补充理解**

ADALINE 在学习时使用线性输出计算误差；实际分类时可以再使用阈值进行判断。

### Q3. Why can’t a single-layer perceptron solve XOR?（4 分）

**题目**

Why can a single-layer perceptron not solve the XOR problem?

**标准英文答案**

> A single-layer perceptron can only learn a linear decision boundary. However, the XOR problem is not linearly separable. Therefore, a single-layer perceptron cannot correctly classify all XOR inputs.

**中文解释**

单层感知机只能学习线性决策边界，而 XOR（异或）问题不是线性可分的。因此，单层感知机无法正确分类所有 XOR 输入。

**核心知识点**

- `single-layer perceptron`：单层感知机。
- `linear decision boundary`：线性决策边界。
- `not linearly separable`：非线性可分。
- XOR 的障碍不是“权重数量不足”，而是无法用单个线性决策边界将两类样本分开。

**易背逻辑链**

> Single layer → linear decision boundary → XOR is not linearly separable → cannot classify correctly.

## 二、Round 2：权重更新与 LMS

### Q4. Perceptron Weight Update Rule（3 分）

**题目**

Given \(e=d-y\), write the perceptron weight update rule and explain the meaning of \(\eta\).

**标准英文答案**

> The weight update rule is \(w_i(t+1)=w_i(t)+\eta e x_i\), where \(\eta\) is the learning rate. It controls the size of weight updates and is usually positive.

**中文解释**

- \(w_i(t)\)：第 \(i\) 个权重的当前值。
- \(w_i(t+1)\)：更新后的权重。
- \(\eta\)：学习率（learning rate），通常为正数。
- \(e=d-y\)：目标输出与实际输出之间的误差。
- \(x_i\)：第 \(i\) 个输入。

学习率控制每次权重更新的幅度。学习率较大时，通常每次更新幅度更大，但不保证训练一定更快收敛。

**公式**

\[
w_i(t+1)=w_i(t)+\eta e x_i
\]

**英语表达**

- `learning rate`：学习率。
- `controls the size of weight updates`：控制权重更新的幅度。
- `weight update rule`：权重更新规则。

**注意**

这里使用 \(\eta\) 表示学习率，避免使用 \(n\)，因为 \(n\) 常被用来表示样本数量。

### Q5. Why does ADALINE use LMS?（3 分）

**题目**

Why does ADALINE use the LMS rule? What quantity does it minimize?

**标准英文答案**

> ADALINE uses the LMS rule to adjust its weights and minimize the mean squared error (MSE) between the desired outputs and the linear outputs.

**中文解释**

ADALINE 使用 LMS 规则调整权重，使目标输出与线性输出之间的均方误差尽可能小。

**误差函数**

\[
E(w)=\frac{1}{2}\sum_p(d_p-w^T x_p)^2
\]

其中：

- \(d_p\)：第 \(p\) 个样本的目标输出。
- \(w^T x_p\)：模型对该样本的线性输出。
- \(E(w)\)：平方误差目标函数。

**核心记忆**

> LMS → adjust weights → minimize MSE.

### Q6. Compare Perceptron and ADALINE（4 分）

**题目**

State two differences between Perceptron and ADALINE in terms of learning or error calculation.

**标准英文答案**

> The perceptron uses the perceptron learning rule and updates weights based on classification errors. ADALINE uses the LMS rule and gradient descent to minimize the mean squared error (MSE).

**中文解释**

- Perceptron 根据分类错误更新权重。
- ADALINE 使用 LMS 学习规则和梯度下降，最小化均方误差 MSE。

**对比表**

| 比较项目 | Perceptron | ADALINE |
|---|---|---|
| 学习规则 | Perceptron learning rule | LMS / Delta Rule |
| 误差依据 | Classification errors | Linear output errors |
| 是否使用梯度下降 | No | Yes |
| 目标 | Correct classification | Minimize MSE |

\[

\]

## 五、30 秒考前速记

1. **Perceptron convergence:** If data are linearly separable, it converges after a finite number of updates.
2. **Perceptron learning:** Hard limit; updates weights based on classification errors.
3. **ADALINE learning:** Linear output; LMS / Delta Rule; gradient descent; minimize MSE.
4. **XOR:** Not linearly separable; a single-layer perceptron cannot classify it correctly.
5. **Learning rate:** Controls the size of weight updates.
