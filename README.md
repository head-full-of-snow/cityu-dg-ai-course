## 🚀 快速开始

```bash
# 克隆仓库（约几百 MB，耐心等待）
git clone git@github.com:head-full-of-snow/cityu-dg-ai-course.git

# 或直接在网页端 Code → Download ZIP
```

- **找复习资料**：进入课程目录 → `期中考试/` 或 `期末考试/`，优先看 MD 源文件
- **找中文翻译**：CS5487 见 `期中考试/课件翻译MD/`；1105 见各周 `_zh` 文件；CS5486 见根目录 `CS5486Slides_全部课件.md`
- **打印 Cheat Sheet**：各 `期中考试/` 目录下提供排版好的 HTML / PDF 打印版
