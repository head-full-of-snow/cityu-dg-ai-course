1 卷积与滤波 Convolution

G[i,j] = Σu,v=−k…k H[u,v] · I[i−u, j−v]
  • 卷积：kernel 先旋转 180°（行、列都翻转）；互相关 cross-correlation 不翻转。题目写 "convolution" → 必须先翻转！
  • 步骤：①核转180° ②核中心对准目标像素 ③与覆盖块对应相乘求和 ④边界处理：zero 补0（默认）／clamp 复制／wrap 环绕／mirror 镜像
  • 线性滤波满足叠加性+平移不变；中值、阈值属于非线性滤波，不能用卷积实现
例1　I块=[[1,2],[3,4]]，核=[[0,1],[1,0]]（对称核，翻转不变）→ 0·1+1·2+1·3+0·4 = 5
例2　I=[0,10,20,30,0]，核=[1,2,3]（原点居中）：相关=1·10+2·20+3·30=140；卷积(翻成[3,2,1])=3·10+2·20+1·30=110——非对称核两者不同！
例3　I 3×3=[[1,2,3],[4,5,6],[7,8,9]]，box核全1/9，zero-pad：中心=(1+…+9)/9=5；左上角=(0+0+0+0+1+2+0+4+5)/9=12/9≈1.33
滤波器作用备注
Box/Mean（全1/9，滑动平均）去噪、模糊有条纹伪影；1D 版=[1/3,1/3,1/3]
Gaussian 高斯去噪、平滑中间大四周小，权重和=1，最常用
Sharpen 锐化 [[0,−1,0],[−1,5,−1],[0,−1,0]]锐化=原图+4·(原图−邻居)≈原图−拉普拉斯；Laplacian=[[0,1,0],[1,−4,1],[0,1,0]]
Median 中值去椒盐噪声取窗口中值；非线性！不能用卷积实现
Bilateral 双边保边平滑空间距离+亮度距离双权重
Threshold 阈值 I>T→255 否则 0二值化非线性（lec01 "Filters: Thresholding"）
h(u,v) = 1/(2πσ²) · e−(u²+v²)/2σ²　σ大→更模糊、核更宽、权重更平
  • 可分离：2D高斯 = 两个1D高斯依次卷积（省计算）
  • 结合律：(h₁∗h₂)∗I = h₁∗(h₂∗I)；卷积还满足交换律 f∗g=g∗f

2 边缘检测 Edges / Canny

∇f=[∂f/∂x, ∂f/∂y]　‖∇f‖=√(gx²+gy²)　θ=atan2(gy,gx)　边缘方向 ⊥ 梯度方向
例　gx=3, gy=4 → 幅值=√(9+16)=5；θ=atan2(4,3)≈53.1°；边缘方向≈53.1°−90°=−36.9°
  • 离散求导 = 有限差分 = 线性滤波 [−1,0,1]。例 I=[10,12,15] → 中心 gx=15−10=5
  • 边缘来源：深度/表面法线/反射率（颜色）突变、遮挡边界；理想模型：阶跃 step／斜坡 ramp／屋顶 roof

3 重采样 · 混叠 · 插值 Aliasing / Interpolation

  • 混叠原因：采样率 < 2×最高频率。Nyquist：采样率 ≥ 2×最高频率；直接丢行丢列(sub-sampling)→摩尔纹/锯齿
  • 修复：先高斯低通再降采样（顺序不能反：先采样后模糊无效，高频已折叠）；经验：模糊半径≈降采样倍数/2
  • 时域混叠同因：马车轮效应/直升机桨"倒转"（帧率低于旋转频率）
  • 高斯金字塔 = 高斯模糊+隔行隔列降采样反复；空间开销 1+1/4+1/16+…=4/3×原图
  • quiz原题：混叠原因（Nyquist 采样定理）+两角度缓解 → ①先高斯低通再降采样 ②提高采样率/分辨率
  • 现代方法名词：多帧超分辨率（Google Pixel 3 Super Res Zoom，利用手抖做亚像素采样）

4 Harris 角点 ★quiz

E(u,v) ≈ [u v] H [u;v] = Au²+2Buv+Cv²，　H = Σ(x,y)∈W
Ix²IxIy
IxIyIy²
（A=ΣIx²，B=ΣIxIy，C=ΣIy²，高斯窗加权）
  • 直觉：flat 任意方向无变化；edge 沿边缘方向无变化；corner 任意方向移动都大变化 → 好特征
  • 特例：水平边缘 Ix=0 → H=diag(0,C)；垂直边缘 Iy=0 → H=diag(A,0)（λ 一大一小 → edge）
  • 判分原理：希望小位移的 E 在所有方向都大 → 即 λmin 要大；xmax=E 增加最快方向（特征向量），λmax=该方向增幅
特征值 λ₁,λ₂区域
都小Flat 平坦（E 各方向都小）
一个≫另一个Edge 边缘（一个方向大一个方向小）
都大且相近Corner 角点（椭圆越圆越胖→角点；特征向量=主轴方向，λ=轴长²）
f = det H − k·(trace H)²，k 用题目值（Tutorial 0.04／quiz 0.05）　或　f = det H / trace H（课件38页版）
  • 步骤：det=h₁₁h₂₂−h₁₂²；trace=h₁₁+h₂₂ → 代 f → 阈值(0.05·Rmax)+NMS（局部极大才保留；流程与代码见 P2 §6）
例1　H=[[2,0],[0,3]]：det=6, trace=5, f=6−0.04×25=5 > 0 → 角点
例2　H=[[5,0],[0,0.1]]：det=0.5, trace=5.1, f=0.5−1.04<0 → 边缘
例3　H=[[3,1],[1,3]]：det=8, tr=6, λ=(6±√4)/2=4, 2（都大→corner）；f=8−0.04×36=6.56
quiz真题　H=[[800,100],[100,750]]：tr=1550, det=590000；λ=(1550±√42500)/2≈878, 672（都大且近→corner）；R=590000−0.05×1550²=469875≫0 → 强角点（k=0.05）

5 描述子与匹配 ★quiz

5.1 流程与两大要求

  • 流程 detect → describe → match；描述子两要求：invariance 不变性（变换下描述子不变）+ discriminability 可区分性（不同点描述子足够不同/唯一）
  • 两个反例（选择题）：描述子恒为 0 → 对一切变换不变但零可区分；5×5 轴对齐窗口 → 只平移不变（旋转/尺度/光照都会变）→ 不变性与可区分性要折中
  • 实用描述子通常能抗：平移、2D 旋转、尺度；有限的 3D 旋转（SIFT~60°）、有限仿射、有限光照变化

5.2 旋转不变的做法

  • 求 patch 主方向：取 H 的 λmax 对应特征向量 xmax；或（更好）平滑后梯度方向；再按该角旋转 patch 后描述

5.3 MOP（Multiscale Oriented Patches）

  • ①40×40 窗 ②缩到 1/5（先预滤波）③旋转到主方向水平（旋转不变关键）④采样 8×8 ⑤减均值、除以标准差归一化（光度不变）

5.4 SIFT（维度计算必考）

  • 基本做法：①取 16×16 窗 ②每像素算边缘方向 = 梯度方向−90° ③阈值剔除弱边缘 ④对存活边缘做方向直方图 ⑤把最大 bin 循环移到首位（旋转不变）
  • 完整版：16×16 分 4×4 cell，每 cell 8 方向 bin 梯度直方图 → 4×4×8=128 维
  • 性质：抗~60° 视角变化、显著光照变化（甚至昼/夜），<1s，代码多

5.5 其他描述子（认名字+一步流程）

  • HOG（Dalal/Triggs，滑窗行人检测）：①[-1,0,1] 求梯度幅值/方向 ②8×8 cell 做 9 bins(0–180°) 直方图、按幅值加权 ③2×2 cell 组成 block 做 L2 归一化（抗光照）
  • ORB = oFAST（FAST 检测 + Harris 度量排序 + 强度质心定向）+ rBRIEF（256 bit 二值强度对比较，采样模式随主方向旋转）；实时 SLAM
  • FREAK：视网膜启发二值描述子，实时；Haar-like：水平/垂直亮度差模板

5.6 匹配与距离

  • 对 I₁ 每个特征在 I₂ 找最近邻：L2/SSD ‖f₁−f₂‖，kd-tree/FLANN 加速
  • Lowe 比值检验：d₁ < 0.75·d₂ 才接受；d₁≈d₂ → 歧义拒绝（讲义例 0.8，答题写 0.75 注明 Tutorial 代码）
  • SSD vs 比值距离：不改变谁是最近邻，只改变距离数值/排序与阈值过滤结果；比值距离对歧义匹配给出大值
例　d₁=50, d₂=80 → 50 < 0.75×80=60 ✓ 保留；若 d₁=58, d₂=62 → 58 < 46.5? ✗ 拒绝（歧义）

5.7 匹配评价 TPR/FPR/ROC ★quiz

  • TP=阈值后保留的正确匹配；FP=阈值后保留的错误匹配；TPR=TP/总正确匹配数（recall），FPR=FP/总错误匹配数
quiz原题　1000 匹配（800 对/200 错），某阈值保留 600 对、100 错 → TPR=600/800=75%，FPR=100/200=50%。全保留真阳→阈值最大（TPR=FPR=1）；零假阳→阈值最小（但无匹配留下）
  • ROC：扫全部阈值画 TPR vs FPR；AUC=曲线下面积，=1 完美，越大越好（综合评价，与单一阈值选择无关）

5.8 特征的应用（lec06 收尾页）

  • 图像对齐/拼接 mosaics、3D 重建、运动跟踪、物体识别、图像检索 indexing、机器人导航

  • Harris（T03）：Ix=cv2.Sobel(img,CV_64F,1,0)；Iy=…(0,1)→Ix²、Iy²、Ix·Iy 各自 cv2.GaussianBlur 加权 → R=det−k·tr²；threshold=0.05·R.max()；NMS：cv2.dilate(R) 取邻域最大，R==dilate(R) 即局部极大

7 简答背诵（一句话）

  1. 卷积前翻核？——卷积定义（满足结合律等性质）；互相关不翻。
  2. 先平滑再求导？——噪声放大导数；结合律合并成高斯导数核。
  3. Canny 双阈值？——单阈值要么断边要么多噪；强边锚定+弱边续接。
  4. 降采样前模糊？——低于Nyquist采样混叠；低通先去高频。
  5. 描述子减均值除std？——消除光照强度/对比度变化影响。
  6. SIFT 旋转不变？——主方向归一（最大bin移到首位）。
  7. 比值检验好在哪？——两候选距离接近=歧义，比值可识别剔除。
  8. 角点为什么是好特征？——任意方向小位移都引起大变化（λ₁、λ₂都大），可重复、信息量大。
  9. Harris 为何用 det/trace 不解特征值？——R=det−k·tr² 是 λmin 的近似，免开方求解。
  10. 描述子恒 0 说明什么？——完全不变但零可区分；不变性与可区分性需折中。
  11. 5×5 窗口描述子不变什么？——只平移不变；旋转/尺度/光照都变。
  12. SSD 与比值距离改变最佳匹配吗？——不改变最近邻是谁，只改变排序与过滤。
  13. 阈值取最大/最小？——最大→全保留(TPR=FPR=1)；最小→全拒绝(无匹配)。
  14. AUC 意义？——扫全部阈值的综合性能，面积越大越好，1 为完美。

8 易错辨析 & 填空高频空 判断对错自测

  • ①卷积必须翻核、互相关不翻（题干写 convolution 就翻）②中值去椒盐但非线性、不能用卷积；高斯去高斯噪声 ③σ大→更模糊；Canny σ小→精细边缘、σ大→大尺度边缘 ④梯度方向=变化最快方向，边缘⊥梯度 ⑤尺度↑ 边缘可移动/合并，不会一分为二 ⑥Lowe 比值不改变最近邻是谁，只滤"两候选都近"的歧义 ⑦非对称核的卷积≠相关（见 P1 例2）
填空：f=det−【k】·tr²（k 取题目值 0.04~0.06）｜Lowe：d₁<【0.75】·d₂｜SIFT=4×4×【8】=【128】维｜金字塔开销=【4/3】×原图｜Nyquist≥【2】×最高频率｜det=【λ₁λ₂】，tr=【λ₁+λ₂】｜TPR=正确保留/【总正确匹配数】｜FPR=错误保留/【总错误匹配数】
