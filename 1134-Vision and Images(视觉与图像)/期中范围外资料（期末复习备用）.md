## A. Harris 不变性与等变（原 §4.4，lec05——仅供参考，期中不考）

| 变换 | Harris 表现 |
|---|---|
| 平移 translation | 等变（equivariant）✓ |
| 旋转 rotation | 等变 ✓（椭圆旋转但特征值不变） |
| 光照 I→aI+b | 对加 b 不变；对缩放 a 部分不变 |
| **尺度 scale** | **不变不了** ✗（放大后角点会被判成边缘） |

术语：invariance=图像变了角点位置不变（光度）；equivariance(covariant)=几何变换后特征在对应位置检出。

## B. 尺度不变检测与 Blob（原 §5，lec05——仅供参考，期中不考）

- **思路**：在图像金字塔（不同尺度/分辨率）上逐尺度计算角点响应 f，取 f 随尺度曲线的**局部最大值**对应的尺度 = 该特征点的代表尺度（characteristic scale）。
- 实现用固定窗口 + 高斯金字塔代替不断变大的窗口。
- **LoG（Laplacian of Gaussian）**：另一个响应函数定义，找空间+尺度上的极值 → blob 检测。LoG ≈ **DoG（Difference of Gaussians，两不同 σ 高斯之差）**，DoG 更快，SIFT 即用它。
- 半径 r 的圆形 blob：LoG 响应峰值出现在与 r 成比例的尺度上。
- LoG/DoG 对旋转等变（covariant）。

## D. 图像变换与 Warping（原 §7，lec07 + Tutorial 04 + week4 纪要）——Week4 quiz 曾考自由度，但**期中不考**

### D.1 滤波 vs 变形
- filtering 改变**值域** g(x)=h(f(x))；warping 改变**定义域** g(x)=f(h(x))。

### D.2 变换族与自由度（背表，quiz 原题）
| 变换 | 矩阵形式 | 自由度 | 保持性质 |
|---|---|---|---|
| 平移 translation | 2×2 **不行**，需齐次 | **2** (tx,ty) | — |
| 旋转 rotation（绕原点） | 2×2 | **1** (θ) | 原点不动 |
| 缩放 scale | 2×2 对角 | 1 | — |
| 相似 similarity | 旋转+缩放+平移 | **3** | 角度保持 |
| 仿射 affine | 3×3，末行 [0 0 1] | **6** | **平行线仍平行**、比例保持；原点可动 |
| 投影 homography | 任意 3×3（差一个尺度）| **8** | **直线仍直线**；平行线**不再平行**（可相交于消失点） |

- 2×2 线性变换 = scale/rotation/shear/mirror 的组合；性质：原点映原点、线映线、平行保持、比例保持。
- **齐次坐标**：(x,y,w)，转回欧氏除以 w：(x/w, y/w)。w→0 时 x/w→∞ → **消失点 vanishing point**（原来平行的线在此相交）。
- homography 只定义到相差一个尺度因子（H 与 2H 等价，所以 9 个元素只有 8 个自由度）。

### D.3 旋转矩阵（要会写会求逆）
$$R(\theta) = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}, \quad R^{-1} = R^{\mathsf T} = R(-\theta)$$
缩放 S = diag(s, s)；相似变换 = [sR | t]。

### D.4 Forward vs Inverse Warping（简答常考）
| | Forward | Inverse |
|---|---|---|
| 做法 | 原图像素送到 T(x,y)，落点非整格时"splatting"摊到邻近像素 | 从目标整格点经 T⁻¹ 回到原图取值 |
| 插值位置 | 目标图上插值 | **原图上插值** |
| 缺点/优点 | **产生空洞**、可能重叠 | 每个目标像素都有值（**推荐**），需要 T 可逆 |

### D.5 单应估计与拼接（Tutorial 04 流程，实践题）
1. 两图各提 SIFT 关键点+描述子；
2. kNN（k=2）匹配 + Lowe 比值 0.75 过滤；
3. **至少 4 对匹配点**估计 3×3 单应 H（每对点给 2 个方程，8 未知数需 4 点）；
4. 用 **RANSAC** 剔除误匹配外点（cv2.findHomography(src, dst, cv2.RANSAC, 5.0)）；
5. warpPerspective 把图 1 投到图 2 视角，叠加检查对齐（红/蓝通道重合=白/黄=对齐好）。

## E. 双目立体匹配（原 §8，lec13）

### E.1 核心公式：视差与深度
校正过的立体对（rectified，极线水平）：
$$\text{disparity} = x_2 - x_1, \qquad \text{深度 } z = \frac{fB}{d}$$
（f=焦距，B=基线，d=视差）。**视差越大 → 越近；视差与深度成反比**。

### E.2 立体匹配流程（步骤题）
1. 标定相机（内外参）；
2. 校正（rectify，使极线水平）；
3. 计算视差：对左图像素，沿**同一极线**在右图找匹配（SSD/SAD 窗口代价最小）；
4. 由视差求深度。
误差来源：标定误差、分辨率低、遮挡、亮度恒定假设失效（镜面反射）、大位移、低纹理区域。

### E.3 概念题要点
- 窗口大小 trade-off：小窗→细节多噪声多；大窗→噪声少细节少（自适应窗口更好）。
- 能量最小化观点：$E(d) = E_{data} + \lambda E_{smooth}$，数据项=匹配代价，平滑项（Potts 模型：相邻像素视差不同则罚）鼓励相邻像素视差相近；λ→∞ 时全图恒定视差（fronto-parallel）。
- 主动方案：结构光（Kinect/iPhone FaceID 投 IR 点阵，简化对应问题）、激光扫描（三角测量）、ToF（时间飞行）。

## F. 多视角立体 MVS（原 §9，lec14）

- 输入：多台已标定相机图像；输出：完整 3D 模型。
- **基线 trade-off（必考概念）**：基线太小 → 深度误差大（三角化窄）；基线太大 → 匹配搜索难、易失配。
- **SSSD**（多基线）：参考视图对每个基线算 SSD 再相加取最小。
- **Plane-sweep**：扫一组平行于参考图像平面的深度平面，邻图经单应投到平面上比较光度一致性（photo-consistency）→ 代价体 → 图割/置信传播解深度图。
- 匹配分数：SSD、SAD、**NCC/ZNCC（零均值归一化互相关，对线性光照变化更鲁棒）**。
- NeRF：把场景表示为 (x,y,z)→(RGB,α) 的神经辐射场 + 体渲染。

## G. 神经网络与分类（原 §10，lec15）

### G.1 分类器谱系
Nearest Neighbor / kNN → Linear Classifier → Neural Network → Deep NN → Transformer。
- 图像 = 高维向量（32×32×3 = 3072 维）；iPhone 照片 4032×3024×3 ≈ 36.6M 维；实际位于低维流形上。
- kNN：不需要训练但要存全部数据、推理慢；线性分类器：参数化、快。

### G.2 线性分类器
$$f(x) = Wx + b$$
- W 每行 = 该类模板（template matching 观点）；几何观点：每类一张超平面，分数=带符号距离。
- 三种观点：代数 / 几何 / 模板匹配（lec15 明确列了，简答可能考）。

### G.3 Softmax + 交叉熵损失（手算必考）
1. 分数 s → 概率：$p_i = \dfrac{e^{s_i}}{\sum_j e^{s_j}}$
2. 交叉熵损失：$L_i = -\log p_{y_i}$（真实类概率越接近 1，损失越接近 0）
- 为什么不用错分数量：离散、无法打破平局、难泛化。
- SVM max-margin 曾流行；当前交叉熵最常用。

**例**：得分 [2, 1, 0]，正确类第 1 类。softmax：e²≈7.39, e¹≈2.72, e⁰=1，和≈11.11；p=[0.665, 0.245, 0.090]；L=−log(0.665)≈0.407。

### G.4 神经网络与梯度下降
- NN = 线性层串联 + **非线性激活**（没有非线性就塌缩成一层线性！简答常考）。
- **参数量计算例题**（lec15 原例）：输入 3072 → 隐层 100 → 输出 10：3072×100 + 100×10 = **308,200**。
- 梯度下降：随机初始化 → 算损失与梯度 → 沿负梯度走 → 重复。高效算梯度 = **反向传播 backpropagation**。
- 学习率：太大跳过最小值，太小收敛慢。

## H. CNN / RNN / Transformer（原 §11，lec16 + Tutorial 06 + 代码）

### H.1 CNN（输出尺寸公式必考）
- 卷积层：滤波器在图像上滑动做点积；滤波器深度=输入深度；K 个滤波器 → 输出 K 张激活图。
- **输出尺寸 = (N − F)/S + 1**（N 输入尺寸，F 滤波器尺寸，S 步长；padding 常使尺寸不变，如 F=3,pad=1）。
  例：N=7, F=3, S=1 → 5；N=7, F=3, S=2 → 3。
- Max Pooling：每个激活图独立取局部最大，降尺寸、平移鲁棒。
- CNN 结构 = Conv → Pool → … → Flatten → FC（Tutorial 06 代码：3 层 conv(32/64/128, 3×3) + 2 层 FC，CIFAR-10 十分类）。
- CNN vs MLP：CNN 权重共享、局部连接，适合图像；小图（32×32）从头训练也快。

### H.2 RNN 与 Attention（概念）
- RNN：隐状态随时间步更新并反馈；所有时间步**共享同一个 W**；训练用 BPTT（长序列用 truncated BPTT）。变体：Vanilla/LSTM/GRU。
- 缺点：串行慢、长程依赖难 → Attention/Transformer。
- Attention：对每个位置加权聚合相关信息（加权 = 相关度打分）。

### H.3 Transformer / ViT（概念+数字）
- **Self-Attention**：Q、K、V 三个矩阵；$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}(QK^{\mathsf T}/\sqrt{d})V$。
- Multi-Head：多组 QKV 并行，捕捉不同关系。
- 因为没有循环 → 需要**位置编码 positional encoding**。
- 解码器用 masked self-attention（看不到未来）。
- **ViT**：图像切成 **16×16 patch** 当"单词"序列（CIFAR-10 需先 Resize 到 224）；Tutorial 06 代码：vit_b_16 + 换 10 类头，学习率 0.0001（比 CNN 的 0.001 小）。
- 深度估计代码：MiDaS（DPT_Large）直接推理出深度图（相对深度）， interpolate 回原尺寸。
