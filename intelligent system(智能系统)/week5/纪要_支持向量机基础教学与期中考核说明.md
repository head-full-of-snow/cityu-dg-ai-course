## 向量范数、内积与投影计算基础

- **L1与L2范数定义**
  - L1范数为向量各分量绝对值之和，记作 $\|x\|_1$
  - L2范数为向量各分量平方和的平方根，记作 $\|x\|_2$，表示两点间直线距离（欧氏距离）
  - 未标注下标的范数默认为L2范数，因其最常用
- **内积的两种表达形式**
  - 代数形式为对应分量乘积之和，即 $w^T x = \sum w_i x_i$
  - 几何形式为两向量L2范数乘积再乘夹角余弦，即 $\|w\| \|x\| \cos\theta$
- **向量投影计算公式**
  - 向量x在w上的投影长度等于x的L2范数乘以夹角余弦
  - 利用内积几何形式可推导出投影公式为 $(w^T x) / \|w\|$

## 超平面表达式与法向量偏置几何意义

- **不同维度空间的超平面表示**
  - 二维空间中超平面为直线，表达式为 $w_1 x_1 + w_2 x_2 + b = 0$
  - 三维空间中超平面为平面，表达式为 $w_1 x_1 + w_2 x_2 + w_3 x_3 + b = 0$
  - N维空间中超平面表达式为 $w^T x + b = 0$，其中w和x均为N维向量
- **法向量W的垂直性证明**
  - 在超平面上任取两点 $x_1, x_2$，其差向量 $v = x_1 - x_2$ 位于平面内
  - 由超平面方程可得 $w^T v = 0$，说明w与平面内任意向量垂直
  - 因此w是超平面的法向量，决定超平面的方向
- **偏置b的几何作用**
  - 将 $w^T x + b = 0$ 改写为 $w^T x = -b$，结合投影公式得原点到超平面的投影长度为 $|-b| / \|w\|$
  - b控制超平面沿法向量方向的平移距离，b=0时超平面过原点
  - 改变b不改变超平面方向，仅改变其位置

## 点到超平面距离公式推导

- **通过投影计算距离的方法**
  - 空间中任一点 $x_0$ 到超平面的距离等于向量 $(x_0 - x)$ 在法向量w上的投影绝对值，其中x为超平面上任意点
  - 投影公式代入后得 $|w^T x_0 + b| / \|w\|$
- **距离公式的绝对值处理**
  - 投影值可能为负（当夹角为钝角时），但距离必须为正
  - 分母 $\|w\|$ 恒大于零，故绝对值仅作用于分子
  - 最终点到超平面距离公式为 $|w^T x_0 + b| / \|w\|$

## SVM Hard Margin原理与优化问题构建

- **Hard Margin与Soft Margin适用场景**
  - Hard Margin用于线性可分数据，寻找能完美分类的超平面
  - Soft Margin用于存在个别不可分点的情况，允许一定误分类以获得更好泛化
- **最大间隔的直观解释与支持向量作用**
  - 最优超平面应使两类数据间的间隔（Margin）最大，避免过于靠近某一类导致泛化差
  - Margin宽度由离超平面最近的几个点（支持向量）决定，其余样本不影响模型
  - SVM在小样本下表现优于深度学习，因其仅依赖支持向量而非全部样本数量
- **标签约束条件的整合表达**
  - 定义类别标签 $y \in \{+1, -1\}$，正类满足 $w^T x + b \geq 0$，负类满足 $w^T x + b < 0$
  - 两类约束可统一为 $y(w^T x + b) \geq 0$，确保所有观测数据被正确分类
- **W/B缩放不变性与分子归一化技巧**
  - 超平面方程中w和b同比例缩放不改变超平面本身及点到平面的距离
  - 可选择缩放因子使支持向量处的 $|w^T x + b| = 1$，从而将距离简化为 $1 / \|w\|$
  - 此归一化是为将分式优化问题转化为可求解形式，否则因分子不光滑无法求导
- **Max Margin转Min目标函数的等价转化**
  - 最大化Margin $1 / \|w\|$ 等价于最小化 $\frac{1}{2} \|w\|^2$
  - 该问题为凸优化问题，存在解析解，无需依赖数值优化工具包
  - 下节课将介绍对偶问题及具体求解方法
