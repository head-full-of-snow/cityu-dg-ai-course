## 任务 1：审计机器学习流程

实验推理 —— 12 分钟

一个医学数据集包含来自同一患者的重复就诊记录。目标是预测之前未见过的新患者的疾病状态。约 5% 的患者患有此疾病。一个团队构建了以下流程：

1.  将所有就诊记录随机分为训练集和测试集。
2.  使用所有可用数据计算特征的均值和标准差。
3.  训练多个分类器，选择测试性能最好的那个。
4.  报告最终的测试准确率。

**问题**

1.  识别该流程中的问题。
2.  提出正确的实验工作流程。
3.  如果漏检患者特别昂贵，这应该如何影响评估？

---

## 解答 1：审计机器学习流程

需要纠正的三个设计问题：

1.  将患者分为训练集、验证集和测试集，并确保同一患者的所有就诊记录保持在同一集合中。
2.  仅从训练集估计预处理统计量。
3.  使用验证数据进行模型选择；保留测试集用于最终评估。

安全的工作流程是：

**患者级别划分 → 预处理 → 训练 → 验证 → 测试一次**

由于只有 5% 的正类，准确率可能会产生误导。如果假阴性代价高昂，还应检查敏感性/召回率和各类别的错误率。

## 任务 2：罕见事件下的贝叶斯定理

计算与解释 —— 12 分钟

设 D 表示患病，+ 表示阳性检测。

P(D) = 0.02，P(+|D) = 0.90，P(+|¬D) = 0.08。

**问题**

1.  计算 P(D|+)。
2.  对于 10,000 人，估计真阳性和假阳性的数量。
3.  为什么 P(+|D) 和 P(D|+) 可能差异很大？

---

## 解答 2：罕见事件下的贝叶斯定理

对于 10,000 人：

P(D|+) = 0.90 × 0.02 / (0.90 × 0.02 + 0.08 × 0.98) ≈ 0.187

-   200 × 0.90 = 180 真阳性
-   9800 × 0.08 = 784 假阳性

敏感性问的是："在患病的人中，有多少人的检测呈阳性？"
后验概率问的是："在阳性检测结果中，有多少人实际患病？"

## 任务 3：线性变换如何改变协方差？

推导与解释 —— 18 分钟

已知：

E[X] = [1; 0]，X = [4  0; 0  1]

定义：Y = AX + b，A = [1  1; 0  1]，b = [2; -1]

**问题**

推导 E[Y] 和 Σ_Y。然后解释 Y₁ 和 Y₂ 的方差与协方差。

---

## 解答 3：变换后的均值和协方差

均值为：E[Y] = AE[X] + b = [3; -1]

协方差为：

Σ_Y = E[(Y - E[Y])(Y - E[Y])^T] = A Σ_X A^T = [5  1; 1  1]

因此：Var(Y₁) = 5，Var(Y₂) = 1，Cov(Y₁, Y₂) = 1。

b 平移了均值，但不影响协方差；A 改变了数据的散布和方向。

## 可选挑战：从协方差到 PCA

考虑 Σ = [3  2; 2  3]

1.  找到其特征值和单位特征向量。
2.  哪个方向的方差最大？
3.  PCA 首先会保留哪个方向？

**与 SVD 的关联**

如果中心化后的数据矩阵满足 X = UDV^T，哪个矩阵包含 PCA 方向？

---

## 解答：协方差、PCA 与 SVD

特征对为：

-   λ₁ = 5，u₁ = 1/√2 [1; 1]
-   λ₂ = 1，u₂ = 1/√2 [1; -1]

因此，最大方差沿 u₁ 方向，所以 PCA 首先保留这个方向。

对于中心化数据，X^TX = V D² V^T。

V 的列给出 PCA 方向；更大的奇异值对应更大的方差。
