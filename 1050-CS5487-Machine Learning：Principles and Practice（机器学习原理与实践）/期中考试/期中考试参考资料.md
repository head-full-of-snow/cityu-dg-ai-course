## 1. 五大分布速查表（第一优先级）

| 分布 | 公式 | 期望 | 方差 | 用途 |
|---|---|---|---|---|
| 伯努利 Bernoulli(π) | $p(x)=\pi^x(1-\pi)^{1-x},\ x\in\{0,1\}$ | $\pi$ | $\pi(1-\pi)$ | 单次二元结果（垃圾邮件、硬币） |
| 二项 Binomial(n,π) | $p(k)=\binom{n}{k}\pi^k(1-\pi)^{n-k}$ | $n\pi$ | $n\pi(1-\pi)$ | n 次独立试验中成功次数 |
| 泊松 Poisson(λ) | $p(k)=e^{-\lambda}\lambda^k/k!$ | $\lambda$ | $\lambda$ | 单位时间事件计数 |
| 高斯 N(μ,σ²) | $p(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp[-\frac{(x-\mu)^2}{2\sigma^2}]$ | $\mu$ | $\sigma^2$ | 连续测量、噪声模型 |
| Beta(α,β) | $p(\pi)\propto\pi^{\alpha-1}(1-\pi)^{\beta-1}$ | $\frac{\alpha}{\alpha+\beta}$ | $\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ | 对未知概率 π 的先验/后验 |

补充：E[K]二项=np、E[K]泊松=λ 是选择题常考。Beta(1,1)=均匀分布。

## 2. 概率基础与贝叶斯规则

### 2.1 核心公式
- 条件概率：$P(A|B)=\frac{P(A,B)}{P(B)}$
- 全概率：$P(B)=\sum_k P(B|A_k)P(A_k)$
- **贝叶斯：$P(A|B)=\frac{P(B|A)P(A)}{\sum_k P(B|A_k)P(A_k)}$**

### 2.2 必考模板：医学检测 / 罕见事件（教程 1 任务 2 原题）

> P(D)=0.02，P(+|D)=0.90，P(+|¬D)=0.08，求 P(D|+)。

解题四步：
1. 写出分子 = 灵敏度×患病率 = 0.90×0.02 = 0.018
2. 写出假阳项 = 0.08×0.98 = 0.0784
3. 相除：P(D|+) = 0.018/(0.018+0.0784) ≈ **0.187**
4. 解释：真阳性 200×0.90=180 人，假阳性 9800×0.08=784 人——**基础率低时阳性者大多没病**

**概念辨析（简答常考）**：P(+|D)（患病者中检测阳性比例=敏感性）≠ P(D|+)（阳性者中患病比例=后验），方向相反。

### 2.3 期望/方差/协方差运算规则

| 规则 | 公式 |
|---|---|
| 线性期望 | $E[aX+b]=aE[X]+b$ |
| 线性变换（向量） | $Y=AX+b \Rightarrow E[Y]=A\mu+b,\ \Sigma_Y=A\Sigma_X A^T$（**b 不影响协方差**） |
| 投影 | $Y=a^TX+b \Rightarrow E[Y]=a^T\mu+b,\ \mathrm{Var}(Y)=a^T\Sigma a$（作业 Q5） |
| 方差性质 | $\mathrm{Var}(aX)=a^2\mathrm{Var}(X)$ |
| 协方差 | $\mathrm{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])]$，对称、依赖单位 |
| 相关系数 | $\rho=\mathrm{Cov}(X,Y)/(\sigma_X\sigma_Y)\in[-1,1]$，无量纲 |

教程 1 任务 3 数值例：E[X]=[1;0]，Σ_X=diag(4,1)，A=[[1,1],[0,1]]，b=[2;-1] ⇒ E[Y]=[3;-1]，Σ_Y=AΣA^T=[[5,1],[1,1]]。

### 2.4 分类评估指标（分母决定指标回答什么问题）

四个基本量：TP、FP、TN、FN。
- **准确率** = (TP+TN)/全部（不平衡时会误导：5% 正类时全预测负也有 95%）
- **精确率** = TP/(TP+FP)：预测为正中真是正的比例
- **召回率/敏感性** = TP/(TP+FN)：真正中被找出的比例（漏检代价高时看它）
- 数据划分：训练（拟合）→ 验证（选模型）→ 测试（**只碰一次**）；预处理统计量只能从训练集估计

## 3. 多元高斯与马氏距离（必考题型 ①，作业 Q1 + quiz）

### 3.1 公式
$$p(\mathbf{x})=\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\left[-\frac{1}{2}(\mathbf{x}-\mu)^T\Sigma^{-1}(\mathbf{x}-\mu)\right]$$

- 同一高斯下比较两点密度 ⇒ 只比**马氏距离** $D=(\mathbf{x}-\mu)^T\Sigma^{-1}(\mathbf{x}-\mu)$（D 小 ⇒ p 大）
- 密度比：$\frac{p(x_A)}{p(x_B)}=\exp[-\tfrac12(D_A-D_B)]$
- 等高线：椭圆；长轴方向=方差大的方向；倾斜=协方差符号

### 3.2 从零解题步骤（背下来）

以作业 Q1 为例：μ=[1;2]，Σ=[[4,1],[1,1]]，x_A=[3;3]，x_B=[1;4]。

1. **算行列式**：|Σ| = 4·1−1·1 = 3
2. **算逆矩阵**（2×2 模板：交换对角、负化反对角，除以行列式）：
   $$\Sigma^{-1}=\frac{1}{3}\begin{bmatrix}1&-1\\-1&4\end{bmatrix}$$
3. **算偏差向量**：x_A−μ=[2;1]，x_B−μ=[0;2]
4. **算马氏距离** D = 偏差^T · Σ⁻¹ · 偏差：
   - $D_A=[2,1]\cdot\frac13[1;-2]=[2,1]\cdot[\frac13;-\frac23]$…… 逐项：D_A = 2²·(1/3) + 1²·(4/3) − 2·(1/3)·2·1·…… 直接展开：
   - $D_A=\frac13(4)+\frac43(1)-\frac23(2\cdot1)=\frac43+\frac43-\frac43=\frac43$（≈1.333）
   - $D_B=\frac13(0)+\frac43(4)-\frac23(0\cdot2)=\frac{16}{3}$（≈5.333）
5. **比较**：D_A < D_B ⇒ **p(x_A) > p(x_B)**（虽然两点到 μ 的欧氏距离都是 √5，马氏距离不同——这就是"不能用欧氏距离"的原因）
6. **比值**：p(x_A)/p(x_B) = exp[−½(4/3−16/3)] = **exp(2) ≈ 7.39**

> 2×2 对称矩阵逆模板：$\begin{bmatrix}a&b\\b&c\end{bmatrix}^{-1}=\frac{1}{ac-b^2}\begin{bmatrix}c&-b\\-b&a\end{bmatrix}$

## 4. 特征值、PCA 与 SVD（教程 1 挑战题）

### 4.1 2×2 对称矩阵特征值模板
Σ=[[a,b],[b,a]] 型（教程题 Σ=[[3,2],[2,3]]）：
- 特征值：λ = a±b → λ₁=5, λ₂=1
- 特征向量：u₁=1/√2[1;1]（对应 a+b），u₂=1/√2[1;−1]

一般 [[a,b],[b,c]]：λ = [(a+c)±√((a−c)²+4b²)]/2。

### 4.2 PCA 要点
- **PCA 方向 = 协方差矩阵最大特征值对应的特征向量**（方差=特征值）
- 步骤：中心化数据 → 求协方差 → 特征分解 → 取前几个大特征值方向
- SVD：中心化 X = UDV^T，则 **V 的列 = PCA 方向**（X^TX=VD²V^T），大奇异值=大方差方向

## 5. 最大似然估计 MLE（必考题型 ②，作业 Q2/Q6）

### 5.1 万能四步（所有 MLE 题通用）
1. 写似然：独立观测 ⇒ 连乘 $L(\theta)=\prod_i p(x_i|\theta)$
2. 取对数：连乘变求和 $\ell(\theta)=\sum_i\log p(x_i|\theta)$
3. 求导置零：$\frac{d\ell}{d\theta}=0$，解出 θ̂
4. 检查：是最大（二阶导<0）或边界情形

### 5.2 三个标准结果（选择题直接用）

| 模型 | MLE | 备注 |
|---|---|---|
| 伯努利 | $\hat\pi=m/n$（成功次数/总数） | 全成功时 π̂=1（**边界解**，因 L=πⁿ 单调） |
| 高斯均值 | $\hat\mu=\bar{x}$ | 已知/未知方差都一样 |
| 高斯方差 | $\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2$ | 无偏版用 n−1 |

**n vs n−1（简答高频）**：均值是从同一数据估出的，残差满足 Σ(xᵢ−x̄)=0，损失 1 个自由度。MLE（÷n）系统偏小；无偏样本方差 ÷(n−1) 修正。两者回答不同问题：MLE 最大化似然，无偏修正系统偏差。

### 5.3 不等方差高斯的 MLE（作业 Q6，精度加权）

设 xᵢ~N(μ, σᵢ²) 独立，σᵢ² 已知但不等：
1. 对数似然（忽略常数）：$\ell(\mu)=-\frac12\sum_i\frac{(x_i-\mu)^2}{\sigma_i^2}+C$
2. 求导：$\sum_i\frac{x_i-\mu}{\sigma_i^2}=0$
3. 解出：
$$\boxed{\hat\mu=\frac{\sum_i x_i/\sigma_i^2}{\sum_i 1/\sigma_i^2}}\quad\text{（精度加权平均，方差小的观测权重大）}$$
4. σᵢ² 全相等时退化为 x̄。

### 5.4 MLE 线性回归数值解（作业 Q2 + quiz，必考）

> 数据 (−1,0),(0,1),(1,2),(2,2)，模型 y=w₀+w₁x+ε，ε~N(0,σ²)。

**第一步：写出似然与正规方程**（对 w₀,w₁ 求导置零）：
$$\sum_i(y_i-w_0-w_1x_i)=0,\qquad \sum_i x_i(y_i-w_0-w_1x_i)=0$$

**第二步：数四个量**（列表格再求和，最不易错）：

| xᵢ | yᵢ | xᵢyᵢ | xᵢ² |
|---|---|---|---|
| −1 | 0 | 0 | 1 |
| 0 | 1 | 0 | 0 |
| 1 | 2 | 2 | 1 |
| 2 | 2 | 4 | 4 |
| **Σx=2** | **Σy=5** | **Σxy=6** | **Σx²=6** |

**第三步：代入方程组**
- 5 = 4w₀ + 2w₁
- 6 = 2w₀ + 6w₁
解得：w₀ = **0.9**，w₁ = **0.7**（ŷ = 0.9 + 0.7x）

**第四步：σ² 的 MLE**（残差平方平均）：
- 拟合值：x=−1→0.2, 0→0.9, 1→1.6, 2→2.3
- 残差：(0−0.2, 1−0.9, 2−1.6, 2−2.3) = (−0.2, 0.1, 0.4, −0.3)
- $\hat\sigma^2=\frac{0.04+0.01+0.16+0.09}{4}=\frac{0.3}{4}=0.075$

**第五步：预测**：x*=3 ⇒ ŷ = 0.9+0.7·3 = **3.0**

## 6. 贝叶斯估计（必考题型 ③，作业 Q3/Q7 + 教程 3 全部）

### 6.1 框架
$$p(\theta|\mathcal{D})\propto \underbrace{p(\mathcal{D}|\theta)}_{似然}\cdot\underbrace{p(\theta)}_{先验}$$
- MLE：只用似然；MAP：似然+先验取众数；后验均值：分布平均；完整后验：保留不确定性
- 后验预测：$P(x_*=1|\mathcal{D})=\sum_\pi P(x_*=1|\pi)P(\pi|\mathcal{D})$（对参数不确定性加权平均）

### 6.2 必考模板 A：离散先验表格法（作业 Q3 原题）

> π∈{0.2, 0.5, 0.8}，先验 (0.2, 0.5, 0.3)，观测 D=(1,1,1,0)。

三列表格：

| π | 先验 P(π) | 似然 P(D\|π)=π³(1−π) | 乘积 | 后验=乘积/证据 |
|---|---|---|---|---|
| 0.2 | 0.2 | 0.2³·0.8=0.0064 | 0.00128 | 0.0202 |
| 0.5 | 0.5 | 0.5⁴=0.0625 | 0.03125 | **0.4941** |
| 0.8 | 0.3 | 0.8³·0.2=0.1024 | 0.03072 | 0.4857 |

- 证据 = 乘积列求和 = 0.06325
- (b) MAP = 最大后验 = **0.5**
- (c) 后验预测 = 0.2(0.0202)+0.5(0.4941)+0.8(0.4857) = **0.6396**（≠MAP 代入的 0.5！）

### 6.3 必考模板 B：Beta-Bernoulli 共轭（教程 3 任务 1 原题）

更新规则（背）：**α←α+m，β←β+(n−m)**

> m=3 成功, n=4 试验；先验 A=Beta(2,2)，先验 B=Beta(20,20)。

| | 后验 | 后验均值=预测概率 | MAP |
|---|---|---|---|
| A | Beta(5,3) | 5/8=**0.625** | (5−1)/(8−2)=**2/3** |
| B | Beta(23,21) | 23/44≈**0.523** | 22/42≈0.524 |
| MLE | — | 3/4=**0.75** | — |

公式：
- 后验均值（=下一次成功概率）：$\frac{\alpha+m}{\alpha+\beta+n}$
- MAP（内部众数，α+m>1 且 β+n−m>1 时）：$\frac{\alpha+m-1}{\alpha+\beta+n-2}$
- **均值≠众数的原因**（简答）：后验不对称时，平均与众数不同；MAP 取最高点，均值对整个分布加权
- 先验强度：集中度 κ₀=α+β 越大先验越强；Var = μ₀(1−μ₀)/(κ₀+1)。数据增多 ⇒ 先验影响变小
- 极端例：5 次全失败，MLE 给 0（预测永远失败），Beta(1,1) 先验给后验 Beta(1,6)，预测 1/7≈0.143——**贝叶斯避免极端结论**

### 6.4 必考模板 C：高斯-高斯共轭（教程 3 任务 2 原题）

设定：μ~N(μ₀, τ₀²)（先验），xᵢ~N(μ, σ²)（σ² 已知），观测 n 个，样本均值 x̄。

**精度 = 1/方差**：λ₀=1/τ₀²（先验精度），λ_D=n/σ²（数据精度）。

三行公式：
$$\mu_n=\frac{\lambda_0\mu_0+\lambda_D\bar{x}}{\lambda_0+\lambda_D}\quad(\text{精度加权平均}),\qquad \tau_n^2=\frac{1}{\lambda_0+\lambda_D},\qquad x_*|\mathcal{D}\sim N(\mu_n,\ \sigma^2+\tau_n^2)$$

> 数值例（教程 3）：μ~N(10,4)，n=2，x̄=14，σ²=8。
> λ₀=1/4=0.25，λ_D=2/8=0.25（**相等 ⇒ 等权**）
> μ_n=(0.25·10+0.25·14)/0.5=**12**；λ_n=0.5 ⇒ τ_n²=**2** ⇒ μ|D~N(12,2)
> 预测：x_*|D~N(12, 8+2=**10**)。预测方差>后验方差，因为=参数不确定性(2)+新观测噪声(8)。

> 讲义例：μ~N(10,4)，n=4，x̄=12，σ²=4 ⇒ λ₀=0.25，λ_D=1 ⇒ μ_n=0.2·10+0.8·12=11.6，τ_n²=0.8。
> 关键直觉：**谁精度高谁权重大**（方差小/数据多/噪声小 ⇒ 可靠）。

### 6.5 MAP 与正则化（作业 Q7 + 教程 3 任务 3）

**通用推导套路**：MAP 最大化 p(w|D) ∝ 似然×先验 ⇒ 最小化 −log似然 −log先验。

| 先验 | −log 先验 ∝ | 惩罚 | 效果 |
|---|---|---|---|
| 高斯 N(0,τ²) | $\frac{1}{2\tau^2}\|w\|_2^2$ | L2（**岭回归**），λ=σ²/τ² | 平滑收缩 |
| 拉普拉斯 e^{−λ\|w\|} | λ\|w\| | L1 | 可压到精确 0（稀疏） |

**岭回归完整链**（推导题背此链条）：
$$\hat w_{MAP}=\arg\min_w \|y-Xw\|_2^2+\lambda\|w\|_2^2,\qquad \lambda=\frac{\sigma^2}{\tau^2}$$
先验中心不为零（w~N(w₀,τ²I)）时：
$$\|y-Xw\|^2+\lambda\|w-w_0\|^2 \Rightarrow \boxed{(X^TX+\lambda I)\hat w=X^Ty+\lambda w_0}$$
- w₀=0 ⇒ 标准岭回归；τ²→∞ ⇒ λ→0 ⇒ 退化为普通最小二乘
- 数值意义：X^TX 近奇异（特征高度相关）时，+λI 把小特征值抬离 0，解更稳定（教程 3 实验：OLS 系数 (4.16,−0.22) 剧烈波动，岭 (1.98,1.93) 稳定）

**拉普拉斯先验 MAP（作业 Q7，软阈值）**：xᵢ~N(w,σ²)，p(w)∝e^{−λ|w|}：
1. 负对数后验：$L(w)=\frac{1}{2\sigma^2}\sum(x_i-w)^2+\lambda|w|$
2. 用分解 $\sum(x_i-w)^2=\sum(x_i-\bar x)^2+n(w-\bar x)^2$ 化简为 $\frac{n}{2\sigma^2}(w-\bar x)^2+\lambda|w|+C$
3. 分情况（|w| 不可导处分类讨论）：
   - w>0：$\frac{n}{\sigma^2}(w-\bar x)+\lambda=0 \Rightarrow w=\bar x-\frac{\lambda\sigma^2}{n}$（当 x̄>λσ²/n 时有效）
   - w<0：$w=\bar x+\frac{\lambda\sigma^2}{n}$（当 x̄<−λσ²/n 时有效）
   - |x̄|≤λσ²/n：**ŵ=0**
4. 合并（软阈值公式）：
$$\boxed{\hat w_{MAP}=\mathrm{sign}(\bar x)\max\left(|\bar x|-\frac{\lambda\sigma^2}{n},\ 0\right)}$$

## 7. 最小二乘的矩阵语言（l3supplements，推导题工具箱）

### 7.1 向量求导规则表（先验=常数时直接查表）

| 表达式 | 梯度 |
|---|---|
| $a^Tw$ 或 $w^Ta$ | $a$ |
| $w^Tw$ | $2w$ |
| $w^TAw$（A 对称） | $2Aw$ |
| $w^TAw$（一般） | $(A+A^T)w$ |

### 7.2 正规方程推导（五步，默写级）
$$J(w)=\|y-Xw\|^2=(y-Xw)^T(y-Xw)=y^Ty-2w^TX^Ty+w^TX^TXw$$
$$\nabla_w J=-2X^Ty+2X^TXw=0\ \Rightarrow\ \boxed{X^TX\hat w=X^Ty}$$
（维度检查：r∈ℝⁿ 是观测空间量，梯度∈ℝᵈ 参数空间量，X^T 完成映射：∇J=−2X^Tr）

### 7.3 残差几何（简答）
- r = y−Xŵ：观测与预测之差
- **X^Tr=0**：残差与 X 每列正交——没有任何特征方向还能再减小残差
- 实践避免显式 (X^TX)⁻¹（数值病态），用 QR/SVD；两特征列几乎相同时 X^TX 病态、权重不稳定

### 7.4 噪声模型 → 损失函数（教程 2 挑战题）
- 高斯噪声 −log p ∝ Σrᵢ²（平方误差；对大误差放大强：r=10 ⇒ r²=100）
- 拉普拉斯噪声 −log p ∝ Σ|rᵢ|（绝对误差，对异常值稳健）

## 8. K-means（必考题型 ④）

### 8.1 目标与算法
目标（簇内总平方距离）：$J=\sum_i\sum_k r_{ik}\|x_i-\mu_k\|^2$，r_ik∈{0,1}，Σₖr_ik=1。

四步循环：
1. 初始化 K 个中心
2. **分配步**：每点归最近中心（固定 μ 优化 r）
3. **中心步**：每个中心 = 其成员均值 $\mu_k=\frac{\sum_i r_{ik}x_i}{\sum_i r_{ik}}$（固定 r 优化 μ）
4. 重复至分配不变

### 8.2 数值例（讲义原题：点 1,2,7,8，初始 μ₁=1, μ₂=5）
1. 距离表：|x−μ₁|=(0,1,6,7)，|x−μ₂|=(4,3,2,3)
2. 分配：{1,2}→1，{7,8}→2
3. 更新：μ₁=(1+2)/2=1.5，μ₂=(7+8)/2=7.5
4. J 从 14 降到 1：更新前 (0+1+4+9)=14；更新后 (0.25×4)=1
5. 再分配不变 ⇒ 收敛（**不动点=局部最优，非全局**）

### 8.3 收敛性与失败模式（简答）
- 收敛：每步 J 不增 + 有限种硬分配 ⇒ 必达不动点
- 为什么交替：r 离散、μ 连续，联合优化难，分而治之
- **假设**：球形簇、欧氏距离=相似度、均值有意义
- **失败**：长条形/环形簇、密度不同、非凸结构、离群点（均值敏感）
- 初始化敏感 ⇒ 多次随机初始化取 J 最小 / K-means++

## 9. GMM 与 EM（必考题型 ⑤，作业 Q4/Q8 各 20 分）

### 9.1 模型
$$p(x)=\sum_{k=1}^K \pi_k\,\mathcal{N}(x|\mu_k,\Sigma_k),\qquad \pi_k\ge0,\ \sum\pi_k=1$$
生成故事：先按 P(z=k)=π_k 选成分，再从该高斯采样。z 是隐藏标签。

### 9.2 E 步（责任 = 后验归属概率）
$$\gamma_{ik}=\frac{\pi_k\mathcal{N}(x_i|\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal{N}(x_i|\mu_j,\Sigma_j)},\qquad \sum_k\gamma_{ik}=1$$
一维高斯代入时注意：$\mathcal{N}(x|\mu,\sigma^2)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-(x-\mu)^2/2\sigma^2}$。π_k 相同、σ_k² 相同时可约掉公共因子（如 x=2 距两中心等距时 γ=(0.6,0.4) 只由 π 决定）。

### 9.3 M 步三公式（背）
$$N_k=\sum_i\gamma_{ik},\qquad \pi_k^{new}=\frac{N_k}{n},\qquad \mu_k^{new}=\frac{\sum_i\gamma_{ik}x_i}{N_k},\qquad (\sigma_k^2)^{new}=\frac{\sum_i\gamma_{ik}(x_i-\mu_k^{new})^2}{N_k}$$
（协方差版：$\Sigma_k^{new}=\frac1{N_k}\sum_i\gamma_{ik}(x_i-\mu_k)(x_i-\mu_k)^T$）
解释：软计数 → 位置（加权均值）→ 散布（加权方差）。**注意 σ² 更新用的是新 μ**。

### 9.4 完整数值例 1（作业 Q4，20 分题，数字已验证）

数据 x={0,2,4}，初始 π=(0.6,0.4)，μ=(0,4)，σ₁²=σ₂²=2。

**E 步**：
- 密度：N(0|0,2)=0.2821，N(0|4,2)=0.0052；N(2|0,2)=N(2|4,2)=0.1038（对称！）；N(4|0,2)=0.0052，N(4|4,2)=0.2821
- 加权：s₁=(0.6·0.2821, 0.6·0.1038, 0.6·0.0052)，s₂=(0.4·0.0052, 0.4·0.1038, 0.4·0.2821)
- 归一化：

| xᵢ | γᵢ₁ | γᵢ₂ |
|---|---|---|
| 0 | 0.9879 | 0.0121 |
| 2 | **0.6** | **0.4**（等距 ⇒ 只由 π 决定） |
| 4 | 0.0267 | 0.9733 |

**M 步**：
- N₁=1.6147，N₂=1.3853（ΣNₖ=3 ✓）
- π₁¹=1.6147/3=**0.5382**，π₂¹=**0.4618**
- μ₁¹=(0.9879·0+0.6·2+0.0267·4)/1.6147=1.3068/1.6147=**0.8094**
- μ₂¹=(0.0121·0+0.4·2+0.9733·4)/1.3853=4.6932/1.3853=**3.3877**
- (σ₁²)¹=[0.9879(0−0.8094)²+0.6(2−0.8094)²+0.0267(4−0.8094)²]/1.6147=1.7694/1.6147≈**1.10**
- (σ₂²)¹=[0.0121(0−3.3877)²+0.4(2−3.3877)²+0.9733(4−3.3877)²]/1.3853=1.2742/1.3853≈**0.92**

> ⚠️ 班上流传手写答案此处为 7.59/9.95，经程序验证有误（那是不除以 Nₖ 或用错 μ 的结果），正确约 1.10/0.92。

### 9.5 完整数值例 2（讲义例：x={1,3,5}，π=(0.5,0.5)，μ=(1,5)，σ²=1）

E 步：γ=(0.9997,0.0003),(0.5,0.5),(0.0003,0.9997)
M 步：N₁=N₂=1.5；π 不变 0.5；μ₁=(0.9997·1+0.5·3+0.0003·5)/1.5≈**1.668**，μ₂≈**4.332**；σ²≈**0.891**
直觉：中点 x=3 各贡献一半权重给两侧——**EM 均值更新 = K-means 中心更新的软化版**。

### 9.6 为什么用 EM（简答，Week3 课堂强调）
- 直接最大化 ℓ(θ)=Σᵢ log(Σₖ πₖN(xᵢ|μₖ,Σₖ))：**log(和)** 导致求导后方程互相耦合，无闭式解
- EM 引入辅助分布 q(z)，用 **Jensen 不等式**构造下界 $\mathcal{L}(q,\theta)\le\log p(X|\theta)$
  - E 步：令 q(z)=p(z|X,θ) 使下界紧贴真实似然
  - M 步：最大化下界 ⇒ 似然提升
  - 下界与似然的差距 = KL(q‖p) ≥ 0，仅当 q=p 时为 0
- 通俗版：固定参数算归属（E），固定归属算参数（M=加权 MLE）；每次迭代似然不减，收敛到局部最优

### 9.6' GMM 补充考点（Week3 课堂）

**四种协方差结构**（选择题）：

| 类型 | 约束 | 形状 |
|---|---|---|
| Spherical | Σₖ=σₖ²I | 球形（=K-means 假设） |
| Diagonal | 对角阵 | 轴对齐椭球，特征独立 |
| Shared | 所有分量同一 Σ | 同形不同心 |
| Full | 无约束 | 任意椭球，参数最多 |

**过拟合风险**：某分量坍缩到单点、σₖ²→0 时似然→∞（记忆噪声）。防护：Nₖ 下限（如 ≥5）、方差下限、多次初始化、验证集。

**模型选择 BIC**：$\mathrm{BIC}=-2\log L+d\log N$（d=参数数，N=样本数），**BIC 越小越好**，用于选 K。注意：GMM 分量数 ≠ 真实类别数。

### 9.7 GMM → K-means 极限（作业 Q8，20 分推导）

条件：πₖ=1/K，Σₖ=σ²I。
(a) 代入责任公式，1/K 与 (2πσ²)^{d/2} 全约掉：
$$\gamma_{ik}=\frac{\exp(-\|x_i-\mu_k\|^2/2\sigma^2)}{\sum_j\exp(-\|x_i-\mu_j\|^2/2\sigma^2)}$$
(b) 两成分比值（分母公共项相消）：
$$\frac{\gamma_{ia}}{\gamma_{ib}}=\exp\left(\frac{\|x_i-\mu_b\|^2-\|x_i-\mu_a\|^2}{2\sigma^2}\right)$$
(c) σ²→0：若 k* 是唯一最近质心，则 ‖xᵢ−μⱼ‖²−‖xᵢ−μ_{k*}‖²>0（∀j≠k*），指数→−∞ ⇒ 比值→0 ⇒ **γ_{ik*}→1，其余→0（硬分配）**
(d) 硬分配下 J_k=Σ_{i∈k}‖xᵢ−μₖ‖²，求导 −2Σr_ik(xᵢ−μₖ)=0 ⇒ **μₖ*=成员均值**——正是 K-means 中心步。

**结论（一句话背）**：等权、等方差 σ²I 的 GMM 在 σ²→0 时软责任退化为最近邻硬分配，EM 退化为 K-means。

## 10. 第 5 周：非参数密度估计与聚类（l5 全部内容，防超纲出题）

### 10.1 局部密度估计与直方图

**核心推导（从零开始）**：一维中 x 的邻域 [x−r, x+r] 宽 2r；区间足够小时 p(u)≈p(x)（矩形近似）：
$$\underbrace{P(x-r\le X\le x+r)\approx 2r\,p(x)}_{\text{概率质量}}\quad\Longleftrightarrow\quad \underbrace{\frac{N_r(x)}{n}}_{\text{经验质量}}\ \Rightarrow\ \boxed{\hat p_r(x)=\frac{N_r(x)}{2nr}}\ (\text{密度}=\frac{\text{局部样本分数}}{\text{局部宽度}})$$

**直方图 = 局部估计特例**：bin 宽 h（=2r），密度 = bin 内计数/(n·h)。两大缺陷：
1. 不连续：bin 边界处估计值跳变
2. 网格敏感：同样 h、不同起始位置 → 不同直方图

### 10.2 KDE 核密度估计

$$\hat p_h(x)=\frac{1}{nh}\sum_{i=1}^n K\left(\frac{x-x_i}{h}\right)\qquad(d\text{维：分母 }nh^d\text{，常用乘积核})$$

- 每个观测贡献一个核"小山"；1/h 保证单个观测的总质量为 1（面积守恒）；结果连续且积分为 1；**密度值 ≠ 概率**
- 核函数：高斯核 $K(u)=\frac{1}{\sqrt{2\pi}}e^{-u^2/2}$（最常用）；Box 核 |u|≤1 取 1/2；三角核 K(u)=max(0,1−|u|)
- 核形状影响小，**带宽 h 才是关键**：h 小→窄高峰、细节多、方差大（可能出现 0 密度间隙）；h 大→平滑、偏差大（可能抹掉真实结构）
- **h 必须用验证集选**（候选值逐个算验证集似然取最优）：训练集不行，因为 h→0 时训练点自身贡献→∞（过拟合）
- 偏差-方差权衡：h 小=低平滑偏差高方差；h 大=高偏差低方差；n 增大可减波动但 h 仍需随 n 调
- 多维：先**特征归一化**（年龄 21–23 vs 体重 40–100kg 会让距离被大量纲特征主导）；维度灾难：h^d 急剧缩小、需指数级样本

**数值例 A（讲义，Box 核）**：观测 x₁=0, x₂=1，h=1，则 $\hat p_1(x)=\#\{i:|x-x_i|\le1\}/(2nh)=\#/(4)$：
| x | 窗口内观测数 | p̂(x) |
|---|---|---|
| −0.5 | 1 | 1/4 |
| 0.5 | 2 | **1/2**（贡献重叠处更高） |
| 1.5 | 1 | 1/4 |
| 3 | 0 | 0 |

**数值例 B（课堂练习，三角核）**：数据 {0,2,3}，K(u)=max(0,1−|u|)，算 x=2：
- h=1：只有 x=2 自己贡献（u=0→1；其余 |u|≥1→0），p̂(2)=1/(3·1)=**1/3**
- h=2：权重 = (K(1), K(0), K(0.5)) = **(0, 1, 0.5)**（注意 K(1)=0，x=0 不贡献），p̂(2)=1.5/(3·2)=**1/4**
- 验证点 x=1：h=1 时密度 0；h=2 时 (0.5+0.5+0)/6=**1/6** ⇒ 选 h=2（大带宽在稀疏区更稳）

### 10.3 均值漂移 Mean-shift

- 思想：**聚类中心 = 密度峰值**；对高斯核 KDE 求梯度做梯度上升 ⇒ 无需预设 K
- 更新公式（加权局部均值）：
$$x^{new}=x+m(x),\qquad m(x)=\frac{\sum_i w_i x_i}{\sum_i w_i}-x,\qquad w_i=\exp\left(-\frac{\|x-x_i\|^2}{2h^2}\right)$$
- 迭代：算权重 → 移动 → 重算，直到位移小于阈值；**一个峰 = 一个吸引盆**，同盆起点归同簇

**数值例 A（讲义）**：观测 {0,2,4}，起点 x⁰=1，h=2：
- 权重：w₁=e^{−1/8}≈0.8825，w₂=e^{−1/8}≈0.8825，w₃=e^{−9/8}≈0.3247
- x¹ = (0.8825·0+0.8825·2+0.3247·4)/(0.8825+0.8825+0.3247) = 3.064/2.090 ≈ **1.47**

**数值例 B（课堂练习）**：{0,1,2,3}，高斯核 h=1，x₀=2 ⇒ x₁≈1.355 ⇒ x₂≈0.778（持续向 0–1 高密度区移动）

- **带宽控制簇数**：h 小→多峰多簇；h 大→峰合并少簇（K 由 h 和数据决定）
- 与 K-means 对比：硬分配 vs 软权重；预设 K vs h 决定；球形 vs 任意形状；复杂度 O(nkd) vs **O(n²d)**（每次迭代算全部距离，大数据需近邻加速）

### 10.4 谱聚类（教程 5 任务 3 完整数值）
- 图：节点=点，w_ij=e^{−‖xi−xj‖²/σ²}；度矩阵 D_ii=Σⱼw_ij（行和）；拉普拉斯 **L=D−W**（每行和为 0）
- Ncut(A,B)=cut(A,B)/vol(A)+cut(A,B)/vol(B)，vol=簇内所有节点度之和（切边小 + 簇平衡）
- 流程：L f=λD f 广义特征问题 → 取前 k 个最小非零特征向量做新特征 → 新空间跑 K-means
- 教程 5 数值例：W=[[0,3,0,0],[3,0,1,0],[0,1,0,3],[0,0,3,0]]
  - D=diag(3,4,4,3)，L=D−W（对角=度，非对角=−w）
  - P1={1,2}|{3,4}：只切 2–3 边（权 1）⇒ cut=1；vol=7,7 ⇒ **Ncut=2/7≈0.286**
  - P2={1}|{2,3,4}：切 1–2 边（权 3）⇒ cut=3；vol=3,11 ⇒ Ncut=1+3/11≈**1.273**
  - **Ncut 越小越好 ⇒ P1 优**（惩罚切出孤立小簇；若只看 cut 也是 1<3）
  - f=[1,1,0,0]ᵀ 时 fᵀLf=½Σw_ij(fᵢ−fⱼ)²=跨割边权=1
- 四种聚类对比（纪要总结）：K-means 球形高效 O(nkd)；GMM 概率软分配；mean-shift 密度峰自适应但 O(n²d)；谱聚类非凸流形但最贵 O(n³)

### 10.5 其他零散概念（Week1-2 讲义）
- 监督（分类/回归）vs 无监督（聚类/密度估计/降维）；泛化是核心目标
- 模型/目标/学习算法三者不同；训练/验证/测试分工
- 似然中观测固定、参数变化；更多数据 ⇒ 似然更集中
- 偏差-方差：偏差=系统性偏离，方差=随数据波动；MSE 分解两者+噪声

(c) Harris 响应 R=det(H)−k·trace(H)²=590000−0.05×1550²=590000−120125=**469875**>0 ⇒ 强角点。
