## 参数估计问题

概率模型描述了观测值是如何生成的。模型中的一些量是未知的，需要从数据中估计。

**示例：抛硬币**

设 x = 1 表示正面，x = 0 表示反面。正面的概率是一个未知参数 θ：

给定观测值 D = {x1, ..., xn}，参数估计要问的是：我们应该如何从观测数据中估计 θ？

---

## 概率与似然

表达式 p(x|θ) 可以回答两个不同的问题。

| **概率** | **似然** |
|---------|---------|
| 参数固定而观测值变化：θ 固定，x 变化。 | 观测值固定而参数变化：L(θ; D) = p(D\|θ)。 |
| p(x\|θ) 是可能观测值的概率分布。 | 似然比较不同的参数值。它不是关于 θ 的概率分布，因此不需要总和为1。 |
| Σx p(x\|θ) = 1。 |

**示例**：在观察到10次抛硬币中出现8次正面后，数据保持不变，而不同的 θ 值被比较。

---

## 独立观测使似然成为乘积

我们通常假设观测值是 i.i.d.（独立同分布）：观测值独立且服从相同分布。独立性使得联合似然可以分解：

p(D|θ) = ∏_{i=1}^{n} p(xi|θ)

由于数据是观测到的，最大似然选择使观测数据最可信的参数：

θ̂_ML = arg maxθ p(D|θ)

取对数得到等效目标：

ℓ(θ) = log p(D|θ) = Σ_{i=1}^{n} log p(xi|θ)

θ̂_ML = arg maxθ ℓ(θ)

---

## 如何最大化似然？

最大似然将估计转化为一个优化问题：

θ̂_ML = arg maxθ ℓ(θ)

为了找到最优值，我们通常：

1. 找到斜率为零的候选点：dℓ/dθ = 0
2. 检查候选点是否是最大值：d²ℓ/dθ² < 0
3. 检查参数上的约束。

**常见错误**

导数为零只给出候选解；它不保证是最大值。

---

## 超越导数：我们应该检查什么？

找到零导数只是第一步。

| 它是最大值吗？ | 它是允许的吗？ |
|---------------|---------------|
| 驻点可能是：<br>- 最大值<br>- 最小值<br>- 平坦区域 | 参数通常有约束。例如：0 ≤ θ ≤ 1<br>最优解可能出现在边界上。 |

曲率有助于确定点的类型。

有效的最大似然估计解必须同时满足优化条件和参数约束。

---

## 伯努利最大似然

---

## 示例：估计硬币概率

假设一枚硬币被抛 n 次。设 xi = 1 表示正面，xi = 0 表示反面。θ 是未知的正面概率：

p(xi|θ) = xi (1-θ)^{1-xi}, 0 ≤ θ ≤ 1

给定观测值 D = {x1, ..., xn}，似然是

L(θ) = ∏_{i=1}^{n} p(xi|θ)

最大似然问：哪个 θ 值使观测到的抛硬币最可信？

---

## 伯努利最大似然：从似然到对数似然

设 m = Σ_{i=1}^{n} xi 是观测到的正面数。似然变为

L(θ) = θ^m (1-θ)^{n-m}

最大化似然等价于最大化对数似然：

ℓ(θ) = m log θ + (n-m) log(1-θ)

---

## 伯努利最大似然：求解和解释

对对数似然求导：

dℓ/dθ = m/θ - (n-m)/(1-θ)

令导数为零：

m(1-θ) - (n-m)θ = 0

解得

θ̂_ML = m/n = (1/n) Σ_{i=1}^{n} xi

最大似然估计就是观测到的正面比例。

---

## 更多数据使似然更加集中

相对似然 1.0 n=5 / n=20 / n=100 — 所有峰值都在 θ̂ = 0.6 附近。

- 最大值保持在观测比例附近。
- 更多的观测产生更尖锐的似然曲线。
- 更多的数据给出更稳定的参数估计。

## 高斯最大似然

---

## 示例：估计高斯数据的均值

假设观测值独立同分布

xi ~ N(μ, σ²)

其中我们首先将 σ² 视为固定的，估计未知的均值 μ。高斯密度为

p(xi|μ) = (1/√(2πσ²)) exp(-(xi-μ)²/(2σ²))

对于独立观测，似然是

L(μ) = ∏_{i=1}^{n} p(xi|μ)

取对数得

ℓ(μ) = -n/2 log(2πσ²) - (1/(2σ²)) Σ_{i=1}^{n} (xi-μ)² + 常数

---

## 高斯均值最大似然

对对数似然求导：

dℓ/dμ = -1/(2σ²) * 2Σ(xi-μ)(-1) = (1/σ²) Σ(xi-μ)

令其为零得

Σ xi - nμ̂ = 0

μ̂_ML = (1/n) Σ xi

二阶导数为 -n/σ² < 0。

---

## 示例：估计高斯方差

在估计均值 μ̂ = x̄ 之后，我们仍然需要估计方差。方差描述了观测值在拟合均值周围的散布程度：

σ² = E[(X-μ)²]

对于高斯数据，最大似然给出

σ̂²_ML = (1/n) Σ_{i=1}^{n} (xi - x̄)²

这是到估计均值的平均平方距离。

**常见错误**

最大似然使用分母 n；无偏估计使用不同的修正。

---

## 为什么估计均值会改变方差？

假设我们有三个观测值 x1、x2、x3；如果真实均值 μ 已知，偏差从一个固定点测量：

(x1-μ, x2-μ, x3-μ)

然而，当 μ 从同一数据估计时，

x̄ = (x1+x2+x3)/3

残差必须满足

Σ (xi - x̄) = 0

一旦均值被估计，残差不再能在所有方向上自由变化。一个自由度被用来估计均值。

---

## 为什么方差使用 n-1？

最大似然估计是 σ̂²_ML = (1/n) Σ(xi - x̄)²

因为一个自由度被用来估计 x̄，

E[σ̂²_ML] = (n-1)/n * σ²

因此，平均而言，最大似然估计的方差略小于真实方差。

无偏样本方差修正了这种影响：

S² = 1/(n-1) Σ (xi - x̄)²

---

## 从一个高斯到多个特征

一维高斯描述一个变量：N(μ, σ²)

对于多个特征

x = [x1, ..., xd]^T

我们需要描述：

- 数据中心在哪里；
- 每个特征如何变化；
- 不同特征如何一起变化。

因此，方差变为协方差矩阵：

N(μ, Σ)

---

## 估计多元高斯

给定样本 x1, ..., xn，我们用样本均值估计中心：

μ̂_ML = (1/n) Σ xi

协方差估计为

Σ̂_ML = (1/n) Σ (xi - μ̂)(xi - μ̂)^T

每个元素都有含义：

- 对角线：一个特征的方差；
- 非对角线：两个特征之间的协方差。

估计多元高斯意味着同时估计特征的位置和特征之间的关系。

---

## 估计器质量

---

## 为什么我们应该关心估计器质量？

相同的估计方法在我们收集不同数据时可能产生不同的结果。

D1 → θ̂1, D2 → θ̂2, D3 → θ̂3

估计器是将数据转换为估计值的规则。例如，样本均值估计未知的总体均值：

- 低偏差，低离散度：θ̂ = x̄ （低偏差，高离散度）
- 高偏差，低离散度

红色十字：真值 蓝色点：来自重复数据集的估计

---

## 偏差和方差描述不同的误差

假设我们重复数据收集多次并获得估计 θ̂。

| **偏差** | **方差** |
|---------|---------|
| 衡量系统性误差： | 衡量跨数据集的随机性： |
| Bias(θ̂) = E[θ̂] - θ | Var(θ̂) = E[(θ̂ - E[θ̂])²] |
| 有偏估计器始终偏离真值。 | 高方差估计器在不同数据集之间变化很大。 |

偏差描述估计值的位置；方差描述它们的散布。

---

## 偏差-方差分解

均方误差（MSE）衡量估计值与真实参数之间的平均平方距离：

MSE(θ̂) = E[(θ̂ - θ)²]

加和减 E[θ̂] 得

θ̂ - θ = (θ̂ - E[θ̂]) + (E[θ̂] - θ)

取期望：

MSE(θ̂) = Var(θ̂) + Bias(θ̂)²

一个估计器可能因为有偏、不稳定或两者兼而有之而不准确。

---

## 示例：样本均值

对于均值为 μ 方差为 σ² 的 i.i.d. 数据，

E[x̄] = (1/n) Σ E[Xi] = μ

因此，样本均值是无偏的。

独立性给出

Var(x̄) = (1/n²) Σ Var(Xi) = σ²/n

## 从似然到最小二乘回归

---

## 概率回归模型

我们将目标建模为输入的线性函数加上噪声：

yi = w^T xi + εi, εi ~ i.i.d. N(0, σ²)

这里 xi 是输入特征向量，w 包含未知参数，εi 表示模型无法解释的随机误差。等价地，

p(yi|xi, w) = N(yi | w^T xi, σ²)

响应 y（均值响应）- 观测值 - 垂直噪声

---

## 为什么高斯噪声导致平方误差？

对于独立观测，

-ℓ(w) = - Σ log p(yi|xi, w)

在高斯噪声下，

-ℓ(w) = n/2 log(2πσ²) + (1/(2σ²)) Σ (yi - w^T xi)²

第一项不依赖于 w，因此最小化负对数似然等价于

ŵ = arg min_w Σ (yi - w^T xi)²

最小二乘是高斯噪声下的最大似然解。

---

## 最小二乘的矩阵形式

将所有样本堆叠成

X ∈ R^{n×d}, y ∈ R^{n}

所有样本的预测是 Xw，残差向量是

r = y - Xw

因此，

J(w) = ||y - Xw||²

最小二乘找到使残差尽可能小的参数。

---

## 最小二乘目标求导

最小二乘目标是 J(w) = ||y - Xw||²

展开平方范数：J = (y-Xw)^T(y-Xw)

展开各项得

J = y^Ty - 2w^TX^Ty + w^T X^TX w

只有包含 w 的项影响梯度。

---

## 从梯度到正规方程

对每一项关于 w 求导：

∇_w J = -2X^Ty + 2X^TXw

在最优点，∇_w J = 0

因此，X^TX ŵ = X^Ty

等价地，

X^T(y - Xŵ) = 0

残差与每个特征方向正交。

---

## 闭式解和实际计算

如果 X^TX 是可逆的，

ŵ = (X^TX)^{-1}X^Ty

这个公式给出了数学解，但实际实现通常避免显式计算逆矩阵。

- QR 分解
- SVD
- 数值最小二乘求解器

---

## 一个最小的 NumPy 实现

```python
import numpy as np
# 求解最小二乘而不形成 (X.T X)^(-1)
w_hat, residuals, rank, singular_values = np.linalg.lstsq(X, y, rcond=None)
print(rank, singular_values)
```

秩和奇异值揭示了数值问题。最终评估应使用保留数据。

## 概率假设决定学习目标

概率模型不仅仅是描述数据。它还决定了我们如何衡量预测误差。

从本节课：

高斯噪声 → -log p(y|x,w) = 平方误差

其他选择产生其他目标：

| 假设 | 产生的目标 |
|-----|-----------|
| 高斯响应噪声 | 平方误差 |
| 伯努利结果 | 交叉熵 |
| 类别结果 | 交叉熵 |

---

## 为什么模型假设很重要？

最大似然依赖于关于数据如何生成的假设。如果这些假设不合理，估计的参数可能无法代表实际问题。

示例：

- **独立性**：来自同一患者的重复测量可能包含共享信息。
- **分布选择**：高斯噪声可能不适合具有强异常点的数据。
- **数据覆盖**：从一个群体学习的模型可能无法泛化到另一个群体。

---

## 总结

1. 似然评估参数对观测数据的解释程度。
2. 最大似然将概率模型转化为优化目标。
3. 高斯假设导致平方误差回归。
4. 更多数据通常会提高估计器的稳定性，但假设很重要。
