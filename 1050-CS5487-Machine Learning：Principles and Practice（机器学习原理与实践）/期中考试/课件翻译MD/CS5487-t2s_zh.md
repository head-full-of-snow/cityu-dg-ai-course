任务1：似然解释与边界情况

伯努利模型 · 12分钟

一枚硬币服从伯努利模型：
p(x | θ) = θ^x (1 - θ)^{1-x}, x ∈ {0, 1}.

考虑两个数据集：
A = (1, 1, 1, 1, 1), B = (1, 0, 1, 1, 0).

问题

1. 在似然函数中，什么是固定的？什么是变化的？
2. 推导数据集A和B的θ的MLE（最大似然估计）。
3. 为什么数据集A产生边界解？

---

解答1：似然解释

在似然中，观测值是固定的，而θ变化。

对于伯努利数据，

L(θ) = ∏θ^{xi}(1-θ)^{1-xi} = θ^m (1-θ)^{n-m},

其中m是正面朝上的次数。
对于数据集A = (1, 1, 1, 1, 1)：

m = 5, n = 5, L(θ) = θ^5.

由于L(θ)随着θ接近1而增加，

θ̂_ML = 1.

---

解答1：构建似然函数

对于数据集B = (1, 0, 1, 1, 0)：

m = 3, n = 5.

因此，

L(θ) = θ^3 (1-θ)^2.

最大化似然等价于最大化对数似然：

ℓ(θ) = 3 log θ + 2 log(1-θ).

取对数将乘积转化为求和，这使得求导更容易。

---

解答1：求解内部最优解

对对数似然求导：在内部最优解处，
dℓ/dθ = 3/θ - 2/(1-θ) = 0.

因此，
3(1-θ) = 2θ,

θ̂_ML = 3/5.

任务2：高斯方差估计

MLE与解释 · 15分钟

假设

x1, ..., xn ~ N(μ, σ²)，

且均值已经估计为：

μ̂ = x̄.

问题

1. 推导σ²的MLE估计。
2. 解释残差项(xi - x̄)²代表什么。
3. 解释为什么无偏样本方差使用n-1而不是n。

---

解答2：高斯方差MLE

设μ = x̄，高斯对数似然为：

ℓ(σ²) = -n/2 log(2πσ²) - (1/2σ²)∑(xi - x̄)² + C.

令v = σ²。则：
dℓ/dv = -n/(2v) + (1/2v²)∑(xi - x̄)².

设导数为零：
-n/(2v) + (1/2v²)∑(xi - x̄)² = 0.

因此，

σ̂²_MLE = (1/n)∑(xi - x̄)².

---

为什么方差使用n-1而不是n？

差异的出现是因为均值是从同一数据估计的。
如果已知真实均值μ，则残差为：

xi - μ.

用x̄替换μ后，残差满足：

∑(xi - x̄) = 0.

这个约束意味着一个方向的变异性不再自由。
估计均值使用了一个自由度，留下了n-1个独立方向来测量变异。

---

解答2：解释n和n-1

MLE方差使用：

(1/n)∑(xi - x̄)².

常用的样本方差使用：

(1/(n-1))∑(xi - x̄)².

差异来自估计目标：

MLE选择使似然最大化的参数；
无偏估计修正系统性的向下偏差。

因此，这两个公式回答不同的问题。

n是MLE选择；n-1是无偏估计修正。

任务3：最小二乘解释

几何与模型理解 · 15分钟

考虑最小二乘解ŵ：
ŵ = arg min‖y - Xw‖².
         w

问题

1. 残差r = y - Xŵ代表什么？
2. 解满足

Xᵀr = 0.

从几何上解释这个条件。
3. 为什么在实践中通常避免使用显式逆矩阵(XᵀX)⁻¹？
4. 如果两个特征列几乎相同，会出现什么问题？

---

解答3：理解残差

残差为：

r = y - Xŵ.

它衡量观测目标值与拟合模型预测值之间的差异。

条件

Xᵀr = 0

意味着残差与X的每一列的内积为零。
因此，没有特征方向可以进一步减少残差。

---

解答3：几何与数值问题

闭式表达式为：

ŵ = (XᵀX)⁻¹Xᵀy.

通常避免显式求逆，因为可能出现数值问题。
如果两个特征列几乎相同，模型无法清楚区分它们的各自贡献。结果：
不同的参数值可能给出相似的预测；
估计的权重变得不稳定；
XᵀX变得病态。
QR分解和SVD提供更稳定的数值解。

可选挑战：改变噪声模型

从概率假设到损失函数

在高斯回归中，噪声假设导致平方误差。
现在假设回归噪声服从拉普拉斯分布：

p(yi | xi, w) = (1/2b) exp(- |yi - wᵀxi| / b).

问题

1. 推导负对数似然目标函数。
2. 与高斯最小二乘法进行比较。
3. 解释为什么噪声模型的选择会影响异常值。

---

解答：拉普拉斯噪声导致绝对误差

取负对数：

-ℓ(w) = -∑ log p(yi | xi, w) = n log(2b) + (1/b)∑|yi - wᵀxi|.

第一项相对于w是常数，而1/b只改变尺度。因此，

ŵ = arg min∑|yi - wᵀxi|.
         w         i

拉普拉斯噪声导致绝对误差回归（L1损失）。

---

解答：高斯噪声与拉普拉斯噪声

两种模型以不同方式衡量预测残差：

r = y - wᵀx.

高斯噪声给出：r²
拉普拉斯噪声给出：|r|

对于大误差，例如r = 10：
r² = 100, |r| = 10.
因此，平方误差对大误差的放大作用更强。
