② 贝叶斯 + 指标

P(D|+)= P(+|D)P(D) / [P(+|D)P(D)+P(+|¬D)P(¬D)]

医学例: 0.9×0.02/(0.9×0.02+0.08×0.98)=0.187；真阳 180 vs 假阳 784（基础率低⇒阳性多没病）。敏感性 P(+|D) ≠ 后验 P(D|+)。

Acc=(TP+TN)/N（不平衡会骗人）；精确率=TP/(TP+FP)；召回/敏感=TP/(TP+FN)；特异=TN/(TN+FP)。训练→验证（选模型）→测试（只碰一次）；预处理只用训练集。

③ 期望/协方差规则

  • Y=AX+b ⇒ E[Y]=Aμ+b；ΣY=AΣAT（b 不影响 Σ）
  • Y=aTX+b ⇒ E=aTμ+b；Var=aTΣa
  • 例: A=[[1,1],[0,1]], Σ=diag(4,1) ⇒ ΣY=[[5,1],[1,1]]，E[Y]=A[1,0]+b
  • Cov=E[(X−E[X])(Y−E[Y])]；ρ=Cov/σσ ∈[−1,1] 无量纲

④ 多元高斯·马氏距离（模板）

p(x)∝exp[−½(x−μ)TΣ−1(x−μ)]；同一高斯比两点⇒只比 D=(x−μ)TΣ−1(x−μ)，D 小者 p 大；pA/pB=exp[−½(DA−DB)]

步骤：|Σ| → Σ⁻¹ → 偏差 → D → 比较 → 比值。2×2 逆：[[a,b],[b,c]]⁻¹ = (ac−b²)⁻¹[[c,−b],[−b,a]]

Q1: μ=[1,2], Σ=[[4,1],[1,1]]：|Σ|=3，Σ⁻¹=⅓[[1,−1],[−1,4]]；xA−μ=[2,1] ⇒ DA=4/3；xB−μ=[0,2] ⇒ DB=16/3 ⇒ pA>pB（欧氏距离同为√5）；比值=e²≈7.39

⑤ 特征值 / PCA / SVD

  • [[a,b],[b,a]] 型：λ=a±b，u=1/√2[1,±1]；一般 2×2 对称：λ=[(a+c)±√((a−c)²+4b²)]/2
  • 例: [[3,2],[2,3]] ⇒ λ=5,1；u₁=1/√2[1,1]（最大方差方向）
  • PCA 方向=协方差阵最大特征值的特征向量；中心化 X=UDVT ⇒ V 列=PCA 方向，大奇异值=大方差（XTX=VD²VT）

⑥ MLE 万能四步

连乘似然 → 取 log → 导数=0 → 检查边界

  • Bernoulli: π̂=m/n；全成功 ⇒ π̂=1（边界，L=πn 单调）
  • 高斯: μ̂=x̄；σ̂²MLE=(1/n)Σ(xᵢ−x̄)²；无偏版 ÷(n−1)（均值从数据估出，损失 1 自由度，MLE 偏小）
  • 不等方差（Q6）: μ̂=Σ(xᵢ/σᵢ²)/Σ(1/σᵢ²)（精度加权）；σᵢ² 相等 ⇒ x̄

⑦ 回归数值题（列表法）

正规方程：Σrᵢ=0，Σxᵢrᵢ=0 ⇒ n·w₀+w₁Σx=Σy；w₀Σx+w₁Σx²=Σxy

Q2: (−1,0),(0,1),(1,2),(2,2)：Σx=2, Σy=5, Σxy=6, Σx²=6 ⇒ 4w₀+2w₁=5；2w₀+6w₁=6 ⇒ w₀=0.9, w₁=0.7；残差=(−0.2,0.1,0.4,−0.3) ⇒ σ̂²=0.3/4=0.075；ŷ(3)=0.9+2.1=3.0

套路：先填 x,y,xy,x² 四列求和 → 解 2×2 方程 → 残差平方平均=σ̂² → 代入预测。

⑧ Beta-Bernoulli 更新

Beta(α,β) + (m,n−m) ⇒ Beta(α+m, β+n−m)

  • 后验均值=下次成功概率=(α+m)/(α+β+n)；MAP=(α+m−1)/(α+β+n−2)（要求 α+m>1, β+n−m>1，否则边界）
  • 例: B(2,2), m=3, n=4 ⇒ B(5,3)：均值 5/8=0.625，MAP 2/3≈0.667，MLE 0.75（先验 κ₀=α+β 越大越拉向先验；B(20,20) 同数据⇒23/44≈0.523）
  • 均值=加权平均：wprior(α+β)/(α+β+n)·先验均值 + wdata·m/n
  • 5 次全败: MLE=0；Beta(1,1)⇒Beta(1,6)⇒预测 1/7（贝叶斯避免极端）

⑩ 高斯-高斯共轭

精度=1/方差：λ₀=1/τ₀²，λD=n/σ²

μn=(λ₀μ₀+λDx̄)/(λ₀+λD)；τn²=1/(λ₀+λD)；预测 x*~N(μn, σ²+τn²)
  • 例: μ~N(10,4), n=2, x̄=14, σ²=8：λ₀=λD=0.25（等权）⇒ μn=12, τn²=2；预测 N(12, 8+2=10)（预测方差=参数不确定+新噪声，更大）
  • 例2: N(10,4), n=4, x̄=12, σ²=4：λD=1 ⇒ μn=0.2·10+0.8·12=11.6, τn²=0.8
  • τ₀²→∞ 或 n→∞ ⇒ μn→x̄=MLE；谁精度高谁权重大

⑪ MAP / 正则化 / 软阈值

  • MAP = 最小化(−log似然 −log先验)。高斯先验 N(0,τ²) ⇒ L2：‖y−Xw‖²+λ‖w‖², λ=σ²/τ²（岭回归）；拉普拉斯先验 ⇒ L1（稀疏，可压到 0）
  • 先验中心 w₀: 惩罚 ‖w−w₀‖² ⇒ (XTX+λI)ŵ = XTy+λw₀；w₀=0⇒标准岭；τ²→∞⇒λ→0⇒OLS
  • 岭稳定机制：XTX 近奇异（特征共线）时 +λI 抬高小特征值
Q7 拉普拉斯 MAP: L(w)=n/(2σ²)·(w−x̄)²+λ|w|（用 Σ(xᵢ−w)²=Σ(xᵢ−x̄)²+n(w−x̄)²）。w>0: w=x̄−λσ²/n（当 x̄>λσ²/n）；w<0 对称；|x̄|≤λσ²/n ⇒ ŵ=0。合并：ŵ=sign(x̄)max(|x̄|−λσ²/n, 0)

⑮ 简答题模板（问法→答题要点）

方差为何 n−1？均值由同数据估出，Σ残差=0 损失 1 自由度；MLE÷n 偏小，÷(n−1) 无偏
MAP≠后验均值？众数 vs 全分布平均；后验不对称时分叉（B(2,5): 0.286 vs 0.2）
后验预测≠代 MAP？按后验对所有参数加权平均，保留不确定性（5 败: MLE 预测 0，贝叶斯 1/7）
敏感性 vs 后验？P(+|D) 患病中阳性 vs P(D|+) 阳性中患病；基础率低⇒后验≪敏感性
先验何时帮/害？帮：真实先验、稳定共线/高维；害：强+错+未检验
为何 EM 不直接 MLE？log(Σ) 耦合无闭式；Jensen 下界每步似然不减；仅局部最优
K-means 收敛？两步各使 J 不增+分配有限⇒不动点；局部最优、初始化敏感
K-means 失败场景？球形假设被违反：长条/密度不均/非凸/离群拉均值
GMM vs K-means？软概率 vs 硬分配；椭球各Σₖ vs 球；GMM 可过拟合（σ²→0，防护 Nₖ≥5）
岭回归为何稳？共线⇒XᵀX 病态系数乱跳；+λI 抬小特征值；λ=σ²/τ²
高斯 vs 拉普拉斯噪声？Σrᵢ² vs Σ|rᵢ|；平方放大大误差（r=10: 100 vs 10）

⑰ K-means

J=ΣiΣkrik‖xi−μk‖²（簇内平方和；rik∈{0,1}, Σkrik=1）

循环：①初始化 ②分配=最近中心 ③中心=成员均值 μk=Σrikxi/Σrik ④重复至不变。每步 J 不降+分配有限⇒收敛（仅局部最优，初始化敏感→多次取 J 最小 / K-means++（按 D(x)² 概率选远点））

例: 点 {1,2,7,8}，μ=1,5：|x−μ₁|=(0,1,6,7), |x−μ₂|=(4,3,2,3) ⇒ {1,2}|{7,8}；μ→1.5, 7.5；J：14→1；再分配不变⇒停

假设：球形/欧氏=相似/均值有意义。失败：长条、密度不均、非凸（环/月牙）、离群点拉偏均值。

⑱ GMM + EM（大题）

p(x)=ΣkπkN(x|μk,Σk)；生成：P(z=k)=πk → x~N(μk,Σk)

E: γik=πkN(xi|μk,σk²)/ΣjπjN(xi|μj,σj²)（每点 Σkγ=1；=归一化 先验×似然）

M: Nk=Σiγik；πknew=Nk/n；μknew=Σγikxi/Nk；σk²new=Σγik(xi−μknew)²/Nk（软计数→位置→散布；σ² 用新 μ！）

Q4 完整例: x={0,2,4}；π=(0.6,0.4)，μ=(0,4)，σ²=2。
一维 N 值：N(0|0,2)=.2821，N(2|0,2)=N(2|4,2)=.1038（对称⇒γ 只由 π 定=(0.6,0.4)），N(4|0,2)=.0052
γ 表：(0.9879,0.0121) / (0.6,0.4) / (0.0267,0.9733)
N₁=1.6147, N₂=1.3853（和=3✓）⇒ π=(0.5382, 0.4618)；μ=(0.8094, 3.3877)；σ²=(1.10, 0.92)
讲义例 x={1,3,5}, π=½½, μ=(1,5), σ²=1：γ=(0.9997,.0003)/(.5,.5)/(.0003,.9997)；N=1.5/1.5；μ=(1.668, 4.332)；σ²=0.891（中点各半贡献）

t4 例（直接给 p(x|z)）：s=π·p=(0.18,0.15,0.12)，Σ=0.45 ⇒ γ=(0.40,0.33,0.27)——大 πk 不一定大 γ（似然也重要）。

M 步目标（Q 函数）：Q(θ)=ΣiΣkγik[log πk+log N(xi|μk,Σk)]（加权 MLE）；GMM 对数似然 ℓ(θ)=Σilog(ΣkπkN(xi|μk,Σk))。

为何 EM：ℓ=Σlog(ΣπN) 的 log(和) 使方程耦合无闭式。Jensen 构造下界 L(q,θ)≤ℓ；E 步 q=p(z|x) 使下界贴紧（gap=KL(q‖p)≥0），M 步最大化下界⇒似然不减，收敛局部最优。

GMM→K-means（Q8）: πk=1/K, Σ=σ²I ⇒ γik=exp(−‖x−μk‖²/2σ²)/Σjexp(−‖x−μj‖²/2σ²)；比值 γa/γb=exp[(‖x−μb‖²−‖x−μa‖²)/2σ²]；σ²→0 且 k* 唯一最近 ⇒ γik*→1 其余→0（硬分配）；M 步变 μk=成员均值 = K-means。

补充: 协方差结构 Spherical(σ²I，等价 K-means 假设)/Diagonal/Shared/Full；过拟合：分量坍缩 σ²→0 似然∞ → 防护 Nk≥5、方差下限、验证集；BIC=−2logL+d·logN（越小越好，选 K）；分量数≠真实类数。

⑲ KDE

p̂(x)=1/(nh)·ΣiK((x−xi)/h)（d 维：1/(nhd)）

  • 核：高斯 1/√(2π)·e−u²/2；Box: |u|≤1 取 ½；三角 max(0,1−|u|)。1/h 保面积=1；密度≠概率
  • 局部推导：2r·p(x)≈Nr(x)/n ⇒ p̂=Nr(x)/(2nr)；直方图=计数/(nh)，缺陷：不连续+对 bin 起点敏感
  • h 小：尖峰/方差大（训练点间隙可为 0）；h 大：平滑/偏差大；h 用验证集选（训练集 h→0 密度→∞ 过拟合）
  • 多维先特征归一化；维度灾难 hd
例 {0,2,3} 三角核求 x=2：h=1 ⇒ 只有自身 K(0)=1 ⇒ 1/3；h=2 ⇒ (K(1),K(0),K(.5))=(0,1,0.5) ⇒ 1.5/6=1/4。验证 x=1：h=1⇒0；h=2⇒(0.5+0.5+0)/6=1/6 ⇒ 选 h=2

⑳ 均值漂移

xnew=x+m(x)，m=Σwixi/Σwi−x，wi=exp(−‖x−xi‖²/2h²)

  • 簇心=密度峰（KDE 梯度上升），无需 K；h 小⇒多簇，h 大⇒合并；峰=吸引盆，同盆同簇
  • 例 {0,2,4}，x=1，h=2：w=(.8825,.8825,.3247) ⇒ x′=3.064/2.090≈1.47；课堂例 {0,1,2,3} h=1 x₀=2→1.355→0.778
  • vs K-means：软权重/任意形状/无需 K；但 O(n²d) 贵

㉑ 谱聚类

wij=e−‖xi−xj‖²/σ²；D=diag(行和)；L=D−W（每行和 0）；fTLf=½Σwij(fi−fj)²（平滑度）

Ncut(A,B)=cut(A,B)/vol(A)+cut(A,B)/vol(B)（vol=簇内度之和）；小者优（惩罚孤立小簇）；NP难→松弛 Lf=λDf 取前 k 小非零特征向量→新空间 K-means。加速：kNN 图代替全连接，O(n³)→稀疏求解。

t5 例 W=[[0,3,0,0],[3,0,1,0],[0,1,0,3],[0,0,3,0]]：D=diag(3,4,4,3)
P₁={1,2}|{3,4}：cut=1（2–3 边），vol 7/7 ⇒ Ncut=2/7≈0.286
P₂={1}|{2,3,4}：cut=3，vol 3/11 ⇒ Ncut=1+3/11≈1.273 ⇒ P₁ 优；f=[1,1,0,0] ⇒ fTLf=2×跨割权/2=1

四聚类对比：K-means 球形 O(nkd)｜GMM 概率软分配｜mean-shift 密度峰 O(n²d)｜谱聚类非凸 O(n³) 最贵。
